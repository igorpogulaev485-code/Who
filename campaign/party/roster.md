# Партия

Стартовое имя группы (сессия 1): **Контактный зоопарк «Бродяга»**.  
Состав менялся по сессиям. Ниже — актуальные и известные персонажи на момент после 8-й основной сессии.

## Активные / ключевые

| Персонаж | Раса / класс | Заметки |
|---|---|---|
| **Балтан** (также **Болтан**) | харенгон-бард | Друг Дранника с сессии 1; вторая ипостась **Тиара** пала в битве за Лунный Овраг |
| **Грок** | тортл-паладин Хельма | С сессии 1 носит **ритуальный кинжал Кардиана** (найден в логове «Хвоста Скорпиона», не изучен); позже — Хельм, кольцо Маэстро |
| **Вирра** | харенгон-жрец кузни | Сиреневая шерсть, серёжка-наковальня; позже — медальон и маска Кардиана |
| **Дранник** | харенгон-друид | Друг Балтана; после 7-й сессии **в плену** (вероятно Храм Лолс) |
| **Мёртвый Лист** | табакси-плут | Бывший воспитанник Приюта «Колыбель Рассвета»; **в плену** вместе с Дранником и Багалом |
| **Фиолетовый Жаб** | грунг-плут | Воровские знаки на рынке сессии 1 сразу вывели к банде; вернулся у храма Хельма |
| **Уораг** | дроу-монах | Иногда отсутствовал; участвовал в ключевых городских арках |
| **Багал** | аасимар-колдун | Младший адъютант короля, посол; **в плену** |
| **Кавел** | человек-друид | Младший адъютант короля, посол |
| **Иннокентий Баль (Кеша)** | человек-воин без оружия (скрытый **вампир**) | Проводник; цель — артефакты Кардиана; задумал усилиться драконьим сетом (1-й в Храме Лолс) |

## Были в партии / эпизоды

| Персонаж | Заметки |
|---|---|
| **Зеварду** | полуорк-друид; присоединился в лагере орков (3-я сессия); позже отсутствовал |
| **Тиара** | ипостась Балтана; **погибла** в битве за Лунный Овраг. Последние слова: «Скажите Балтану... я вернулась в детство, чтобы снова найти себя» |

## Орден Королевских Адъютантов Аэлендора

Багал и Кавел — младшие адъютанты Его Величества, в походе выступают **послами короля Константина III**.
