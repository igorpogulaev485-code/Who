# Зеварду Каменный лев

| | |
|---|---|
| Раса | Полуорк |
| Класс | Друид — Круг земли |
| Уровень | 2 (XP 810) |
| КД / HP | 12 / 17 |
| Предыстория | Мудрец — профессор |
| Мировоззрение | Законно-добрый |

## Статус

Эпизодический. **Не** герой Аэлендора.  
В объявлениях признан **помощником Кардиана**: своей магией (призвал сову) **разбил Зеркало Разлома**.

Афиша розыска: [`assets/images/parchment-posters/15-wanted-zevardu.png`](../../../assets/images/parchment-posters/15-wanted-zevardu.png)

## Заметки с листа

- Внешность: мощный, чёрные волосы с сединой у висков в пучке, светло-голубые глаза, спокойный взгляд мудреца.
- Племя «Серые Скалы»; наставник Уртаг / Хетаг; кристалл «Сердце Каменного Льва».
- Черта «Дикий талант» (псионика UA).

## Канон катастрофы

По слову мастера: Зеварду призвал сову, и она разбила **Зеркало Разлома** → соучастник катастрофы Лунного Моста.
