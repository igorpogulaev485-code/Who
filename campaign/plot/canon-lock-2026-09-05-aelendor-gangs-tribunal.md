# Канон: федеральные банды, банкиры, Верховный трибунал

Утверждено мастером 2026-09-05.

## Три федеральные сети

| # | Имя | Суть |
|---|---|---|
| **F1** | **Чёрная Просека** | дороги, обозы, «налог с тракта» |
| **F2** | **Паутина Росы** | порты, долги, морская/речная контрабанда (опора — Розалия) |
| **F3** | **Пепельный Договор** | оружие, наёмники, трофеи (юг / ЮЗ) |

В каждом регионе дополнительно **2–5** местных банд (имена — по мере сюжета).  
**Лунный Мост** ≈ без банд (религиозный центр); **Хвост Скорпиона** уничтожен.

Где-то федералы сильнее местных, где-то наоборот.

## Банкиры

Отдельного кресла в Синклите **нет**.  
Сила через касту / блок **Серебряный Путь** (торговцы) и влияние на казну.

## Верховный трибунал

Институт **светских** судей.  
Имеет **отдельное кресло** в Синклите (9-е отраслевое).  
Храмовые суды остаются у жрецов — возможен конфликт юрисдикций.

Синклит теперь: **9 отраслей + 8 регионов**.
