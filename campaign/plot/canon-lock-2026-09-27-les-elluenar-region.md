# Лок — регион у портала

Опрос v1 закрыт ответами мастера (свободный текст → id ниже).

## Решения

| id | Решение |
|---|---|
| **A** | Имя региона — **эпичное эльфийское**. Зафиксировано агентом на ревью карты: **Эллуэнар** *(мастер может переименовать)* |
| **B** | Центральный город = **Серебряный Порог** (уже на карте государства). Не новая выдумка |
| **C** | **Храм Серебряного Порога** — **вне** города, близко, **отдельная** точка |
| **D** | **Пятно порчи на карту не ставить** — карта условно постоянная; порча = временный тик / стол, не география |
| **E** | **Силвании нет** на этой карте. У столицы / Древа / любой крупной точки страны — **свой** регион |
| **F** | Вопрос композиции снят: расклад делает агент по смыслу (западный зум страны у Порога) |
| **G** | Сразу **карта** (понятнее текста) → потом seed |
