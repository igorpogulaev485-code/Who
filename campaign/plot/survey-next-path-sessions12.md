# Опрос — какой путь следующий?

**Контекст:** сессия 1 (похороны) общая и готова. Сессия 2 уже есть для дверей **A** (фиолетовый / mq-01) и **F** (чёрный / mq-04).  
Нужен полный скрипт **сессии 2** следующего направления (как договаривались: первые 2 сессии по каждому пути).
