# Канон: как узнать государственную касту

Речь только про **официальные / государственные** касты (не банды, не теневой слой):

1. Высшие Дома  
2. Звёздный Круг  
3. Щит Луны  
4. Корни  
5. Серебряный Путь  
6. Хранители Завесы  

## Правило улицы

| Уровень | Как отличить |
|---|---|
| **Между кастами** | По **одежде и внешнему виду** — у каждой касты своя **форма / узнаваемый облик**. Обычный житель за несколько секунд видит *какую* касту. |
| **Внутри касты** | **Регалии**: медали, нашивки, знаки отличия **на той же форменной одежде** — ранг, заслуга, дом/отделение внутри касты. |

Форма касты = «мундир» государства для этого сословия.  
Регалии = иерархия *внутри* мундира.

Конкретные цвета / крои / знаки по каждой касте — **к наполнению** (вопрос за вопросом).
