## Что залочено

1. **Силуэт** красного пунктира: лес запад+центр, залив восток с островами (в духе contour-lock / карты мира).
2. **Снаружи** пунктира: пергамент + западные горы у левого края; без подписей соседей.
3. **Шесть точек** (иконки + exact whitelist-подписи):
   - Силвания (столичный зал / постройки)
   - Мировое Древо (рядом, со святилищем)
   - Серебряный Порог (запад у гор)
   - Пепельный Рубеж (запад у хребта)
   - Северная Заводь (север у воды, пристань)
   - Восточные Врата (материковый берег у залива)
4. Атмосфера v12: живой полог, туман, тропы, детали берега — не «сухой» плоский лес.

## Правила дальше

| Можно | Нельзя |
|---|---|
| Копировать locked → новый слой (регионы, дороги, баннеры) | Перегенерировать всю карту «с нуля» без нового лока |
| Точечные правки только по ок мастера | Двигать города / силуэт / заливать соседей без запроса |
| Подписи соседей — только если мастер просит, на производном слое | Править `…-map-locked.jpg` на месте |

Старый этап 1.1 terrain lock остаётся **superseded** (патч-композит); полная карта — этот лок.
