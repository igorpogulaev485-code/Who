# Лок: Живой мир

Первичный ответ:

```
A=a_both B=b_2plus C=c_rift+c_order+c_ridge+c_ice+c_velian+c_valley+c_elessar
D=d1 E=e_later F=f_no G=g_mix H=h_lock
```

**Правка мастера 2026-09-24:** A → **`a_end`** (тик только по итогам **сессии**; интерлюдию не брать в расчёт).

| id | Решение |
|---|---|
| **A** `a_end` | Тик **только** в конце сессии (после клиффа / рекапа). Интерлюдия ≠ тик |
| **B** `b_2plus` | За тик: **1–2** фронта + **обязательная новость** партии |
| **C** | Горячие ★: **Разлом · Орден · Хребет · Льды · Велиан · Долина · Элессар** |
| **D** `d1` | Старт Лунного Разлома = жар **1** |
| **E** `e_later` | Часы Двойника — **позже** |
| **F** `f_no` | Интерлюдия дневника ≠ тик (согласуется с A) |
| **G** `g_mix` | Канал новости чередуем |
| **H** `h_lock` | Лок → гл. 17 |

**Как вести:** после сессии (и после интерлюдии — только действия партии) смотришь, что случилось → крутишь тик **только** если была сессия → обновляешь трекер.
