# Лок: Живой мир

Ответ мастера:

```
A=a_both B=b_2plus C=c_rift+c_order+c_ridge+c_ice+c_velian+c_valley+c_elessar
D=d1 E=e_later F=f_no G=g_mix H=h_lock
```

| id | Решение |
|---|---|
| **A** `a_both` | Тик в конце **сессии** и в **интерлюдии** |
| **B** `b_2plus` | За тик: **1–2** фронта + **обязательная новость** партии |
| **C** | Горячие ★ сейчас: **Разлом · Орден · Хребет · Льды · Велиан · Долина · Элессар** |
| **D** `d1` | Старт Лунного Разлома = жар **1** |
| **E** `e_later` | Часы Двойника / крышки — **позже**, не крутить каждый тик |
| **F** `f_no` | Интерлюдия дневника (open 16/17/52–55) **≠** тик мира |
| **G** `g_mix` | Канал новости чередуем |
| **H** `h_lock` | Лок → трекер и шаги в гл. 17 |

Не в ★ сейчас (фон): Милана/дневник · Тёмные леса · Камнеград · арты · Двойник.
