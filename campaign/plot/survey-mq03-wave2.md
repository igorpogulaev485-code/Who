## Зачем эта волна

Сессия 2 теперь выглядит так (черновик каркаса):

1. Верхний город / похоронный хвост или утро после с.1.  
2. Кавил **может** (если игрок захочет) открыть портал.  
3. Высадка в **храме**.  
4. Осмотр / контакт / правила Леса.  
5. Клифф: **три дороги** с порога храма (или только намёки).

Всё, что ниже — про храм, портал, вилки и что оставить на потом.

## J · Что это за храм? (характер места)

**Контекст.**  
Не столица и не «дворец Элессара». Нужна точка высадки с атмосферой, НПС и смыслом, почему **королевский** портал Аэлендора вообще ведёт **сюда**.

| id | Вариант | Ощущение | Зачем портал сюда логичен |
|---|---|---|---|
| **j_druid** | **Друидский** храм / роща-святилище | Природа, камни, живое дерево | Связь с Малфурионом / советом; Дранник «дома» |
| **j_royal** | **Дипломатический** храм-посольство Аэлендора в Лесу | Гербы, гостевые крылья, строгие эльфы | Канал адъютантов / Теневого Совета |
| **j_neutral** | **Нейтральный** храм границ (ничейный обычай гостя) | Серые правила, ни корона ни круги | «Сюда можно всем высоким гостям» |
| **j_ancient** | **Древний** храм (до текущего двора Леса) | Руины/жива старина; местные смотрят косо | Портал на старой линии, не на столицу |
| **j_sylphia** | Связь с **Сильфией / Мировым Древом** (осторожно) | Сакрал дракона-друида | Глубокий лор; риск спойлеров |
| **j_other** | Другое / уточню | | |

## L · Портал: правила за столом

**Контекст.**  
Кавил **может** открыть — но не обязан. Нужны границы, чтобы не сломать арку («прыгнули обратно через час»).

| id | Вариант |
|---|---|
| **l_one_way_day** | В с.2: **односторонний** или обратный только через **сутки+/ритуал** |
| **l_return_cost** | Обратный есть, но **цена** (ячейка / долг Совету / шум Разлому) |
| **l_kavil_only** | Открывает **только Кавил** (или с его печатью); без него — нет |
| **l_once_arc** | Эта линия портала — **редко** (не ежедневный телепорт-хаб) |
| **l_mix** | `l_kavil_only` + обратный с ценой / задержкой |
| **l_other** | Другое / уточню |
