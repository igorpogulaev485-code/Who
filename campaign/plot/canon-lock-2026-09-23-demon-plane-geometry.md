# Лок — геометрия плана демонов

Опрос: [`survey-demon-plane-geometry-v1.md`](survey-demon-plane-geometry-v1.md)  
План: [`../prep/orchestrator/demon-plane-map-plan.md`](../prep/orchestrator/demon-plane-map-plan.md)

## Главное (слова мастера)

1. **Круги — это круги ПЛАНА**, не «круги Разлома».  
2. **Разлом (на Материале)** = лишь **вход** в план. Входов **много** (пять активных Разломов мира → разные точки входа на один атлас плана).  
3. Атлас: круги ≈ **страны / государства** плана.  
4. Переход круг→круг = через **большие демонические ворота** (архитектура).  
5. **Маяк душ** на обзоре = **крошечная** точка на **первом круге** (едва заметна).  
6. Player-карта: подписи **только названий кругов** + ясно, **как пройти** между ними (ворота).  
7. План мёртвых на этой карте **не** показывать (`h_none`).  
8. Каркас mq-02 ~20 + круг 2 охоты — **ok** (`j_ok`).

## Якоря на атласе (решение «как надо» для C)

Согласовано со spine и с моделью «круги = страны»:

| Круг (роль) | Что внутри (GM; на player-обзоре — только имя круга) |
|---|---|
| **Круг 1** | Вход с **Лунного моста** (Купель); **Маяк** (точка); **Алтарь Крови**; путь к первым воротам |
| **Круг 2** | За первыми воротами: охота mq-02 (дворы носителей) |
| **Круг 3** | **Серебряный Филактерий** / лабиринт душ = своё «государство» |
| **Круг 4** | **Око Затмения** / сердце плана |

Цепь для mq-01: 1 → ворота → 2 → ворота → 3 → ворота → 4.  
Другие Материальные Разломы могут выплюнуть партию/врагов в **другие** края тех же или иных кругов (детали входов 2–5 — позже).

Имена кругов для подписей карты — в gazetteer (черновик → ok мастера на whitelist).

## mq-02 (решение «как надо» для I)

| | |
|---|---|
| На **обзорной** player-карте | носителей и дворы **не** подписывать (только круг 2 как страна + ворота) |
| В spine / GM | имена носителей **оставить**: Шепчущий Взор · Жнец Жилы · Зов-без-Голоса |
| Site-карты дворов | когда дойдём до круга 2 за столом |

Ворота 1→2 = те же «первые ворота» локa mq-01/02, теперь явно: **крупные демонические ворота** между государствами плана.

## Терминология (править в prep)

| Было (привычка) | Стало |
|---|---|
| «круги Разлома» | **круги плана** |
| Разлом = всё пространство ветки | Разлом = **рана/вход** с Материала |
| карта «внутри Разлома» | **атлас плана демонов** |

## Не на этой карте

- Серый Причал / план мёртвых  
- Имена Алтари / Филактерия / Ока на **player**-обзоре (GM-схема B может держать)  
- Крупный Маяк как доминанта атласа  

## Уточнение 2026-09-23 (мастер: «сколько в ДНД»)
