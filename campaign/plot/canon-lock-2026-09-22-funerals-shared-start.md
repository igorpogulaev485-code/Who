# Лок — общий старт направлений

| # | Решение |
|---|---|
| 1 | **Сессия 1 арки 3** (похороны Маэстро по всему Лунному мосту + центр) — **общий старт для всех направлений** mq-01…mq-06 (и заглушек волны). |
| 2 | После похорон партия выбирает **дверь** → это и есть вход в конкретный mq. |
| 3 | **Сессия 2 «Рана в Купели / Маяк душ»** — только если дверь = Разлом (mq-01 / сплетение mq-02/04). Иные двери → другая сессия 2. |
| 4 | mq-05 не «вместо» старта: похороны **и есть** хаб; чтение дневника / дочь — ветки **внутри** или сразу после хаба. |
