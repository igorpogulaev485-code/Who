## A. Что такое «регионы» на атласе?

| id | Вариант |
|---|---|
| `a_realms` | ★ **Края / державы загробья** (страны памяти) — как «государства» у демонов, но другие имена и тон |
| `a_cities` | Цепь **городов-островов** в пепельном море (Причал = один порт из многих) |
| `a_rings` | Кольца/слои (ближе к Данте) — риск «второй ад» |
| `a_other` | Своё |

**Почему ★:** spine уже мыслит краями (Причал → Край → второй город), не кольцами; визуально отличит от демонов.

## B. Серый Причал на обзоре

| id | Вариант |
|---|---|
| `b_port` | ★ **Крупная подпись + силуэт города** на берегу (хаб mq-04) |
| `b_dot` | Микроточка (как Маяк на демонах) |
| `b_omit` | Не показывать — только site-карта |
| `b_other` | Своё |

**Почему ★:** выход чёрного потока = сразу площадь; игрокам нужен якорь «мы здесь».

## C. Сколько именованных краёв на первом атласе?

| id | Вариант |
|---|---|
| `c_5` | ★ **5 краёв** (хватит spine 1–12) |
| `c_7` | **7 краёв** (место под акт D) |
| `c_9` | 9 (симметрия с демонами — не советую) |
| `c_other` | Своё число |

**Черновик пятёрки ★ (имена provisional — ok отдельно):**

| # | Рабочее имя | Роль в mq-04 |
|---:|---|---|
| 1 | **Серый Причал** | вход / хаб |
| 2 | **Край** | след Велиана, диверсии |
| 3 | **Пепельные Плёсы** | серые бури Кардиана (открытая зона) |
| 4 | **Нижние Дворы** | охотники / архивы имён / риск |
| 5 | **Второй Берег** | «второй город» акта D (имя позже) |

## D. Как связаны края?

| id | Вариант |
|---|---|
| `d_roads` | ★ **Серые тракты / мосты пепла** между соседними (читаемый путь) |
| `d_gates` | Большие **ворота** как у демонов |
| `d_boats` | Переправы по **пепельному морю** |
| `d_mix` | Тракты + редкие переправы |
| `d_other` | Своё |

**Почему ★:** тон «загробный быт» = дороги и караваны памяти, не демонические арки.

## E. Где «живёт» давление Кардиана на карте?

| id | Вариант |
|---|---|
| `e_zone` | ★ Отдельный край (**Пепельные Плёсы**) — буря как погода региона |
| `e_overlay` | Не регион: буря может накрыть **любой** край (на обзоре не рисовать) |
| `e_dot` | Точка «сердце бури» внутри Плёсов |
| `e_other` | Своё |

## F. Второй город / Нижние дворы

| id | Вариант |
|---|---|
| `f_named` | ★ На атласе **два** пятна: Нижние Дворы + Второй Берег (имена draft ok) |
| `f_one` | Одно пятно «Дальние дворы» на первое время |
| `f_hide` | Не подписывать до акта D |
| `f_other` | Своё |

## G. Player-подписи

| id | Вариант |
|---|---|
| `g_realms` | ★ Только **имена краёв** + Причал + тракты |
| `g_plus_edge` | + подпись **Край** крупнее (квест-направление) |
| `g_full` | Ещё реликвии/диверсии (не советую на обзоре) |
| `g_other` | Своё |

**Запрет ★:** Велиан · пятёрка · Кардиан · Лайра · имена нпс Причала.

## H. Связь с планом демонов

| id | Вариант |
|---|---|
| `h_none` | ★ **Отдельный атлас** (как уже для демонов) |
| `h_hint` | Маленькая пометка «другой поток Купели» без карты демонов |
| `h_other` | Своё |

## I. Эстетика / якорь стиля

| id | Вариант |
|---|---|

| `i_echo24` | Ближе к атласу демонов v24 (контрастнее биомы) |
| `i_mix` | Причал-тон + чуть контраста краёв |
| `i_other` | Своё |

| `j_other` | Своё |
