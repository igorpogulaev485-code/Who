# Опрос mq-03 v2 — с контекстом «зачем спрашиваю»

**Путь:** дверь **D** · «как раньше» = после ответов spine + скрипт сессии 2 → стоп.  
**Новый канон:** [`canon-lock-2026-09-22-malfurion-council.md`](canon-lock-2026-09-22-malfurion-council.md) — Малфурион + совет друидов (~1 мес.).

## Зачем вообще эти вопросы

У Разлома сессия 2 = **не** финал квеста, а **закрепиться**:

| Дверь | Сессия 2 закончилась на… | Финал направления — позже |
|---|---|---|
| **A** | Маяк душ + Сарель | Алтарь / Око / … |
| **F** | Серый Причал + Лайра | Велиан ~с.6 пути |
| **D** | ??? ← вот это и выбираем | Элессар? совет? оба? |

В Лесу теперь **две** цели, которые могут тянуть в разные стороны:

1. **Корона** — найти / уговорить **Элессара I**.  
2. **Природа** — Дранник (и партия, если расскажет) знает про **совет друидов** у **Малфуриона** через ~месяц.

Вопросы A–I решают: *куда упирается вечер сессии 2*, *как едем*, *кто толкает*, *что мешает на дороге*, *как Лес встречает*, *сколько prep пишем сразу*, *что тикает дома*, *как сплести корону и совет*.

## A · Где клифф сессии 2? (куда «приземлиться» к концу вечера)

**Контекст.**  
Дорога Лунный мост → ЮВ → зона **Ордена пламенеющей стали** → дальше к Лесу — **долгая**. Если впихнуть Элессара в сессию 2, получится «киношный скачок» (как если бы в сессии 2 фиолетового сразу дали Алтарь).  
Параллель: A закончилась на **Маяке** (первая база), F — на **Причале** (первая база).

| id | Вариант | Что это значит за столом | Плюс / риск |
|---|---|---|---|
| **a_order** | Клифф в **зоне Ордена** | Вечер: сборы → выезд → первая серьёзная сцена с Орденом; Лес = дым/слухи на горизонте | Близко к городу; мало «Леса»; давление войны |
| **a_border** | **Граница Леса** | Монтаж/дорога + узел Ордена (или нет — см. D) → деревья-стражи; клифф «порог» | Классика «закрепились у входа», как Маяк/Причал |
| **a_village** | **Первое поселение** под кронами | Успели войти; культура Леса; **ещё нет** аудиенции Элессара и **ещё нет** совета | Богаче тон Леса; дольше дорога |
| **a_elessar** | До **Элессара** в ту же сессию | Сжатый тревел + аудиенция одним вечером | Много спойлеров/политики сразу; совет Малфуриона может не успеть |
| **a_malfurion** | До **Малфуриона** / места совета (без полного совета) | Личная нить Дранника; корона — позже | Сильный xp_personal Драннику; Элессар откладывается |
| **a_other** | Другое / уточню | | |

## B · Как сжимаем дорогу по времени за столом?

**Контекст.**  
Игровое время ≠ экранное. «Месяц до совета» тикает в мире; за **один** вечер нельзя отыграть месяц пути без монтажа.  
Нужно правило: сколько **игровых дней** съест сессия 2 и сколько сцен игроки реально крутят.

| id | Вариант | Пример вечера | Влияние на таймер совета |
|---|---|---|---|
| **b_montage** | **Монтаж дней** + 1–2 ярких узла | «Неделя пути» одной сценой + Орден + граница | Можно сжечь много календаря за вечер |
| **b_one_day** | **Один** игровой день | Утро сборов → Врата Рассвета → лагерь/засада к ночи | Таймер почти не двигается; совет всё ещё ~месяц |
| **b_few_days** | 2–4 игровых дня, несколько коротких битов | Без «недели в абзаце», но и не один день | Умеренно |
| **b_multi** | Много полноценных тревел-сцен без монтажа | Медленно; атмосфера | Риск не дойти до клиффа A |
| **b_other** | Другое / уточню | | |

## C · Кто «открывает» дверь D после похорон?

**Контекст.**  
В сессии 1 дверь D уже названа: «Врата Рассвета; сборы». Но **кто даёт толчок**, чтобы партия не «просто ушла молча»?

- **Тандил** — город/Разлом; может отпустить с болью («короне нужен король»).  
- **Кавил** — политика Совета, письма, долг короны.  
- **Наблюдатель Леса** (уже в очаге делегаций сессии 1) — знак, что Лес **ждёт**.  
- **Дранник** сам: «мне сказали во сне — совет».  
- Или смесь.

| id | Вариант | Тон сессии 2 |
|---|---|---|
| **c_tandil** | Главный голос — **Тандил** | Долг перед Аэлендором / Элессаром |
| **c_kavil** | **Кавил** / мандат Совета | Политика, бумага, интрига |
| **c_forest** | **Наблюдатель Леса** зовёт | Мистика Леса; мало города |
| **c_drannik** | Толчок от **видения Дранника** (Малфурион) | Природа / совет на первом плане |
| **c_mix_crown** | Тандил/Кавил **+** наблюдатель | Корона + Лес |
| **c_mix_nature** | Дранник/видение **+** Тандил «и король там же» | Обе нити с порога |
| **c_party** | Уходят сами, без сцены «отпуска» | Суше; экономия времени |
| **c_other** | Другое / уточню | |

## D · Орден на дороге в **этой** сессии 2?

**Контекст.**  
Канон маршрута: через зону **Ордена**. Орден сейчас **у стен Сильванора** и режет дороги юга.  
Это может быть:

- главный антагонист вечера (как выброс в Купели),  
- или фон (дым, патруль виден, но не бой),  
- или отложено.

| id | Вариант | За столом |
|---|---|---|
| **d_must** | **Обязательный** узел: обход **или** дипломатия **или** стычка (игроки выбирают) | Как «выброс» у Купели — кульминация дороги |
| **d_optional** | Есть в таблице вставок; можно проехать | Гибко |
| **d_skip_s2** | В с.2 только слухи/дым; узел Ордена = сессия 3+ | Больше места Лесу/Малфуриону |
| **d_other** | Другое / уточню | |

## E · Как Лес встречает (если с.2 доходит до границы / кроны)?

**Контекст.**  
Лесные эльфы ≠ городские Аэлендора. Карточка mq-03 уже намекает: испытание гостеприимства / стражи.  
Плюс: друиды едут на **совет** — к ним могут отнестись иначе, чем к «Героям с мечами».

| id | Вариант | Ощущение |
|---|---|---|
| **e_test** | Сразу **испытание** (корни / охота / гостеприимство) | Жёсткий порог; герои доказывают право |
| **e_guide** | **Проводник** ведёт в поселение; тест позже | Мягкий вход; лор через НПС |
| **e_cold** | Холодный досмотр; «городские» = подозрение | Напряжение; мало тепла |
| **e_warm** | Настороженно-тёплые правила гостя | Культура; можно нарушить |
| **e_druid_gate** | Отдельная ветка: если открыли видение — **друидский** проход проще, «мечникам» — нет | Награда Драннику за лор |
| **e_later** | В с.2 Лес только силуэт/запах; контакт = с.3 | Если клифф = Орден |
| **e_other** | Другое / уточню | |
