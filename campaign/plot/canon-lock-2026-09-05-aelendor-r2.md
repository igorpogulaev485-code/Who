# Канон-лок: опрос Аэлендор (раунд 2)

## Публичная власть после ложного Константина

Простой эльф в **Лунном мосту** (и по королевству) слышит:

> Страной правят **верховные советы** — не один король на троне.

Названные советы (лок, список можно уточнять):

| Совет | Заметка |
|---|---|
| **Совет магов** | уже мелькал в каноне (Сильванор) |
| **Совет рыцарей** | |
| **Совет генералов** | |
| **Совет правительства** | имя может быть уточнено (голос) |
| **Совет старейшин** | |

Это **официальная картинка** для народа и внешней пропаганды. Истинный король **Элессар I** по-прежнему скрыт (r1).

## «Кто главный» для народа

**Единого №1 нет.** Зависит от **касты** слушателя:

- кому-то важнее маги;
- кому-то — военные / генералы;
- и т.д. по касте.

→ В Аэлендоре есть **кастовая оптика власти** (детали каст — к наполнению / уточнению).

## Хостия

Участвует в попытке **раздела Аэлендора** / захвата части земель.  
**В меньшей степени**, чем ядро вторжения (Орден / Долина / Звёздная Пыль), но **участвует** — не только «на бумаге».

Точный участок фронта / какая земля — **уточнить**.

## Три дракона в Чаше Шёпотов

| | |
|---|---|
| Возраст / ранг | **Не** древние; обычные драконы империи |
| Цвета | **чёрный**, **зелёный**, **красный** |
| Имена | нет — продумать |
| Роль | несут **волю Империи Драконьего Хребта**; перевозят **всадников** (драконорождённые / дракониды — уточнить термин) |

Связано с r1: 3 дракона + охрана в Чаше; город формально под Тандилом.
