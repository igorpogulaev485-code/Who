# Опрос — mq-06 тройка: с какого арта стартовать

**Факт:** да, партия **может** начать не с Доспехов.  
Карточка mq-06 уже говорит «порядок свободный»; детально прописан только **акт A (льды)**.  
Лок `d_ice_only` = про вечер **льдов**, не запрет других стартов.

## A · Хаб после похорон (дверь E)

**Контекст.** В с.1 дверь E = «Льды / земля → mq-06». Сейчас звучит как «сразу льды». Нужно ли **меню тройки**?

| id | Вариант |
|---|---|
| **a_menu** | Кавил/Филлер **называет тройку** → партия выбирает первую цель |
| **a_bias_ice** | Меню есть, но Эларион **тянет** на льды (остальные могут переубедить) |
| **a_three_doors** | Три поддвери E1/E2/E3 в меню похорон |
| **a_kavil_pick** | Кавил **назначает** первую цель (Совет) |
| **a_other** | Другое |

## C · Кто держит **Меч разрушений**? *(дыра канона)*

Сейчас только «в Империи Драконьего Хребта».

| id | Вариант |
|---|---|
| **c_vault** | В **трофейной зале / хранилище** столицы Империи |
| **c_garrison** | У **авангарда у Лунного моста** (Кезарр / комендант) |
| **c_general** | У **военачальника** в Хребте (не у моста) |
| **c_cult** | У **культа**/агентов — Хребет ещё не полностью контролирует |
| **c_moving** | **Перевозят** (караван/корабль) — гонка |
| **c_propose** | Предложи 2–3 имени хозяина → выберу |
| **c_other** | Другое |

## D · Клифф с.2 ветки **меча**

| id | Вариант |
|---|---|
| **d_talk_kezarr** | Жёсткий торг с гарнизоном у моста (яйца / доступ / отказ) |
| **d_road_empire** | Выезд в Империю; клифф = ворота / аванпост Хребта |
| **d_vault_sight** | Вид хранилища / залы (меч виден, не взять) |
| **d_agent** | Перехват гонца/агента демонов у меча |
| **d_other** | Другое |
