# Опрос — план демонов: геометрия

**Статус: ждём ответы.** Потом лок → gazetteer из ответов → бриф → отрисовка.

**Уже лок (не переспрашиваю):**
- Эстетика-база: Искажённое Лунное Царство  
- Вход: Купель → ~5 мин → пустошь + **Маяк душ** (site LOCKED)  
- 3 якоря: **Алтарь Крови** · **Серебряный Филактерий** · **Око Затмения** (spine mq-01 ok)

## A · Топология «кругов»

| id | Вариант |
|---|---|
| **a_rings** | Концентрические **кольца** (Маяк на внешнем / входном крае) |
| **a_wedges** | **Клинья** от Маяка вглубь (как сектора) |
| **a_depth** | **Этажи вниз** (глубже = страшнее; «вниз» важнее компаса) |
| **a_wrong_city** | Искажённый **анти-Лунный мост** (узнаваемые «улицы», но чужие) |
| **a_mix** | Смесь: кольца + один «провал» к Оку |
| **a_other** | Другое → заметка |

## B · Где **Маяк** на обзорной карте?

| id | Вариант |
|---|---|
| **b_edge** | На **краю** карты = берег входа из Купели |

| **b_corner** | Угол / «юг» карты; глубина уходит на противоположную сторону |
| **b_other** | Другое |

## C · Три якоря — взаимное положение

Spine намекает: Алтарь ближе → Филактерий глубже → Око в сердце. Подтверди расклад:

| id | Вариант |
|---|---|
| **c_chain** | **Цепь вглубь:** Маяк → Алтарь → (ворота) → Филактерий → Око |
| **c_triangle** | **Треугольник** якорей; путь между ними свободный |
| **c_altar_near** | Алтарь близко к Маяку; Филактерий и Око — два разных «крыла» |
| **c_eye_center** | Око в **центре** карты; Алтарь и Филактерий на периферии |
| **c_other** | Другое / нарисую словами в заметке |

## F · Масштаб «в вечерах» (ориентир для карты)

Сколько **игровых вечеров пути** между крупными узлами? (не реализм км)

| id | Вариант |
|---|---|
| **f_tight** | Плотно: Маяк→Алтарь ≈ **1** вечер; Алтарь→ворота ≈ **1**; ворота→Око зона ≈ **2–3** |
| **f_spine** | Как spine: пустошь+Алтарь **много** вечеров (3–5); Филактерий блок; Око блок — карта «просторная» |
| **f_montage** | На карте **близко**, путь часто **монтаж** между якорями |
| **f_other** | Другое (числа в заметке) |

## G · Что на **player**-карте (слой A)?

| id | Вариант |
|---|---|
| **g_full_anchors** | Подписать все **3 якоря** + Маяк + ворота + крупные биомы |
