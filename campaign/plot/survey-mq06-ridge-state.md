# Опрос — Драконий Хребет (государство → ветка меча)

**Зачем:** без паспорта империи с.2 «пойти за мечом» висит в воздухе.  
**Уже лок:** меч = реликвия в **священном месте**, охрана, не делятся; **портал** (союзники); яйца **не** в этой ветке; с.2 = только скрипт + seed.

**С карты / overview:** юг материка; горы/пепел/вулканы; драконорождённые + …; гарнизон у Лунного моста; сожгли Камнеград; Разлом внутри; ситуационный союз с Аэлендором.

| **e_guard_clash** | Стычка с охраной **на подступах** (без захвата арта) |
