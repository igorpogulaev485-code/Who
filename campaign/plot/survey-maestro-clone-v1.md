## A · Сколько раз душа **переезжала** в готовый двойник? (успешные «смерти→клон»)

**Контекст.**  
Стр. 17 даёт **минимум один** переезд (юность). Фраза «меняю плоть, когда стареет» намекает на повторы — но это может быть риторика / редкие циклы / преувеличение для дневника.

Эльф на службе дворов сотни лет: если сбрасывал возраст каждые ~80–120 лет «для виду», переездов могло быть **много**. Если почти не старел внешне — мог обойтись **единицами**.

| id | Вариант | Смысл для арки |
|---|---|---|
| **a_1** | Только **тот один** (юность) | Проще; «старое тело» на похоронах = последнее |
| **a_few** | **2–4** за жизнь | Редкие кризисы / старение |
| **a_dozen** | **~5–12** (регулярный сброс для двора) | Маэстро = серийный «перезапуск»; сильнее ужас |
| **a_many** | **>12** / почти рутина | Очень тёмный; риск обесценить смерть |
| **a_unknown** | Партия **никогда** не узнает точное число | Мистика; лор только тебе |
| **a_other** | Другое / уточню | |

**Рек. (не лок):** `a_few` — вес есть, без конвейера.

## B · Сколько сосудов он **вырастил** за жизнь? (успешные инертные тела, не считая 3 ранних провала)

**Контекст.**  
По PHB/ттг обычно **один** активный сосуд: пока лежит нетронутый клон, новый — история мастера.  
«Меняю плоть» может значить: старый сосуд **использован** (смерть) → вырастил **новый** про запас.

Провалы юности (3) уже канон — **не** входят в ответ B, если не скажешь иначе.

| id | Вариант | |
|---|---|---|
| **b_1** | Всего **1** успешный сосуд за жизнь (= тот, в который переехал в юности); дальше жил без запаса | Дневник «держу сосуд» = привычка/ложь себе / метафора |
| **b_2** | **2**: юношеский (израсходован) + **один** запасной во взрослой жизни | Чистая загадка «где второй» |
| **b_cycle** | По **одному запасному** на каждый цикл (число ≈ A) | Согласовано с a_few/a_dozen |
| **b_hoard** | Держал **несколько** сосудов сразу (нарушение «обычного» Clone — его личный закон) | Опасный прецедент; несколько крышек |
| **b_other** | Другое | |

**Рек.:** `b_2` или `b_cycle` при `a_few`.

## C · Сколько **готовых** сосудов существует **в момент убийства демонами**?

**Контекст.**  
Это главный рычаг ветки. Варианты радикально разные:

| id | Вариант | Если герои найдут крышку |
|---|---|---|
| **c_0** | **Ноль** — запас исчерпан / не успел вырастить новый / уничтожен до смерти | Крышка пуста или разбита; путь клона **закрыт** → мёртвые / Милана |
| **c_1** | **Ровно один** готовый | Классический хук: нашли — можно рискнуть переездом (если душа свободна) |
| **c_multi** | **>1** | Гонка; фальшивки; кто dig'нет первым |
| **c_growing** | Один **ещё растёт** (<120 дней) — не готов | Таймер; клифф |
| **c_other** | Другое | |

**Рек.:** `c_1` — clearest drama. `c_0` = жестокий твист («искали зря»).

## D · Где сейчас (или был) **актуальный** сосуд?

**Контекст.**  
Стр. 17: первый — под мостом. Дальше он мог: оставить там же / перенести / уничтожить нишу / завести новую.

| id | Вариант | Стол |
|---|---|---|
| **d_bridge** | Всё ещё **ниша под Лунным мостом** (та же или рядом) | Герои копают **дома** — быстро |
| **d_moved_city** | В городе, но **другое** место (Кузница / купель / склеп / шатёр — уточни в заметке) | Расследование в Мосту |
| **d_outside** | **Вне** моста (Лес / льды / другое гос-во) | Отдельная экспедиция |
| **d_destroyed** | Сосуд **уничтожен** (демоны / он сам / Милана / случай) | Ветка = руины + улики |
| **d_unknown_party** | Место знает только лор; герои сначала ищут **улики**, не точку | Медленный burn |
| **d_other** | Другое | |

## G · Душа Маэстро **сейчас** — может ли переехать в клон?

**Контекст.**  
Правило Clone: душа должна быть **свободна и согласна**. Убит демонами + арты ушли в Разлом + хук «план мёртвых» — возможно душа **не** свободна.

| id | Вариант | Эффект ветки |
|---|---|---|
| **g_free** | Свободна и согласится → клон **сработает**, если сосуд цел | Прямое воскрешение телом |
| **g_trapped_demon** | Держат демоны / печать | Нужен Разлом (A) **до** или **вместе** с крышкой |
| **g_dead_plane** | На **плане мёртвых** / с Велианом | Крышка пуста без F |
| **g_split** | Часть здесь / часть там (метафизика) | Оба пути обязательны |
| **g_refuse** | Свободна, но **не согласна** (пока) | Мораль / условие |
| **g_other** | Другое | |

**Рек.:** `g_trapped_demon` или `g_dead_plane` — иначе клон съедает арку слишком рано.
