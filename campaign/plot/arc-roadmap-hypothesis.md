# Куда могут пойти — гипотеза

**Не канон.** Опирается на залоченные вводные; конкретные точки внутри чужих государств и порядок сессий — на вкус мастера / выбор игроков.

Детальное меню маршрутов арки 3 + часы «живого мира»: [`arc3-routes-living-world.md`](arc3-routes-living-world.md).

## Рамка арок (лок мастера)

| Арка | Победа = | Уровень к концу |
|---:|---|---:|
| **3** | Победа над **демонами**, лезущими через Разлом | ~**14** |
| **4** | Победа **Аэлендора на земле** над всеми оставшимися врагами | ~**17** |
| **5** | Победа над **воскресившимся Кардианом** | ~**20** |

Сейчас: **старт арки 3**, Лунный Мост, уровни **8–9**.

---

## Сейчас → развилка (сессии 1–3 арки 3)

Герои в **Лунном Мосту**. Воздух уже задан:

- похороны **Маэстро** (верхний город открыт);
- **дневник** не изучен → воскрешение;
- **Велиан** пропал в Разломе;
- Разлом **расширился**;
- у моста — **авангард Драконьего Хребта**;
- два пути, оба ок: **Лес Хранителей** / **Разлом**.

### Гипотеза «сначала король, потом Бездна»

1. Похороны / дневник / разговор с **Тандилом** и, возможно, **Филлером** (через канал Кавила).
2. Короткий выход на **юг** → **Хранитель пик** → **Лес Хранителей** → аудиенция у **Элессара I**.
3. Король даёт *легитимность* и политический крюк (Аэлендор без маски Константина), но главная угроза всё равно **демоны** → возвращает партию к Разлому Лунного моста.
4. Вход в Разлом (по следам Велиана / артефактов / плана мёртвых / дочери Маэстро).

### Гипотеза «сразу в Разлом»

Похороны → дневник → прыжок вслед за Велианом. Элессара встречают позже (середина/конец арки 3 или старт 4) — как *возвращение с трофеями из Бездны*.

Обе рабочие. Лес не отменяет арку демонов — он её **обрамляет**.

## Арка 3 — демоны через Разлом (~8/9 → 14)

**Жанр:** выживание, саботаж, исследование «искажённого» плана. Не полномасштабная война государств.

### География угрозы

Пять активных Разломов = пять «кранов», из которых лезут демоны:

| Разлом | Государство | Зачем партии туда |
|---|---|---|
| **Лунный мост** | Аэлендор | Главный вход; 3 артефакта у демонов; Велиан |
| Ледяной Союз | север | Второй фронт + **доспехи смерти** (фон/крюк) |
| Звёздная Пыль | СВ / острова | Враг + **сапоги покрова** |
| Драконий Хребет | юг/горы | «Союзник» с гарнизоном у моста + **меч разрушений** |
| Хостия | пустыня | Другой биом; чистое знакомство с миром |

### Гипотетический путь внутри арки

**Фаза A — Лунный Разлом (ядро)**  
Вход у моста → поиск Велиана / лагеря демонов → контакт с 3 артефактами (**маска, кинжал, медальон**). Уничтожение/порча/кража — «как пойдёт». Победа здесь = демоны перестают *бесконечно* литься через главный разрыв Аэлендора.

**Фаза B — чужие Разломы (выбор, не чек-лист)**  
Партия не обязана закрыть все пять в арке 3. Логичные «выезды» из Лунного Разлома:

- **Хребет** — потому что гарнизон уже у дома; дипломатия на грани войны после Камнеграда.
- **Звёздная Пыль** — потому что предатели; Разлом там = моральный и военный удар.
- **Ледяной Союз** — Зеркало Завесы + доспехи; lore-heavy.
- **Хостия** — если нужно «воздух» и экзотика между тяжёлыми актами.

**Фаза C — финал арки 3**  
Крупная победа над демоническим командованием / якорями вторжения. Разломы ещё **не все закрыты** (это топливо арки 4–5), но *напор демонов сломан*. Выход ~14 ур.

**Параллельные нити, которые можно вшить без смены жанра:**

- дневник / план мёртвых / дочь → шанс вернуть Маэстро (или понять цену);
- яйца в Кузнице Фиалки — тикающий фон, не обязательный данжен;
- Кавил и Теневой Совет — короткие «столичные» вставки между вылазками.

## Арка 4 — победа Аэлендора на земле (~14 → 17)

**Жанр:** контрнаступление, дипломатия, многофронтовая война. Демоны уже не главные — **государства**.

### Карта врагов после Стража

| Фронт | Состояние | Куда пойдут герои |
|---|---|---|
| **Орден пламенеющей стали** | у стен **Сильванора** | Снятие осады столицы — главный «земной» босс-акт |
| **Теневая Долина** | отрезана в глубине | Зачистка / пленение группировки внутри Аэлендора |
| **Тёмные леса** | атташе, перемирие | Дипломатия (не обязательно бой) |
| **Звёздная Пыль** | предатели | Рейд / морской поход / Разлом там |
| **Драконий Хребет** | «союз» на лезвии | Камнеград, яйца, меч; решить: союзник или следующий враг |
| **Хостия / прочие** | фон | По желанию партии |

### Гипотетический порядок

1. **Сильванор** — снять Орден (символ «Аэлендор жив»).
2. **Внутренняя зачистка** — отрезанная Долина; возврат провинций (Розалия и др. — если игроки захотят закрыть старый долг).
3. **Внешние удары** — Звёздная Пыль и/или Хребет; мирские артефакты Кардиана всплывают как военные трофеи / приманки.
4. **Элессар на троне** (если ещё не был) — финальный политический аккорд арки: королевство снова одно.

К концу арки 4: враги Аэлендора на земле повержены; Разломы частично стабилизированы; **артефакты** собраны/уничтожены достаточно, чтобы ритуал воскрешения Кардиана стал неизбежен (или уже запущен). ~17 ур.

## Арка 5 — воскресившийся Кардиан (~17 → 20)

**Жанр:** личный антагонист, эсхатология, закрытие лора.

### Откуда он встаёт (гипотезы, выбрать одну)

- энергия уничтоженных якорей / собранных шести предметов;
- ритуал через **Мёртвый город** (уже посещён — «вернуться туда другим»);
- тело/имя, связанное с Маэстро (друг) или с ложным Константином / королевской линией.

### Куда пойдут герои

1. След воскрешения (Мёртвый город / Разлом / место первого ритуала).
2. Сбор последних якорей или наоборот — *осознанный* отказ их трогать.
3. Финальная арена: не поле государства, а **личная война** с некромантом, который когда-то был другом Маэстро.
4. Победа = конец кампании. ~20 ур.

## Сквозной «коридор» на карте мира

Упрощённая линия, если партия не будет сильно петлять:

```
Лунный Мост
  ├─(коротко)→ Лес Хранителей (Элессар)
  └─→ Разлом Лунного моста  ──арка 3──►
        ├─ вылазки: Хребет / Звёздная Пыль / Льды / Хостия
        └─ выход ослабленными демонами
              └─→ Сильванор (Орден) ──арка 4──►
                    ├─ зачистка Долины внутри Аэлендора
                    ├─ удар по предателям / «союзнику»
                    └─ мирские артефакты Кардиана
                          └─→ Мёртвый город / ритуал ──арка 5──► Кардиан
```

---

## Что сознательно не фиксируем

- Обязательный порядок пяти Разломов.
- Уничтожат ли 3 демонических артефакта именно в арке 3.
- Вернётся ли Маэстро живым.
- Станет ли Хребет врагом №1 в арке 4 или останется союзником до финала.

Это развилки для игроков; дорожная карта выше — только **куда логично смотреть**, не «обязательный тур».
