# Канон: Разлом — переход

## Куда ведёт

Разлом ведёт на **два плана**:

1. **План демонов**  
2. **План мёртвых**

По умолчанию поток **хаотичен** (свой путь Разлома).  
**Магия Аэлендора** умеет **направить** переход на нужный план.

Каждый план = **единое «государство»-устройство** (не россыпь стран): города, устои, быт. Дробить на несколько государств **не** нужно. Собирать через skill `form-state` (режим Planar / Full).

## Ощущение входа

При входе — **магическая волна**, быстрое перемещение.  
Всё насквозь пропитано магией: **не добрая и не злая** — просто магия. Чувствуется явно, даже если переход занимает мгновения.

## Уничтожение артефактов Кардиана

Шесть «Артефактов Падения» **можно уничтожить только в Разломе**.  
Маэстро хотел отправить их туда для уничтожения; демоны унесли три раньше.  

**Как и где именно** (какой план / место / ритуал) — **к разработке** вместе с планами.

## Связанное уже в каноне

- Три в Разломе у демонов: **маска знаний**, **кинжал души**, **медальон призыва**  
- Три в мире: доспехи смерти (Ледяной Союз), меч разрушений (Хребет), сапоги покрова (Звёздная Пыль)  
- Второй шанс воскресить **Маэстро** — на **плане мёртвых**  
- Арка 3: победа над демонами через Разлом; арка 5: воскресший Кардиан
