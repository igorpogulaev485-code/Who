# Лок: хвосты воскрешения

```
A=a_ally_tense B=b_casters(+info hunt) C=Kuzad-Dum
D=one-winner E=Amirat desert temple ~s.15 F=f_lock
```

| id | Решение |
|---|---|
| **A** `a_ally_tense` | Союз с трением: Милана может помогать уликам, но **не** идёт путём сосудов / в Амират как свой план |
| **B** | Её трек = поиск **кто поможет** (великие заклинатели / боги через информантов). Сначала **собирает информацию**, не финальный ритуал |
| **C** | **Растущий** сосуд спрятан в **Кузад-Думе** (гос-во некромантии/чёрной магии; не «зло ради зла», но чужие боятся; даже драконы сторонятся → Маэстро счёл безопасным) |
| **D** | Побеждает **один** путь. Милана раньше → Маэстро жив, **сосуд сохраняется**. Сосуд раньше → Милана **останавливает** свой путь (отец уже жив) |
| **E** | Готовый сосуд: **храм в пустыне Амирата** (люди-раса). Ловушки, долгий путь, расследование. До храма ~**сессия 15** арки (не раньше) |
| **F** `f_lock` | Портрет Маэстро + интерьер шатра = **канон-внешность** |

## Сводка сосудов (обновление)

| Сосуд | Где | Статус |
|---|---|---|
| Готовый | Храм в пустыне **Амирата** | цель позднего R (~с.15) |
| Растущий | **Кузад-Дум** | таймер; отдельная нить/угроза/приз |

Ниша под Лунным мостом — история первого клона / улики, не актуальный готовый.
