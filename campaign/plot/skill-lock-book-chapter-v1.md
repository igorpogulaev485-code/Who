# Лок: решения для `echo-dawn-book-chapter`

Источник: ответы мастера на [`skill-survey-book-chapter-v1.html`](skill-survey-book-chapter-v1.html) (2026-09-05).

| id | Решение |
|---|---|
| A1 | Обхват = главы книг игроков **+ мастерские кодексы / скрытый лор** (не для игроков) |
| A2 | Закрытые главы (без «Вы изучили…») — **не канон**; только **prep/черновик по запросу** |
| B1 | Файлы: **отдельная папка на книгу** `world/player-books/<book>/chapters/…` |
| B2 | Скил пишет **в репо**; Telegraph — **мастер руками** |
| B3 | **md + docx**, как у других скилов |
| C1 | **Свой голос на книгу** (Зеркало ≠ Флора ≠ Драконы) — зафиксировать в скиле |
| C2 | Стандарт: **meta** (книга/номер/статус/telegra) + **текст** + **якоря канона** + **игрок vs мастер** |
| C3 | Длина — **как в этой книге** (смотреть соседние главы) |
| D1 | «Открыть» = канон: файл + индекс «изучено» + (когда готово) ссылка Telegraph |
| D2 | После главы — **чеклист** разноса в CANON / локации / NPC / артефакты / таймлайн |
| D3 | Qwen можно брать и **сильно править** |
| E1 | Изучение за столом: партия **тратит время** на прочтение |
| E2 | Антипаттерн: **generic-фэнтези** без голоса мира / имён канона |
