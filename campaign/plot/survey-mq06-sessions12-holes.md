# Опрос mq-06 — дверь E · льды

**Путь:** после похорон → дверь **E** · сессия 2 = закрепление на линии **Ледяной Союз / Лианэя / Доспехи** (не вся тройка mq-06 за вечер).  
**Параллель:** A → Маяк · F → Причал · D → Порог. Льдам нужен свой «первый берег».

HTML: [`survey-mq06-sessions12-holes.html`](survey-mq06-sessions12-holes.html)

## A · Где клифф сессии 2?

**Контекст.**  
До Лианэи лицом к лицу = моральный ядерный узел Элариона. Если впихнуть его в с.2 — как «Элессар в первый вечер Леса». Обычно с.2 = **закрепиться** у края льдов.

| id | Вариант | Смысл |
|---|---|---|
| **a_hub** | Только **хаб** в Лунном мосту (акт 0): Кавил/Брорр/карта охоты; выезд = клифф | Мало льда; безопасно |
| **a_road_north** | Дорога/порт на север + первый холод; льды на горизонте | Тревел-вечер |
| **a_brorr_camp** | Лагерь/форт **дварфов** у линии тумана (Брорр или его родня) | Аналог Маяка: база союзников |
| **a_army_sight** | Вид **армии мёртвых** на равнине (без диалога с Лианэей) | Сильный кадр видения |
| **a_call** | Голос/силуэт в доспехах зовёт Элариона — **без** полного разговора | Личный крюк; остальным — туман |
| **a_meet** | **Встреча** с Лианэей в ту же сессию | Ядерный узел рано |
| **a_other** | Другое / уточню | |
