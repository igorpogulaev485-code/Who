# Опрос mq-06 v2 — дверь E · льды (с контекстом)

**Путь:** похороны (с.1) → дверь **E** → сессия 2 на линии **Ледяной Союз / Лианэя / Доспехи смерти**.  
**Метод:** как A/F/D — с.2 = **закрепиться**, не финал mq-06.  
**Канон уже есть:** видение Элариона; Брорр в очаге порта с.1; L1+L2 (Доспехи = антенна Кардиана, он причастен к воскрешению — **не** спойлерить игрокам в с.2 без нужды).

## Зачем эти вопросы

У других дверей сессия 2 закончилась так:

| Дверь | Клифф с.2 | Финал направления |
|---|---|---|
| **A** | Маяк душ + Сарель | Алтарь / Око / … |
| **F** | Серый Причал + Лайра | Велиан ~с.6 |
| **D** | Храм Серебряного Порога → пути Силвания/Малфурион | Элессар ~с.10 |
| **E** | ??? ← выбираем | Лианэя / Доспехи / тройка земных артов |

Во льдах **две** силы тянут в разные стороны уже с порога:

1. **Личная** — Эларион и зов сестры («иди ко мне»).  
2. **Арка** — Кавил/Совет: не дать демонам **Доспехи смерти** (и позже меч/сапоги).

Плюс на равнине уже **дварфы** держат линию против тумана (слух Брорра) — это готовый «Маяк» союзников.

Вопросы A–I решают: *куда упирается вечер*, *как едем*, *чей заказ*, *сколько mq-06 открываем*, *что знает стол про сестру*, *нужен ли бой*, *сколько пишем*, *что тикает дома*, *нужен ли playbook*.

## A · Где клифф сессии 2?

**Контекст.**  
Видение Элариона уже дало кадр: ледяная равнина, легионы мёртвых, **дварфы напротив**, сестра в Доспехах, зов.  
Но «дойти до Лианэи лицом к лицу» в с.2 = как впихнуть **Элессара** в первый вечер Леса: ядерный моральный узел слишком рано, мало места на дорогу и базу.

Параллель:

- A не заканчивается на Алтаре — на **Маяке**.  
- F не находит Велиана — на **Причале**.  
- D не видит короля — на **Пороге**.

| id | Вариант | Что за столом | Плюс | Риск |
|---|---|---|---|---|
| **a_hub** | Только **хаб** Лунного моста (акт 0): Кавил / Брорр / карта охоты; клифф = «выходим на рассвете» | Соц + сборы; льда почти нет | Быстро; безопасно | Слабо «пошли во льды» |
| **a_road_north** | Дорога/порт + первый мороз; льды = дымка на горизонте | Тревел + атмосфера | Почувствовать север | Мало базы |
| **a_brorr_camp** | **Лагерь/форт дварфов** у линии тумана | База союзников, слухи, карта фронта | Лучший аналог Маяка/Причала | Лианэя ещё далеко |
| **a_army_sight** | Вид **армии мёртвых** на равнине (без диалога) | Кадр из видения «вживую» | Сильный вау | Может спровоцировать «бежим к ней» |
| **a_call** | Голос/силуэт в Доспехах зовёт **только** Элариона; остальным — туман/давление | Личный крюк без полного NPC | Эмоция Элариона | Остальные сидят зрителями |
| **a_meet** | **Встреча** с Лианэей в ту же сессию | Переговоры/угроза/объятие-ловушка | Ядерный узел | Съедает арку рано; спойлеры L1+L2 |
| **a_other** | Другое / уточню | | | |

**Рекомендация prep (не лок):** `a_brorr_camp` или `a_army_sight` (± короткий `a_call` для Элариона).

## B · Как сжимаем дорогу на север?

**Контекст.**  
Ледяной Союз = **крайний СЗ** материка. Из Лунного моста это не «за угол».  
Игровое время ≠ экранное: монтаж может сжечь неделю календаря (часы Разлома/Ордена тикают сильнее); один день пути почти не двигает мир.

Уже в с.1 заготовлен крюк **Брорра** (дварф-купец со льдов) — удобный проводник/корабль/караван, если хочешь.

| id | Вариант | Пример вечера | Влияние на часы дома |
|---|---|---|---|
| **b_montage** | **Монтаж дней** + 1–2 ярких узла | «Неделя на север» абзацем → лагерь/стычка | Сильно двигает календарь |
| **b_ship** | **Корабль/река** → северный порт / перевал ко льдам | Порт моста → борт → холодный причал | Средне; морской тон |
| **b_road** | **Сухопутный** путь через север Аэлендора | Заставы, беженцы, слухи | Много вставок; медленнее |
| **b_portal** | **Портал/магия** (редкий shortcut) | Цена: компонент, долг магам, риск | Мало дней, но «дёшево» ощущается |
| **b_mix** | Сборы в хабе + монтаж + высадка у дварфов | Как D: город → прыжок/дорога → база | Баланс |
| **b_other** | Другое / уточню | | |

## C · Кто «открывает» дверь E после похорон?

**Контекст.**  
В с.1 дверь E уже в меню: «Кавил / Тандил / Брорр → mq-06». Но **чей голос** делает выезд неизбежным?

| Голос | Что несёт |
|---|---|
| **Эларион** | Видение уже у игрока: «Брат, иди ко мне». Личная миссия; партия может ехать «ради него». |
| **Брорр** | Фронт дварфов: «мёртвые строем», щиты против тумана. Война/союз, не обязательно «сестра». |
| **Кавил** | Заказ Совета: Доспехи смерти на земле — не дать демонам. Политика артов mq-06. |
| **Тандил** | Может отпустить с болью («город горит, но…») — реже главный толчок на север. |

| id | Вариант | Тон сессии 2 |
|---|---|---|
| **c_elarion** | Главный толчок — **Эларион** / видение | Драма семьи |
| **c_brorr** | **Брорр** зовёт помочь линии | Война со льдом |
| **c_kavil** | **Кавил** выдаёт охоту на Доспехи | Шпионский / артовый |
| **c_mix_personal** | Эларион **+** Брорр | Семья + фронт (часто лучший микс) |
| **c_mix_order** | Кавил **+** Эларион | Арт + сестра в одном брифе |
| **c_tandil_ok** | Тандил «отпускает» + любой из выше | Долг городу закрыт устно |
| **c_party** | Уходят сами, без сцены отпуска | Экономия времени; суше |
| **c_other** | Другое / уточню | |

## D · Сколько mq-06 открываем в **этой** сессии 2?

**Контекст.**  
mq-06 = **три** цели: Доспехи (льды) · меч (Хребет) · сапоги (Звёздная Пыль).  
Сессия 2 не обязана показывать всю карту охоты — но Кавил любит «меню», а Эларион тянет **только** на сестру.

| id | Вариант | За столом | Плюс / риск |
|---|---|---|---|
| **d_ice_only** | Только **льды / акт A** | Фокус: линия тумана, Доспехи, Лианэя-как-горизонт | Чисто; меч/сапоги потом |
| **d_menu** | В хабе **тройку** назвали (льды/меч/сапоги), потом едем во льды | Игроки видят масштаб mq-06 | Может размыть «пошли во льды» |
| **d_ice_plus_hint** | Льды + **один** намёк (письмо/слух) про меч **или** сапоги | Живой мир без второй страны | Лёгкий крючок |
| **d_other** | Другое / уточню | | |

**Рекомендация prep:** `d_ice_only` или `d_ice_plus_hint`.

## E · Что знает **партия** про «сестру» к концу с.2?

**Контекст.**  
Видение отправлено **игроку Элариона**. Остальные за столом могут думать, что едут «бить нежить / за арт / помочь дварфам».  
От этого зависит тон сцен: личная драма vs военная операция.

L1+L2 (Кардиан / антенна Доспехов) в с.2 **не** обязаны всплывать — максимум эхо холода/серой пыли без имени.

| id | Вариант | Ощущение |
|---|---|---|
| **e_private** | Тайна Элариона (пока сам не сказал) | Интрига; он может врать партии |
| **e_party_soft** | Он **уже рассказал** до/в с.2: «сестра во льдах» | Вся партия в теме; меньше тайн |
| **e_reveal_scene** | Раскрытие **сценой** (зов, имя, «не живая/не мёртвая») | Сильный бит вечера |
| **e_dwarves_lady** | Дварфы зовут её **«Леди Льда»**; родство — только если Эларион раскроет | Военный фольклор |
| **e_other** | Другое / уточню | |

## F · Бой / давление в с.2?

**Контекст.**  
A имеет выброс у Купели. F — undead при открытии чёрного. D — шпионы Ордена.  
Льдам нужен свой «зуб»: разведка тумана, вурдалаки, культисты, обстрел с равнины — или ужас без большого CR.

| id | Вариант | Когда уместно |
|---|---|---|
| **f_skirmish** | **Обязательная** стычка (разведка мёртвых / стык у линии) | Если клифф = лагерь/армия |
| **f_optional** | Бой в таблице вставок; можно проехать | Гибко |
| **f_social** | Социал + ужас (лагерь, пленные, ритуал на горизонте) — без большого боя | Если клифф = хаб/разговоры |
| **f_setpiece** | Одна **сетаповая** сцена (не обязательно lethal): спасти дозор / закрыть прорыв | Киношность |
| **f_other** | Другое / уточню | |
