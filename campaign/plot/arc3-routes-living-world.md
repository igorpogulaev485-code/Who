## 3. Живой мир: часы фронтов

Пока партия пьёт в «У Последней Завесы», нижеописанное **всё равно происходит**.  
Мастер двигает 1–2 фронта между сессиями (или в конце сессии «новостями»).

Шкала условная: **шаг** = примерно 1 сессия / несколько игровых дней.  
Не нужно отыгрывать всё — достаточно 1–2 последствий, которые партия *узнает*.

### Часы арки 3

| Часы | Если партия **не** вмешивается | Если вмешивается |
|---|---|---|
| **Демоны / Лунный Разлом** | Разлом расширяется; вылазки в нижний город; жертвы; слухи о «втором Люмиэле» | C/D — тормозят или откатывают |
| **Велиан** | Отряд гибнет / дезертирует / возвращается искажённым / приносит ложные вести | J — шанс спасти или узнать правду раньше |
| **Орден у Сильванора** | Стены трещат → квартал пал → угроза падения столицы | B — снимает давление (частично) |
| **Теневая Долина (отрезанные)** | Голод → мародёрство → сдача / резня / партизанщина в тылу | H — контрнаступление чище / быстрее |
| **Тёмные леса** | Атташе заключают перемирие **без** партии (условия хуже) **или** срыв → новый фронт | K — выгоднее / честнее / подло |
| **Драконий Хребет у моста** | Комендантский час → реквизиции → ультиматум по яйцам/героям → стычка | L/M — дипломатия или бой |
| **Камнеград** | Месяц без оружия → затяжная война; дварфы копят долг ненависти к Хребту | M — ускоряет восстановление / месть |
| **Чужие Разломы** | В каждом государстве свой кризис; беженцы доходят до Аэлендора | G/E — локальный выигрыш, не пауза всех часов |
| **Артефакты Кардиана** | Демоны *используют* тройку; на земле артефакты меняют хозяев / культы | D/E — контроль или уничтожение |
| **Дочь Маэстро / дневник** | Дочь действует сама; дневник могут украсть / вскрыть NPC | I/Q — партия в центре нити |
| **Элессар I** | Король выходит на сцену **без** партии (манифест / армия Леса) — или остаётся в тени слишком долго | A — партия «коронует» момент |
| **Звёздная Пыль** | Предатели закрепляют морские пути; Разлом там кормит флот демонами-метафорой | E/G/S — диверсия |
| **Филлер / Совет** | Политика столицы без Героев: назначения, казни «предателей», ошибочные приказы | P — Кавил влияет |

### Правило таверны

Если партия **N сессий подряд** не трогает ключевые часы:

1. Мир всё равно делает **N шагов** по 2–3 самым горячим часам.  
2. Партия получает это как **слух / глашатай / письмо Филлера / беженец / пожар за окном**.  
3. Ключевые квесты **не пропадают** — они **ухудшаются или меняют форму** (Велиана уже не спасти живым; столица просит эвакуации, не обороны; артефакт уже у другого хозяина).

Прелесть: сидеть в таверне — тоже выбор с ценой. Мир не ждёт «правильного» квеста.

## 4. Как это стыкуется с победой арки 3

Победа арки = **демоны через Разлом** побеждены / напор сломан (~14).

Значит:
- Маршруты **C, D, G** — прямые к победе арки.
- **A, B, H, E, F…** — валидны, но пока партия там, **часы демонов тикают**.
- Можно выиграть арку 3, почти не ходя в Лес/Долину — тогда король и война приедут *к ним* последствиями.
- Можно почти не лезть в Разлом — тогда к ~14 ур. арка может **формально не закрыться**, а мир станет хуже (Разлом ест Лунный мост) → жёсткий старт «догоняющей» фазы или перенос цены в арку 4.

Мастер не форсит один путь. Мастер **двигает часы**.

## 5. Минимальный prep под живой мир

На каждую сессию достаточно заготовить:

1. **Где партия** (из меню A–T).  
2. **1 местный конфликт** на месте.  
3. **1 новость с другого фронта** (шаг часов).  
4. **1 дверь дальше** (не рельс — опция).

Этого хватает, чтобы мир ощущался живым без прописанных 16 сессий заранее.
