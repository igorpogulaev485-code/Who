# Хронология кампании

Относительная шкала: **T0** = прибытие героев в Лунный Мост перед Фестивалем «Сияние Нового Рассвета».

## Арка 1 — знакомство с миром

| Когда | Событие |
|---|---|
| T0 | Подготовка к фестивалю; герои у Маэстро Келебрима |
| Сессии 1–2 | Квесты в Лунном Мосту; улики культа Лолс / Дома Вандерли |
| Сессия 3 | Убийство Люмиэля; пробуждение Разлома; хаос |
| Сессия 4–5 | Веларис; Пиппин (свидетель поджогов → амнезия → позже предатель → **убит**); временная печать у Лунного Оврага |
| Сессия 6 | Битва за Лунный Овраг; смерть Тиары; «Константин III» (адъютант-маска) на сцене |
| Конец арки 1 | Разлом открыт; Теневая Долина нападает на Аэлендор |

## Арка 2 — спасение Аэлендора

| Когда | Событие |
|---|---|
| Ранняя 2 арка | Герои у **Серебряного Стража** (визит 1); позже из‑за Разлома Страж **пал** |
| Дипломатия / 5 столиц | Путь к **Звёздной Пыли** через **Розалию**; до столицы **не дошли** — Розалия в осаде → разворот → **Лунный Мост** через **Камнеград**. Ложный Константин ещё «на троне» (послы / снятие обвинений) |
| Разоблачение маски | Ложный Константин снят **во время/после дипломатии, до** освобождения Стража |
| Звёздная Пыль | Были союзниками → **предали** Аэлендор (причина партии неизвестна) → Хребет стал ситуационным союзником |
| Камнеград (до Стража) | Квесты, турнир, выборы, свадьба **Невила** и др. — **канон**. Яйца; позже уход мимо дракона |
| Кеша | Раскрыт как вампир и **убит**; Грок забрал **кольцо зелёного дракона**. Ранее Кеша убил **Багала** |
| Яйца | **Зелёное** — Дранник, **синее** — Вирра; спрятаны в приюте/кузне (потайной пол) |
| Артефакты Кардиана | В Камнеграде Грок передал Маэстро **3**: кинжал, медальон, **маска** → у демонов в Разломе |
| Финал арки 2 | Герои **вернули Серебряный Страж** (визит 2 / освобождение). **+2 ур.**, 7 very rare; титулы **Герои Серебряного Стража** + **Герои Аэлендора**; Кавил → Теневой Совет Адъютантов |

## Последняя сыгранная сессия (стык 2→3)

- В **Камнеграде** — **3 дракона авангарда** → город сожжён; производство оружия ~**месяц** на восстановление (глашатай).  
- В **Лунном Мосту** демоны **убили Маэстро**; похороны через 2 дня (верхний город открыт гражданам). Мэр военного времени — **Тандил**.  
- **Велиан** + отряд ушли **в Разлом** («операция отмщения») — статус неизвестен.  
- У Лунного моста — **гарнизон авангарда Драконьего Хребта**.  
- Ложный Константин мёртв → Элессар I.

## Сейчас (решение игроков)

Герои в **Лунном Мосту**. Мастер готовит **оба** пути:

1. **Лес Хранителей** (государство ЮВ; Элессар I)  
2. **Разлом** — артефакты у демонов; дневник Маэстро / план мёртвых / **Марин**

**5 активных Разломов:** Лунный мост · Ледяной Союз · Звёздная Пыль · Драконий Хребет · Хостия.
