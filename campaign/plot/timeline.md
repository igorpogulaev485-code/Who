# Хронология кампании

Относительная шкала: **T0** = прибытие героев в Лунный Мост перед Фестивалем «Сияние Нового Рассвета».

## Арка 1 — знакомство с миром

| Когда | Событие |
|---|---|
| T0 | Подготовка к фестивалю; герои у Маэстро Келебрима |
| Сессии 1–2 | Квесты в Лунном Мосту; улики культа Лолс / Дома Вандерли |
| Сессия 3 | Убийство Люмиэля; пробуждение Разлома; хаос |
| Сессия 4–5 | Веларис; Пиппин (позже раскрыт как предатель и **убит**); временная печать у Лунного Оврага |
| Сессия 6 | Битва за Лунный Овраг; смерть Тиары; «Константин III» на сцене |
| Конец арки 1 | Разлом открыт; Теневая Долина нападает на Аэлендор |

## Арка 2 — спасение Аэлендора

| Когда | Событие |
|---|---|
| Ранняя 2 арка | Герои защищали **Серебряный Страж**; позже из‑за Разлома он **пал** |
| Дорога / Розалия | Партия **не пошла** на осаду Розалии (выбор игроков). Осаду начала Теневая Долина; затем **Империя Звёздной Пыли предала** Аэлендор и присоединилась. Это подтолкнуло **Империю Драконьего Хребта** стать ситуационным союзником Аэлендора |
| Камнеград | Много квестов выполнено; герои ушли, **прошли мимо** дракона у города; сохранили себе **2 драконьих яйца**. Позже вернулись по другому квесту |
| Кеша | Раскрыт как вампир и **убит**; Грок забрал **кольцо зелёного дракона**. Ранее Кеша убил **Багала** (скрытый антагонист, конкурент) |
| Яйца | **Зелёное** — Дранник, **синее** — Вирра; оба спрятаны в приюте (Кузница Фиалки) |
| Артефакты Кардиана | В Камнеграде Грок передал Маэстро **3**: кинжал, медальон, **маска** → у демонов в Разломе |
| Финал арки 2 | Герои **вернули Серебряный Страж**; мир сдвинулся (см. player-briefs). **+2 ур.**, 7 very rare, титул **Герои Аэлендора**; Кавил → Теневой Совет Адъютантов |

## Последняя сыгранная сессия (стык 2→3)

- В **Камнеграде** — **3 дракона авангарда** → город сожжён; производство оружия ~**месяц** на восстановление (глашатай).  
- В **Лунном Мосту** демоны **убили Маэстро**; похороны через 2 дня (верхний город открыт гражданам). Мэр военного времени — **Тандил**.  
- **Велиан** + отряд ушли **в Разлом** («операция отмщения») — статус неизвестен.  
- У Лунного моста — **гарнизон авангарда Драконьего Хребта**.  
- Ложный Константин мёртв → Элессар I.

Сводка игрокам: [`../sessions/player-briefs-silver-guard-and-herald.md`](../sessions/player-briefs-silver-guard-and-herald.md)

## Арка 3 — сыграно (с.1–2, склеенно)

| Когда | Событие |
|---|---|
| с.1 | Похороны Маэстро; центральная поминальная часть. **Вирра** и **Дранник** остались в приюте (офф-стол) |
| с.1–2 | Камень портала украден Орденом (стража-подделка → склады → корабль); партия вернула камень с помощью городской стражи |
| с.2 | Переход в **Храм Серебряного Порога**. Балтан + **Саэла Троповед** (камень планов / план фей). **Плач звезды** пойман на краже → арест группы → суд |
| Итог суда | Штраф **3000 зм** (+ арты по мин. цене, список не фиксирован). Плач → **Разлом в Лесу Хранителей** (искупление / разведка). Грок отдал Лесу **кольцо зелёного дракона**; Балтан подарил Саэле **Звездострел**. Камень планов вернули Саэле |
| Репутация | **Балтан · Грок · Кавил · Эларион**: с жителями Леса **−4** |

## Сейчас

- **Балтан · Грок · Кавил · Эларион** — у **Храма Серебряного Порога** (отпущены после суда).  
- **Плач звезды** — в **Разломе Леса Хранителей** (миссия искупления).  
- **Вирра · Дранник** — в **приюте** Лунного моста (чем заняты — открыто).  
- mq-03: на Пороге; вилка Силвания / Малфурион ещё впереди; репутация Леса −4 давит на социал.  
- **Тик после с.1–2:** реликвия драконов у Леса (→ столица); ячейка Ордена в Лунном мосту уничтожена; Аэлендор вытесняет врагов (размыто); Разломы набирают силу; друиды съезжаются; монастырь в Пепельном Рубеже разграблен (слух); у Порога **чернеет земля / некромантия** — ищут героев. Сводка: [`../sessions/player-briefs-forest-tick-after-s1s2.md`](../sessions/player-briefs-forest-tick-after-s1s2.md).  
- **Книги:** партия прочитала **16 глав** (список — позже).

**Цели арок 3–5:** демоны через Разлом (~14) → победа Аэлендора на земле (~17) → воскресившийся Кардиан (~20).  
Гипотетический маршрут: [`arc-roadmap-hypothesis.md`](arc-roadmap-hypothesis.md)

**5 активных Разломов:** Лунный мост · Ледяной Союз · Звёздная Пыль · Драконий Хребет · Хостия · **(+ локальный Разлом в Лесу Хранителей — путь Плача; уточнять связь с пятёркой)**.
