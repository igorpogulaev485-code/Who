# Лок: C ≠ R

| Дверь | Путь | Метод |
|---|---|---|
| **C · Милана** | Дочь воскрешает отца | **Боги** + **великие заклинатели** — **не** сосуды Двойника |
| **R · Крышка** | Партия (и/или мир) по следу дневника | **Сосуд** в храме пустыни **Амирата** (~с.15) + душа свободна от **демонов** |

Принципиальная разница: Милана **отказывается** (или принципиально не идёт) путём клонов отца. Её дверь = иной теологический/ритуальный трек.

## Стык (хвосты)

| | |
|---|---|
| **Союз** | `a_ally_tense` — помогает уликам, **не** идёт в Амират своим планом |
| **Её трек сейчас** | `b_casters` — сначала **собирает информацию**, кто может помочь (имена/дворы — позже) |
| **Победа** | **Один** путь: кто успел раньше — второй сходит (Милана раньше → сосуд **сохраняется**; сосуд раньше → она **останавливается**) |
