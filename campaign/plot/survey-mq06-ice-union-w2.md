# Опрос mq-06 w2 — Ледяной Союз (государство + карта)

**Уже лок (волна 1):** столица **Гирмхельм** · эскорт из Туманного Щита · нанимает **тан** · доска 4–6 миссий (микс) · улица+заказ · Лианэя ~с.6 на **поле боя** · оффер зла = выбор партии · при отказе давление на Элариона.

**Зачем эта волна:** паспорт Союза + **карта государства** (как у Леса Хранителей) — без этого город и доска висят в воздухе.

## A · Что значит «Союз» по власти?

**Контекст.**  
Нанимает **тан** (лок), но в five-capitals — **Фростара Безмолвная** / Храм Ледяного Сердца. Нужно, кто реально правит Гирмхельмом.

| id | Вариант |
|---|---|
| **a_thane_king** | Тан = **светский глава** Союза; жречество — культ/совет |
| **a_dual** | **Двоевластие**: тан (война/город) + Фростара (сакрал/Завеса) |
| **a_frostar_top** | Фростара выше; тан — главнокомандующий фронта (нанимает партию от её имени) |
| **a_clan_fed** | Федерация **кланов**; тан Гирмхельма = «первый среди равных» на время войны |
| **a_other** | Другое / уточню |
