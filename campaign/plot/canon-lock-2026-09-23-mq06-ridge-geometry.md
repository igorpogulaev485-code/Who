# Лок — силуэт Империи Драконьего Хребта

Слова мастера (после v6):

| | |
|---|---|
| Форма | **Полуостров**, не остров |
| Запад | Примыкает к материку **через горы**; граница с **Амиратом** |
| Северо-восток | Есть **маленькая полоска суши** к **Хозяйству Болот Скорби** (не только вода) |
| Восток | Вулкан / архипелаг на конце ленты (столицу двигаем сюда — опрос городов) |

## Следствие для карты v7+

- Не рисовать Хребет как оторванный остров в океане.  
- Запад: горный стык + намёк на Амират **без** подписи соседа (или только горы снаружи пунктира).  
- СВ: узкий сухопутный перешеек/полоска к топям.  
- Вайб держать как v6.
