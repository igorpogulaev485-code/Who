# Лок — mq-04 блок A (вход)

Ответы мастера + правка mq-01/02.

| id | Решение |
|---|---|
| **a_entry** | Тот же вход (**Купель**). **Маги** определяют направление: открывают поток в план **демонов** (фиолетовый) **или** в план **мёртвых** (чёрный). Партия не «выбирает цвет сама» — договаривается с магами, какой поток открыть. |
| **a_when_know** | Про два плана рассказывает **Тандил** (стратегия города). Момент: **сессия 1, двери после похорон (1.4)** — когда называет дверь Разлом / Велиан. Элиан на Купели даёт технику открытия, не первый лор. |
| **a_fork_timing** | Развилка **на входе в Разлом** у раны: это **разные проходы** (разный открытый поток), не «глубокая развилка внутри одного плана». |

## Правило открытия потока (mq-01 и mq-02)

Когда маги **открывают** поток для входа:

1. Из раны **выходят враги** в зал Купели (выброс).
2. План демонов → **демоны**.
3. План мёртвых → **мертвецы + некромант** (или эквивалент).
4. Поток стабилизируется после боя / удержания периметра → партия входит в проход.

## Разрешение магов (уже было; уточнено)

Вход **только** с одобрения магов (лок vision §11).  
Путь к одобрению — **социальный** (договор с Элианом / уважение к Ваэре; отказ → Persuasion / поручительство Тандила). Боем вход не «ломают» без цены городу.
