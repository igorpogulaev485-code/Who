# Опрос mq-06 — город / гос.квесты / сестра ~с.6

**Уже залочено:** с.1 похороны → с.2 дверь E = камень северной ниши → **Туманный Щит** → стычка → клифф (равнина / зов на горизонте). Встречи с Лианэей в с.2 **нет**.

**Твой концепт (этот опрос):** портал/путь ведёт дальше в **крупный город** Ледяного Союза (возможно столица) → Союз **уже знает** про мёртвых и готовится → герои легко узнают угрозу → им предлагают работать **на государство** (много квестов на пути к цели) → встреча с сестрой **~с.6** = короткий разговор + оффер зла (да = арка ломается/инвертируется; нет = она готовит следующую встречу).

## A · Какой город — выход «в цивилизацию»?

**Контекст.**  
С.2 заканчивается на **южной кромке** (лагерь дварфов). Дальше нужен **крупный** город — не деревня. В репо пока **нет** playbook столицы Союза; в five-capitals есть якорь **«Храм Ледяного Сердца»** (жрица Фростара), в книгах — **Гирмхельм** (ледники). Это кандидаты имён, не лок.

| id | Вариант | За столом |
|---|---|---|
| **a_capital** | **Столица** Союза | Максимум государства, политики, жречества |
| **a_war_hub** | Крупный **фронтовой** город (не столица) | Война ближе; столица = горизонт позже |
| **a_capital_front** | Столица **и** хаб мобилизации (фронт у ворот/в долине) | И политика, и война в одном месте |
| **a_two_step** | Сначала второй крупный город → столица ближе к с.5–6 | Два playbook; больше дороги |
| **a_other** | Другое / уточню | |

**Рекомендация prep:** `a_capital_front` или `a_war_hub` (столица чистая без фронта может отодвинуть ощущение угрозы).
