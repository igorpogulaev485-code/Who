# Канон: девять кругов — берём DnD и прикручиваем

## Решение

Структура **девяти кругов и их владык** = **официальный канон DnD** (Девять Адов / Lords of the Nine), с возможностью **лёгкой рихтовки** под лор Эха рассвета (имена на карте, детали быта, связь с Разломом).  
Не выдумываем параллельную девятку с нуля.

Геометрия Эха уже залочена: круги на **одной карте**, вход = **ворота** (не вертикальный провал).  
Космология: [`canon-lock-2026-09-05-demon-plane-cosmology.md`](canon-lock-2026-09-05-demon-plane-cosmology.md)

## Иерархия власти (каркас)

```
Асмодей (9-й круг / Nessus) — верховный Владыка всего Дома
    └── восемь архидьяволов/архидемонов — лорды кругов 1–8
            └── генералы, дворы, города, замки, легионы
                    └── низшие фиэнды / тифлинги / слуги / смертные анклавы
```

Подчинение Асмодею обязательно; **междоусобица между лордами и ниже** — норма (уже в локе).
