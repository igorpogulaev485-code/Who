# Канон-лок: ответы опросника TG↔канон v3

Источник: ответы мастера в чате (2026-09-05). Форма: [`canon-survey-v3-telegram.html`](canon-survey-v3-telegram.html).

## A. Пять столиц

| id | Решение |
|---|---|
| A1 | TG «Аль-Харима» = столица **Амирата** |
| A2 | TG «Гримхельм» = столица **Ледяного Союза** |
| A3 | TG «Небесный Форт» = столица **Империи Звёздной Пыли** |
| A4 | **Сильвания** = то же, что **Древо Мира** (два имени ок) — столица Леса Хранителей |
| A5 | TG «Моредон / Элдеринская гавань» = **Элдеринская гавань** с карты — **отдельное** государство (не путать с Ульфгардом) |
| A6 | Партия **направилась** в Звёздную Пыль; маршрут через **Розалию**; **не успели** — Розалия в осаде → развернулись → обратно в **Лунный Мост** через **Камнеград** |

## B. Константин / власть

| id | Решение |
|---|---|
| B1 | **Константин** = адъютант, предъявленный миру как король, чтобы спасти настоящего. **Филлер** = глава ордена адъютантов, прямой руководитель **Кавила**. Кавил получил депешу с именем настоящего короля — **настоящего брата** прошлого короля (**Элессар I**) |
| B2 | Сцена снятия обвинений / послов = тот же адъютант-«король» |
| B3 | Ложный разоблачён / снят: **во время или после дипломатии, до Стража** |

## E. Статус блоков

Все **E1–E7 → canon**: указ/фестиваль; приют/кольцо/Морвин/Велиан; Овраг+артефакты; дипломатия пяти столиц; Камнеград до Стража; два визита/освобождение Стража; сожжение Камнеграда после Стража.
