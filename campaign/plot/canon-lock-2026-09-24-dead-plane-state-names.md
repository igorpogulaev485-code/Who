# Лок — имена государств плана мёртвых

Опрос: [`survey-dead-plane-state-names-v1.md`](survey-dead-plane-state-names-v1.md)  
Геометрия: [`canon-lock-2026-09-23-dead-plane-geometry.md`](canon-lock-2026-09-23-dead-plane-geometry.md)

## Ответы мастера

| # | id | Лок |
|---|---|---|
| A | `a_bereg` | #1 = **Берег Памяти** |
| B | `b_kray` | **Край** = отдельное государство #2 |
| C | `c_mol` | #3 = **Молчаливый Пролив** |
| D | `d_rename` + note | #4 = **Вечный Путь** |
| E | `e_rename` + «Придумай» | #5 = **Устье Забвения** (придумано агентом; можно править) |
| F | `f_pack` | Сразу бриф + отрисовка атласа |

## Пятёрка (LOCKED, кроме пометки #5)

| # | Государство | На обзоре |
|---:|---|---|
| 1 | **Берег Памяти** | + город Серый Причал только на **site** (не на обзоре) |
| 2 | **Край** | обычная подпись |
| 3 | **Молчаливый Пролив** | обычная |
| 4 | **Вечный Путь** | обычная |
| 5 | **Устье Забвения** | обычная · *имя от агента по запросу «придумай»* |

Цепь: `Берег Памяти → Край → Молчаливый Пролив → Вечный Путь → Устье Забвения`

## Следствия

- Старые draft **Нижние Дворы** / **Второй Берег** / **Молчаливая Коса** — **не** использовать на атласе.  
- Серый Причал остаётся **городом** ⊂ Берег Памяти.  
- Паспорта `echo-dawn-state` — позже, этими именами.
