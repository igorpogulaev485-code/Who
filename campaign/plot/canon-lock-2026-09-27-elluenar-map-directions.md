# Лок — направления с Эллуэнара + монастырь

## Направления (по карте страны)

От **Серебряного Порога** / региона Эллуэнар (запад Леса у гор):

| Указатель на карте региона | Азимут с листа Эллуэнара | Обоснование (карта страны) |
|---|---|---|
| **→ Силвания** | **восток / ВСВ** | столица внутрь полога, восточнее Порога |
| **→ Мировое Древо** | **ВСВ / СВ** | севернее-центральнее страны; дальше по тому же «внутрь», чуть севернее пути в столицу |
| **→ Пепельный Рубеж** | **юг / ЮЮЗ** | вдоль западных гор, южнее Порога на карте страны |

Силванию / Древо / Рубеж **не рисовать** как поселения на листе Эллуэнара — только **краевые стрелки-указатели**.  
На стрелке Рубежа — **только** «→ Пепельный Рубеж», **без** слова «монастырь».

## Монастырь (мастер / не на карте региона)

| | |
|---|---|
| Где | **Пепельный Рубеж** (регион страны) — факт для мастера |
| Было | слух/prep «северная чаща» — **снимаем** как место монастыря |
| На карте Эллуэнара | **не** подписывать; игрок видит лишь направление в Рубеж |

## Номера на v5

Проверить: каждый номер **у своей иконки**; портал **только** у #2 (храм вне города); без лишних арок.
