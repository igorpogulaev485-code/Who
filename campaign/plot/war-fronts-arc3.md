# Фронты войны (старт арки 3)

Единственный индекс «кто сейчас в конфликте».  
Граница прошлого: [`past-present-boundary.md`](past-present-boundary.md).  
Обзор всех государств: [`states-overview.md`](../../world/locations/states-overview.md).

**Важно:** список «кто напал» (Филлер) ≠ список «кто сейчас бьётся». Ниже — оба слоя.

## Слой A — кто напал (канон послания Филлера)

1. Теневая Долина  
2. Орден пламенеющей стали  
3. Хостия  
4. Империя Звёздной Пыли (**предательство**)  
5. Тёмные леса вечной тени  

Источник: [`konstantin-iii.md`](../../world/npcs/konstantin-iii.md).

| Государство | Сторона | Статус сейчас | Карточка |
|---|---|---|---|
| **Аэлендор** | оборона | Контрнаступление; столица под Орденом; Разлом в Лунном мосту | [`aelendor.md`](../../world/factions/aelendor.md) |
| **Орден пламенеющей стали** | агрессор | Легионы у стен **Сильванора**; ядро вторжения | [`orden-plameneyushchey-stali.md`](../../world/factions/orden-plameneyushchey-stali.md) |
| **Теневая Долина** | агрессор | Снабжение обрублено; группировка в глубине **отрезана** | [`tenevaya-dolina.md`](../../world/factions/tenevaya-dolina.md) |

## Слой C — участвуют слабее / участок фронта уточнять

| Государство | Почему в списке | Статус сейчас | Карточка |
|---|---|---|---|
| **Тёмные леса вечной тени** | Нападали; питали Долину | Связь разорвана; **атташе → перемирие** | [`temnye-lesa.md`](../../world/factions/temnye-lesa.md) |
| **Хостия** | В списке Филлера «напали» | **Лок r2–r3:** участвует в **разделе Аэлендора** / захвате земли, **в меньшей степени**. Бьёт **со своей территории** (пустыни): подход с **З / ЮЗ** Аэлендора — сектор между давлением **Теневой Долины** (СЗ) и **Ордена** (Ю/ЮВ). Участок фронта на локальной карте — западный–юго-западный рубеж (зона **Тёмных лесов** / **Вратного града**). Есть активный **Разлом**. | [`khostiya.md`](../../world/factions/khostiya.md) |

## Горячие точки на карте Аэлендора

| Точка | Фронт |
|---|---|
| **Сильванор** | Орден — осада |
| **Лунный Мост** | Разлом + гарнизон Хребта |
| **Серебряный Страж** | Вернули; восстанавливают; снабжение Долины обрублено → ощущение **контрнаступления** |
| **Розалия** | **Всё ещё в осаде**; деблокада параллельно арке 3; основной удар Хребта vs Звёздная Пыль (драконы / дирижабли) |
| **Лунный Мост** | **Разлом внутри города**; тучи/фиолетовые молнии над городом (сжаты магами к Разлому); фронтовой быт |
| **Чаша Шёпотов** | Долина: **разобщённые отряды**, армия зачищает; + 3 дракона Хребта (**чёрный / зелёный / красный**) **со всадниками** + охрана; город под Тандилом |
| **Камнеград** | Сожжён; политически = «несчастный случай»; восстанавливается |
| **Глубина королевства** | Отрезанная группировка Долины |

## Победа на земле — не арка 3

Арка 3 = демоны через Разлом.  
Победа Аэлендора над оставшимися врагами на земле = **арка 4** ([`arcs.md`](arcs.md)).
