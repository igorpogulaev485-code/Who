# Канон: Верховный Синклит Аэлендора

Улица и дипломаты коротко: **«Синклит»** (= то самое «правительство / советы»).

## Председатель (не «архонт»)

**Архонт** — отменяется как термин (непонятен).  

Публичный глава: **Председатель Синклита**.  
**Сейчас это Филлер** (Верховный адъютант = Председатель). Он ведёт заседания, подписывает указы Синклита, принимает послов. Для народа он не «король», а глава правительства.

## Кресла: по одному от каждого блока

### Отраслевые блоки (по 1 креслу)

| # | Блок | Откуда делегат |
|---|---|---|
| 1 | Маги | Совет магов |
| 2 | Рыцари | Совет рыцарей |
| 3 | Генералы | Совет генералов |
| 4 | Старейшины | Совет старейшин |
| 5 | Гражданская коллегия | Налоги, снабжение, администрация |
| 6 | Торговцы | Купеческие гильдии / Серебряный Путь |
| 7 | Жрецы | Хранители Завесы / храмы |
| 8 | Адъютанты | Представительство **адъютантов короля** (главные помощники короны; даже когда король скрыт) |

### Региональные блоки (по 1 креслу)

От **каждого региона** Аэлендора — свой голос (включая священные и портовые):

| Регион (рабочие имена по карте) | Опора |
|---|---|
| **Сильванор** (столичный) | Столица |
| **Лунные Пики / Лунный Мост** | Священный град |
| **Розалия** | Северный порт |
| **Златоцвет** | СВ |
| **Элиандор** | Центр–восток |
| **Вратный град** | ЮЗ |
| **Хранитель пик** | Юг |
| **Серебряный предел** | ЮВ |

Итого кресел: **8 отраслевых + 8 региональных = 16** (+ Председатель, который может быть из блока адъютантов и не занимать второе кресло — голос Председателя отдельно / решающий при ничьей).  
Точные границы провинций на белом пунктире карты — можно уточнять имена регионов позже; принцип «каждый регион = кресло» — **канон**.

## С королём / без короля

| | |
|---|---|
| **Сейчас (король скрыт)** | Синклит = суверенитет для народа и послов |
| **Если король явен** | Советы и Синклит — **под короной** |

## Адъютанты

В Синклите **обязательно** есть кресло адъютантов.  
Теневой Совет Адъютантов / разведка — отдельный **государственный теневой** слой (не путать с уличным бандитизмом). Кавил — член Теневого Совета.

## Касты (официальные) — сетка утверждена, имена ок

| # | Каста | Кто |
|---|---|---|
| 1 | Высшие Дома | знать |
| 2 | Звёздный Круг | маги, писцы |
| 3 | Щит Луны | воины, рыцари |
| 4 | Корни | труд, ремесло, деревня |
| 5 | Серебряный Путь | **торговцы**, мореходы, порты |
| 6 | Хранители Завесы | жрецы / святыни |

Это **официальные** касты. Теневые госструктуры и банды — **отдельный слой** (черновик на утверждение).
