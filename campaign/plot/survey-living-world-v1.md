## A · Когда мир тикает?

| id | Вариант |
|---|---|
| **a_end** | В конце **каждой** сессии (после клиффа) |
| **a_inter** | Только в **интерлюдии** (между сессиями) |
| **a_both** | И сессия, и интерлюдия (рекомендую) |
| **a_calendar** | По игровому календарю (неделя/месяц), независимо от стола |
| **a_other** | Другое / уточню |

## B · Сколько фронтов за один тик?

| id | Вариант |
|---|---|
| **b_1** | Ровно **1** фронт |
| **b_2** | **1–2** фронта (как в draft) |
| **b_2plus** | 1–2 фронта + обязательная **новость** партии (даже если не копали) |
| **b_other** | Другое |

## C · Какие 3 фронта горячие **сейчас** (старт арки 3)?

Выбери до трёх (в HTML — чекбоксы). Рекомендация: Разлом · Орден · Хребет у моста.

| id | Фронт |
|---|---|
| **c_rift** | Демоны / Лунный Разлом |
| **c_order** | Орден у Сильванора |
| **c_ridge** | Хребет у Лунного моста |
| **c_ice** | Лианэя / льды |
| **c_milana** | Милана / дневник |
| **c_velian** | Велиан в Разломе |
| **c_valley** | Теневая Долина (отрезанные) |
| **c_elessar** | Элессар / Лес |
| **c_clone** | Сосуд Двойника Маэстро |
| **c_other** | Другое |

## D · Стартовый жар Лунного Разлома (сейчас)

| id | Вариант |
|---|---|
| **d0** | 0 · давление есть, но город «держится» |
| **d1** | 1 · вылазки / жертвы / слухи (рекомендую) |
| **d2** | 2 · уже плохо (квартал/паника) |
| **d3** | 3 · кризис на пороге |
| **d_other** | Другое |

## E · Часы «Двойник / крышка» после стр. 16–17

| id | Вариант |
|---|---|

## F · Интерлюдия с дневником — мир уже тикнул?

| id | Вариант |
|---|---|
| **f_yes** | Да — 1 тик уже прошёл (отметить в трекере) |
| **f_no** | Нет — чтение ≠ тик мира |

| **f_other** | Другое |
