# Опрос — регион у портала (Порожье)

Контекст: карта **страны** Леса уже locked. Нужен **регион**, куда вышли герои из портала.  
Храм **Серебряного Порога** = точка портала (site уже есть).  
**Силвания** = столица государства — **не** «центральный город региона», если не выберешь иначе.  
Тик: у Порога **порча / некромантия**.

Ответь в чат: `A=… B=… C=… D=… E=… F=… G=…` или HTML.

---

## A · Имя региона (подписи / папка)

| id | Вариант |
|---|---|
| `a_porozhe` | **Порожье** (рабочее имя ветки; коротко) |
| `a_gost` | **Гостевой Порог** (как в паспорте страны) |
| `a_serebro` | **Сребролесье** / земли Серебряного Порога |
| `a_other` | Другое / уточню |

## B · Центральный город у портала (пакет имён)

Храм остаётся **местом** у/в городе или чуть в стороне (см. C). Город **меньше Силвании**.

| id | Центр | 2 мелких города | 2–3 деревни | Заброшка |
|---|---|---|---|---|
| `b_leaf` | **Листоврат** | **Тихая Крона** · **Моховой Брод** | **Три Корня** · **Росинка** · **Пеньковый Угол** | **Чернокорнь** (деревня) |
| `b_silver` | **Среброречье** | **Ивовый Щит** · **Камнелист** | **Светлый Пень** · **Туманный Брод** · **Олений Луг** | **Пепельная Роща** (город-призрак) |
| `b_guest` | **Гостевой Венец** | **Нижний Порог** · **Зелёный Стан** | **Чаша Росы** · **Две Тропы** · **Корневой Посад** | **Молчаливый Храм** (заброш. поселение у старого алтаря) |
| `b_other` | Свои имена (заметка) | | | |

## C · Храм / портал относительно центра

| id | Вариант |
|---|---|
| `c_edge` | Храм **на краю** центрального города (как «ворота гостей») |
| `c_out` | Храм **вне стен**, ½–1 день пешком; город — ближайший хаб |
| `c_in` | Храм **внутри** города (квартал Порога) |
| `c_other` | Другое |

## D · Интересные места (2–3 + порча)

| id | Пакет (кроме поселений) |
|---|---|
| `d_blight` | **Пятно Порчи** (чёрная земля у портала/троп) · **Круг Стражей** (древние камни) · **Тропа Гонцов** (знак → Силвания) |
| `d_ruin` | Пятно Порчи · **Разбитый Монастырь-спутник** (не главный монастырь короля) · **Серебряный Ключ** (родник / святое место) |
| `d_wild` | Пятно Порчи · **Логово Шептуна** (зверь/дух леса) · **Зеркальная заводь** (маленькое озеро-туман) |
| `d_other` | Свои 2–3 места |

## E · Силвания на региональной карте

| id | Вариант |
|---|---|
| `e_arrow` | Только **стрелка / подпись** «к Силвании» (столица за краем) |
| `e_edge` | Силвания **на самом краю** карты (силуэт, не центр региона) |
| `e_off` | Вообще не показывать — только локальные точки |
| `e_other` | Другое |

## F · Расклад на карте (композиция)

| id | Вариант |
|---|---|
| `f_west` | Якорь страны: Порог **запад** → центр региона у западного входа; мелкие города по дуге внутрь леса |
| `f_hub` | Портал/храм в **центре** листа; города кольцом; заброшка + порча к югу/тени |
| `f_road` | Главная **дорога гонцов** через центр; деревни по бокам; заброшка в стороне от дороги |
| `f_other` | Другое |

## G · После ответа

| id | Вариант |
|---|---|
| `g_map` | Лок имён → **бриф + карта региона** → seed центрального города |
| `g_brief` | Сначала только **текстовый бриф** точек (без картинки) |
| `g_other` | Другое |

---

**Черновик агента (не лок):** `a_porozhe` + `b_leaf` + `c_edge` + `d_blight` + `e_arrow` + `f_west` + `g_map` — Листоврат у храма-ворот; порча как крюк тика; Силвания стрелкой.
