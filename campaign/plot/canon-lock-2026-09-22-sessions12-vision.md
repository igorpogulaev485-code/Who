# Лок — ответы опроса vision-v1

## Метод

| # | Решение |
|---|---|
| 1 | У мастера есть **ключевые кадры**; детали докручиваем вместе (опросник + свободный текст). |
| 2 | Глубина файла к столу: **почти скрипт** (речи-черновик, «что сказать игрокам», DC, враги). |
| 3 | После сессий импровизацию стола вносим в канон и правим дальше. |

## Похороны (сессия 1)

| # | Решение |
|---|---|
| 4 | Похороны **на весь город**: поминальные очаги в разных уголках; у партии **выбор**, где участвовать; плюс **центральное** мероприятие. |
| 5 | С помоста: **Тандил** + **жрец Собора Безмолвного Звона**; Героям можно речь, если захотят и будут на центральном. |
| 6 | Тон Тандила: **сталь поверх горя**; в душе жалеет, слабости не показывает. |
| 7 | **Фириэсса:** почти заговорит — прервётся/уйдёт. Партия уже в связи с ней (помогли; собирает инфу); связь через **магическое кольцо связи Маэстро**. Хочет высказаться — не станет. |
| 8 | Must-have: **пустота** без Маэстро/шатра/фестиваля; скорбит **весь город и страна**; есть **иностранные делегации**. |

## Вход в Разлом (сессия 2)

| # | Решение |
|---|---|
| 9 | Вход **не** «прыжок с баррикады Тар-Аминона»: прореха в **Храме Купель Вечных Звёзд**, где стояло **зеркало**. Сдерживают **эльфийские маги**; службу несут **эльфы-дроу** (хранители зеркала). |
| 10 | Вид: **серебряная рана в воздухе** внутри храма на месте зеркала; пепел, без тепла. |
| 11 | Вход только с **одобрения магов**, контролирующих Разлом. |
| 12 | Первый сильный кадр сессии 2: **инструктаж Тандила + мага**, отвечающего за контроль Разлома. |
| 13 | Проход ≈ **5 минут**: пустота, **невесомость**, вокруг **фиолетовые сгустки магии**; нужно **пробраться к выходу**. |
| 14 | Во время прохода у каждого: спасброски **Телосложения, Интеллекта, Мудрости** → временные дебафы (числа — prep, докрутка). |
| 15 | На выходе: спасбросок **Ловкости**; провал → **2к8** урона (приземление). |
| 16 | Выход = **демоническая пустошь**; виден **маяк**; на маяке живут **тифлинги-изгои** — можно договориться как с **проводниками**. |
| 17 | Разлом может вести в **два плана**: демонов и мёртвых. **Кровь** тянет к плану мёртвых; **демоны** — искушение / подавление воли. |
| 18 | **Кардиана / аватара** в сессиях 1–2 нет (душа занята другим). |
| 19 | Эстетика архива «Искажённое Лунное Царство» — **база, докручиваем**. |
