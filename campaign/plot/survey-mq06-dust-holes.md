## C · Как партия **добирается до Розалии** в с.2 сапог?

| id | Вариант |
|---|---|
| **c_portal_roz** | Есть **портал** Мост / королевский → **Розалия** (как доступ Кавила) |
| **c_road_montage** | Дорога/караван — **монтаж** (не играть весь путь) → старт вечера уже у Розалии |
| **c_play_road** | Играть кусок дороги (1–2 бита) → Розалия |
| **c_start_roz** | С.2 **сразу в Розалии** (путь «за кадром» до сессии) |
| **c_other** | Другое |
