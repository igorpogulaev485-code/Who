## Иерархия (уточнение мастера 2026-09-23)

```
Атлас плана мёртвых
 └─ 5 государств-островов в пепельном море  ← подписи обзора
     └─ города / места внутри государства   ← отдельные карты позже
         пример: Серый Причал ⊂ входное государство
```

Как у демонов: круг = государство; здесь остров = государство.  
Причал ≠ на обзоре (override мастера 2026-09-24); site-карта города отдельно LOCKED.

### Пайплайн отрисовки (слово мастера)

1. **Обзорный атлас** — только государства-острова (**без** микро-Причала).  
2. **Карты государств** — границы/регионы внутри острова.  
3. **Города** — как Серый Причал (site уже LOCKED) внутри своего государства.

Паспорта государств — позже через `echo-dawn-state` (после имён).

## Следствия для атласа

1. **Пепельное море** = среда между государствами (фарватеры / паромы).  
2. **5 государств** — имена LOCKED ([лок имён](canon-lock-2026-09-24-dead-plane-state-names.md)).  
3. **Серый Причал** = город ∈ **Берег Памяти**; на обзоре **не** показывать.  
4. **Край** = государство #2 по цепи.  
5. **Нет** государства «Пепельные Плёсы» — буря = overlay.  
6. Player-обзор **не** спойлерит диверсии, отряд, душу Кардиана.

## Уже канон (не отменяется)

- Чёрный поток → сразу **площадь Причала** (город)  
- Site Причала LOCKED  
- Край = за бытом города / юг; след Велиана  
- Кардиан = серая буря при вмешательстве  

## Не на этой карте

- План демонов  
- Имена Велиана / пятёрки / Лайры / Кардиана  
- Полные карты городов внутри государств (кроме микро-Причала)  
- Отдельный биом «зона бури»
