# Лок — геометрия плана мёртвых

Опрос: [`survey-dead-plane-geometry-v1.md`](survey-dead-plane-geometry-v1.md)  
План: [`../prep/orchestrator/dead-plane-map-plan.md`](../prep/orchestrator/dead-plane-map-plan.md)

## Ответы мастера

| # | Ответ | Лок |
|---|---|---|
| A | `a_cities` | Топология = **цепь городов-островов** в **пепельном море** (не края-державы суши, не кольца Данте) |
| B | `b_dot` | **Серый Причал** на обзоре = **микроточка** (как Маяк на демонах); site-карта города отдельно LOCKED |
| C | `c_5` | На первом атласе **5** именованных островов/портов |
| D | `d_boats` | Связь = **переправы** по пепельному морю (не тракты суши, не демонические ворота) |
| E | `e_overlay` | Буря Кардиана **не** отдельный регион; может накрыть любой край — **на обзоре не рисовать** |
| F | `f_named` | На атласе **два** дальних пятна: **Нижние Дворы** + **Второй Берег** (имена draft → ok) |
| G | `g_realms` | Player: **имена островов/портов** + микро-Причал + явные **переправы**; без НПС/Велиана/Кардиана |
| H | `h_none` | План демонов на этой карте **не** показывать |
| I | `i_prichal` | Эстетика = тон **Серого Причала** (серое небо, зола, бумага) |
| J | `j_spine` | Масштаб просторный под биты spine mq-04 |
| K | `k_path` | Первая версия акцентирует путь **Причал → Край → намёк на даль** |

## Следствия для атласа

1. **Пепельное море** = фон/среда между островами (читаемые фарватеры / лодки / паромы).  
2. **5 островов** (whitelist имён — gazetteer; ждут ok мастера):  
   - входной порт (**Причал**, микро)  
   - **Край** (направление Велиана)  
   - **Нижние Дворы**  
   - **Второй Берег**  
   - пятый остров-ступень между ними (имя draft в gazetteer)  
3. **Нет** региона «Пепельные Плёсы» — буря = overlay, не край.  
4. Player-обзор **не** спойлерит диверсии, отряд, душу Кардиана.

## Уже канон (не отменяется)

- Чёрный поток → сразу **площадь Причала** (не пустошь)  
- Site Причала LOCKED  
- Край = за бытом города / юг; след Велиана  
- Кардиан = серая буря при вмешательстве  

## Не на этой карте

- План демонов  
- Имена Велиана / пятёрки / Лайры / Кардиана  
- Отдельный биом «зона бури»
