# Канон: витрина эльфийских богов Аэлендора

Не весь Селдарин из справочника — **верхушка + чуть ниже**, плюс **Лолс** обязательно.

Имена — классический эльфийский пантеон D&D; транслит как в книгах стола (Кореллон, Сеханине, Лолс).

## На витрине

| Бог | Роль на витрине | Акцент Аэлендора |
|---|---|---|
| **Кореллон Ларетиан** | Глава пантеона | Творение, магия, искусство, война высших; лицо короны и Синклита |
| **Сеханине Лунная Лука** | Вторая по слышимости | Луна, сны, переходы, смерть/путь; **Лунный Мост** как духовный центр |
| **Лабелас Энорет** | Время и память | История, долголетие; стыкуется с гордостью за многовековую традицию |
| **Ханали Целанил** | Красота и любовь | Городская эстетика, храмы-витрины, «высокий» вкус |
| **Солонор Теландира** | Охота / стрельба / стража | Рыцари, границы, боевой клир рядом с армией |
| **Аэрдри Фаэнья** | Воздух / погода / полёт | Чуть ниже верхушки; храмы и ритуалы «неба» у городских |
| **Лолс** | Обязательное верование | Контур **теневых** эльфов; храмы по стране (и миру); **не** лицо короны, но **нельзя** вычёркивать из поля веры |

## Не на витрине (есть в мире, не подчёркиваем в Аэлендоре)

Риллифан, Эреван, Дип Сашелас, Фенмарел, Шевраш и прочие — не запрещены, но **не** в государственной/народной «витрине» высших городов.  
(Риллифан естественнее звучит у **Леса Хранителей** — отдельный контур.)

## Как подавать за столом

- Официальные проповеди и Синклит-жрецы → **Кореллон / Сеханине** (+ Лабелас, Ханали по поводу).  
- Лунный Мост → **Сеханине** особенно слышна.  
- Храмы **Лолс** — отдельная реальность; драконий сет / Хребет уже завязаны.  
- Хранители Завесы = институт клира государства над этой витриной, не «ещё один бог».
