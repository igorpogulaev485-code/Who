# Опрос — Серебряный Порог (город)

Контекст: партия у **Храма** (вне стен). Регион **Эллуэнар** LOCKED v11. Seed города есть (`gorod-serebryanyy-porog`).  
Мастер: город **очень крупный**, много активностей, герои должны **захотеть задержаться**.  
Храм = отдельный site. Не путать со столицей **Силвания**.

Ответ: в чат `A=… B=… … H=…` или HTML → «Собрать ответы».

## A · Глубина первой волны

| id | Вариант |
|---|---|
| `a_full` | **Сразу весь город** как Камнеград: все районы детально (места + НПС 1–12 + 1к6 + якоря) |
| `a_wave3` | Сейчас **3 приоритетных района** полностью; остальные — оглавление + следующая волна |
| `a_map_first` | Сначала **карта города + каталог ~20 мест**, потом детализация районов |
| `a_other` | Другое / уточню в заметке |

## B · Размер / число зон

| id | Вариант |
|---|---|
| `b_seed5` | Углубить **5 районов** из seed (Ворота · Рынок · Ярусы · Двор · Нижняя тропа) |
| `b_big8` | Расширить до **~8 районов** (крупный гостевой хаб) |
| `b_kamne` | Масштаб Камнеграда: **каталог ~20+ мест**, 8–10 зон |
| `b_other` | Другое / уточню в заметке |

## C · Тон города

| id | Вариант |
|---|---|
| `c_wood` | Живое дерево / серебро коры / эльфийский гостевой хаб (как seed) |
| `c_mixed` | Эльфы + полуэльфы + **караваны / чужие кварталы** (Аэлендор на гостевых печатях) |
| `c_gate` | Больше **крепость-ворота Леса**, чем рынок развлечений |
| `c_other` | Другое / уточню в заметке |

## D · Репутация партии (−4)

| id | Вариант |
|---|---|
| `d_soft` | Косые взгляды и цены выше — **активности открыты** |
| `d_gate` | Часть услуг **закрыта** без услуги/искупления у старосты |
| `d_hard` | Почти всё закрыто; открыты «грязная» работа и линия **порчи** |
| `d_other` | Другое / уточню в заметке |

## E · Порча у портала

| id | Вариант |
|---|---|
| `e_side_now` | Якорь в городе + **сразу** полный quest-side после playbook |
| `e_anchor` | Только якорь в playbook; quest-side отдельным ok позже |
| `e_temple` | Вести порчу из playbook **Храма**; в городе — слухи/наём |
| `e_other` | Другое / уточню в заметке |
