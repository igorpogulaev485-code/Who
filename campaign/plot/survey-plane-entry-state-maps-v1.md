# Опрос — карты «стран» после Разлома

Уже LOCKED: атлас демонов v24 · атлас мёртвых v2 · site **Маяк** · site **Серый Причал**.

Сейчас нужны **карты государств** с **точкой появления** партии.

| План | Входное государство | Точка появления (уже канон) |
|---|---|---|
| Демоны | **Пепельный Порог** (круг 1) | у **Маяка душ** |
| Мёртвые | **Берег Памяти** | площадь **Серого Причала** |

HTML: [`survey-plane-entry-state-maps-v1.html`](survey-plane-entry-state-maps-v1.html)  
Litterbox: *(заливка после коммита)*

## A · Сколько карт сейчас?

| id | Вариант |
|---|---|
| `a_two` | ★ **Только 2 входных** (Пепельный Порог + Берег Памяти) |
| `a_dead` | Только **Берег Памяти** |
| `a_demon` | Только **Пепельный Порог** |
| `a_more` | Больше государств → в заметке |
| `a_other` | Своё → заметка |

## B · Порядок

| id | Вариант |
|---|---|
| `b_dead` | ★ Сначала **Берег Памяти** (мёртвые), потом Порог |
| `b_demon` | Сначала **Пепельный Порог**, потом Берег |
| `b_parallel` | Оба брифа сразу, рисуем по очереди без паузы |
| `b_other` | Своё → заметка |

## C · Что на карте государства?

| id | Вариант |
|---|---|
| `c_hub` | ★ **Точка появления** + **4–8** именованных мест / трактов (как компактный регион) |
| `c_appear` | Только появление + силуэт государства + выход к соседу |
| `c_dense` | Плотно 10–15 точек (почти playbook-карта) |
| `c_other` | Своё → заметка |

## D · Как показать появление?

| id | Вариант |
|---|---|
| `d_mark` | ★ Яркая метка **«Появление»** / разломный след + подпись места (Маяк / Причал) |
| `d_place` | Только подпись места появления (без слова «появление») |
| `d_both` | Метка Разлома **и** отдельная подпись лагеря/города |
| `d_other` | Своё → заметка |

## E · Связь с уже LOCKED site-картами

| id | Вариант |
|---|---|
| `e_nest` | ★ Государство = zoom-out; Маяк/Причал = **точка** (site не трогаем) |
| `e_inset` | То же + маленький inset site на углу карты государства |
| `e_redraw` | Пересобрать site внутри новой карты (не советую) |
| `e_other` | Своё → заметка |
