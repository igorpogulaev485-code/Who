# Лок — mechanics-v1

Дополняет [`canon-lock-2026-09-22-sessions12-vision.md`](canon-lock-2026-09-22-sessions12-vision.md).

## Проход (сейвы)

| Сейв | DC | Провал → до **длинного отдыха** |
|---|---|---|
| Телосложение | **15** | весь получаемый урон **×2** |
| Интеллект | **15** | **ячейки заклинаний ×½** (вниз); если ячеек нет — помеха на Int checks/saves |
| Мудрость | **16** | **−10** ко всем проверкам **Восприятия** |

Урон приземления (Dex): DC **13**, провал = **2к8** дробящего — без изменений.

## Невесомость

Только **индивидуальные** проверки (не skill challenge группы).  
Провал ≠ «застрял навсегда»: всех всё равно выплёвывает к выходу через ~5 мин; цена — урон сгустком + помеха на Dex-приземление (см. скрипт).

## Маяк и тифлинги

| # | Решение |
|---|---|
| 1 | Имя: **Маяк душ**. |
| 2 | Было место ритуалов демонов над пленными; **заброшено** (легион, возможно, ушёл к другому месту силы). |
| 3 | Тифлинги **прячутся** там; для демонов они **ничтожны**; **договоров с легионом нет**. |
| 4 | Угроза: демон, который хочет их **убить / забрать души**. |
| 5 | Лидер: **Сарель Пепельный Договор** — просит **помощь** взамен на проводку. |
| 6 | Партия может **отказаться**. Квест проводника закрывается: **социалка / бой / силой заставить** Сарель вести. |
