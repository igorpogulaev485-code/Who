# Лок — survey-mq06-triad-entry

| id | Решение |
|---|---|
| **a** | `a_other` — **открытый мир**: партия сама обсуждает и выбирает цель (льды / Хребет / Пыль). Не форсить меню Кавила. Знают примерно, где арты. |
| **b** | `b_sword_first` — prep: сначала ветка **меча / Хребет** |
| **c** | `c_other` — Меч = **реликвия в священном месте** Империи; охрана; драконы **не хотят делиться** |
| **d/e** | Портал есть (союзники). Клифф с.2 = закрепиться у святыни/подступов (уточним после паспорта) |
| **f** | `f_none` — яйца **не** связывать с веткой меча |
| **g** | `g_admiral` — сапоги у **адмирала / флота** Пыли |
| **h/i** | Пыль = **враги**; портал **закрыт**. Путь: скорее **Розалия → корабль** (тайно / иной ход) |
| **j** | `j_other` — пока партия не во льдах, **армия мёртвых развивается** (как именно — позже) |
| **k** | `k_s2_only` — на ветку: скрипт с.2 + seed |
| **note** | Государства — **обязательно** через `echo-dawn-state` |

## Следствие

1. Паспорт **Империи Драконьего Хребта** (опрос → лок → W1/W2) → затем с.2 меча.  
2. Паспорт **Звёздной Пыли** — следующим заходом (после меча).  
3. Обновить mq-06: свободный порядок; яйца ≠ меч; сапоги = адмирал; Пыль через Розалию.

## Не делает этот лок

- Имя столицы / правителя Хребта  
- Имя священного места меча  
- Полный скрипт с.2 меча (после паспорта)
