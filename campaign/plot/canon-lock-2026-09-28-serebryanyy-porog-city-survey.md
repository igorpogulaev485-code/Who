# Лок — опрос города Серебряный Порог

| # | id | Решение |
|---|---|---|
| **A** | `a_other` | **Волнами.** ~**20–25 мест** |
| **B** | `b_other` | Районы **есть**; число районов ≠ размер (как Лунный мост: мало районов, много мест) |
| **C** | `c_wood` | Живое дерево / серебро коры / эльфийский гостевой хаб |
| **D** | `d_soft` | −4 = взгляды и цены; **активности открыты** |
| **E** | `e_temple` | Порча ведётся из playbook **Храма**; в городе — слухи / наём |
| **F** | `f_yes` | Numbered map + каталог мест |
| **G** | `g_other` | Порядок: **город → квесты с НПС → порча → остальные точки региона** |
| **H** | `h_rival` | По размеру/шуму **почти сопоставим** со столицей (гостевой «второй город») |

## Порядок работ

1. Собрать город (карта + каталог + playbook мест/НПС) — волнами  
2. Квесты в городе (quest-side)  
3. Порча (Храм + городские слухи)  
4. Остальные точки карты Эллуэнара
