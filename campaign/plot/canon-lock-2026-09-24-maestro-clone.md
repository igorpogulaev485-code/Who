# Лок: Двойник Маэстро

```
A=a_few B=b_other(7) C=c_other(1+growing) D=d_other(Amirat)
E=e_kardian_dead F=f_hint G=g_trapped_demon H=h_other
I=i_not_yet J=j_other K=k_rare(L-мастер: «как лучше») L=l_other(дверь R)
```

| id | Решение |
|---|---|
| **A** `a_few` | Успешных переездов души (**смерть→клон**): **2–4** за жизнь |
| **B** | Успешных сосудов выращено за жизнь: **7** (не считая юношеские 3 провала) |
| **C** | На момент убийства демонами: **1 готовый** + **1 ещё растёт** (<120 дней) |
| **D** | **Готовый** актуальный сосуд скрыт в государстве **Амират** |
| **E** `e_kardian_dead` | Второй из «двое знали» нишу под мостом = **Кардиан** (пал) |
| **F** `f_hint` | Милана **догадывается** / есть запрет отца — не GPS |
| **G** `g_trapped_demon` | Душу держат **демоны** |
| **H** | Клон **не** связан с планом мёртвых. Душу забрали демоны → она **не** попала на план мёртвых |
| **I** `i_not_yet` | В начале арки 3 точку в Амирате **нельзя** найти — только улики |
| **J** | При успехе: **полная** магическая сила сразу (адаптация Clone под чародея). Память: есть **пробелы** vs исторический Маэстро, но в клоне — **чёткие инструкции**, как восполнить пробелы |
| **K** `k_rare` | Ещё **1–2** провала сосудов во взрослой жизни (рек. сюжета: улики/ложники без «кладбища») |
| **L** | Открытые стр. 16–17 → появляется **дверь R · Путь воскрешения** (отдельно от двери B · дневник) |

## Следствия для стола

1. **Воскрешение телом** = освободить душу у демонов (дверь **A** / план демонов) **+** дойти до готового сосуда в **Амирате** (дверь **R**, поздний этап).  
2. План мёртвых (**F**) — **не** про душу Маэстро (другие цели: Велиан и т.д.).  
3. Растущий сосуд = **таймер** (мастер ведёт дни; точное место роста — уточнить позже, если нужно).  
4. Ниша под Лунным мостом = **история** первого клона / возможные улики, не актуальный готовый сосуд.

## Дверь R (ранбук)

Открывается, когда партия **изучила** стр. 16–17 (уже канон интерлюдии).  
Ранбук: [`../prep/arc3-visual-book/chapters/18-index.md`](../prep/arc3-visual-book/chapters/18-index.md)

## Открытый хвост (не блокер)

Точное укрытие в Амирате (город/пирамида/другое) — когда партия реально пойдёт на юг; до тех пор `i_not_yet`.
