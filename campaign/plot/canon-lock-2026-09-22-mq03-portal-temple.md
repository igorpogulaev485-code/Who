## Решения (A–I, кроме E — уточним)

| id | Решение |
|---|---|
| **A · старт / клифф с.2** | Старт сессии 2 = **верхний город** Лунного моста. Там **порталы** для королевских служащих высокого уровня. **Кавил** (Старший адъютант / Теневой Совет) — такой. Портал **не** в столицу Леса, а в **храм в Лесу Хранителей**. От храма развилка: **Малфурион** / **столица Леса** / **Элессар** (тайное место — решим отдельно). |
| **B · дорога** | Решается **порталом** (нет долгого тревела Аэлендор→Лес в с.2). |
| **C · толчок** | **Кавил** инициирует, **если захочет** (не принудительный рельс «Тандил отправил»). |
| **D · Орден** | В сессиях **1–2** Ордена на пути **нет** и партия **не узнаёт**. Фоном (только мастер): Орден готовит **очень серьёзное вторжение** в **Элдеринскую гавань** и **Лес Хранителей** — расширение вражды, скоро. |
| **E** | Не отвечен → волна 2 (встреча в храме). |
| **F · spine** | «Как обычно» → полный каркас ~20 + скрипт с.2 после дозакрытия дыр. |
| **G · playbook** | **Поступательно.** Первым делом — описать **храм**, куда телепорт. |
| **H · цена уезда** | Пока партии нет: **бой за Разлом без них** + последствия. Точный масштаб последствий **пока не фиксируем** — будут. |
| **I · Элессар ↔ Малфурион** | До совета ещё есть время. С храма можно начать с **поиска короля** **или** пойти в **столицу** говорить с руководством государства Леса. |

## Следствия для prep

1. Дверь D в скриптах: не «только Врата Рассвета / дорога», а **портал верхнего города** (Кавил).  
2. Первый location-seed: **храм в Лесу** (имя/суть — опрос волна 2).  
3. Живой мир Ордена: ступень «готовит удар по Элдерину + Лесу» — в open-threads как **GM-only** до игры.  
4. Элессар = **не** обязательно столица; тайное место TBD.
