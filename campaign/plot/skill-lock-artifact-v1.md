# Лок: решения для `echo-dawn-artifact`

Источник: ответы мастера на [`skill-survey-artifact-v1.html`](skill-survey-artifact-v1.html) (2026-09-05).

| id | Решение |
|---|---|
| A1 | Скил покрывает **большие сеты + сюжетные уникальные + very rare / rare** (Страж, Овраг…) |
| A2 | Обычный лут и расходники — **вне скила** (коротко в квесте/локации) |
| B1 | Канон: **сводка сета + карточка на предмет** (`world/artifacts/…`; наследие сводок — `world/lore/artefacts-*`) |
| B2 | **Docx** — да, как у локаций/квестов |
| C1 | Карточка **стандарт**: id/сет/редкость + где сейчас + механика 5e + цена/проклятие/сет + якоря поиска + игрок vs мастер |
| C2 | **Официальный** предмет 5e → не переписывать (ссылка на источник). **Доработка / homebrew** → **максимум** деталей |
| D1 | Типы: Кардиан · Драконы · Божественный · прочий уникальный; **новые сеты будем создавать вместе** |
| D2 | Сетовый слот только через **основной квест / явный ok мастера** |
| D3 | У Кардиана дебафы на **2 / 3 / 4 / 5 / 6**; у **других сетов тоже могут быть** дебафы |
| E1 | Отдельный **`artifacts-roster`** (партия + мир) |
| E2 | Антипаттерн: **легендарка с потолка без места в мире** |
