# Канон: образование и Лесоверье

## Государство образования

Аэлендор — **максимально образованное** государство: учат **от мала до велика**.  
**Школы / академии есть в каждом городе** (общее образование + местные магические школы).

Это не страна «одной башни»: грамотность и обучение — норма гражданства.

## Лесоверье

| | |
|---|---|
| Что | **Великая / главная магическая академия** — колыбель магического могущества Аэлендора |
| Не что | Не единственная школа; академии есть повсюду |
| Тон | Очень сильное, «крутое» место; лицо того, почему Аэлендор — **могущественная магическая держава** |
| Каста | Естественный хаб **Звёздного Круга** (не монополия: магов готовят и в городах) |

Связь с доктриной: сильные маги и линия **Маэстро** (учитель/эталон) питаются этой школьной культурой; Лесоверье — её **вершина**, не вся система.
