# Канон: входы Разлома → круги Дома Владыки

## Правило

В лоре — **семь** узлов Разлома; сейчас **пять** активны, **два** спят.  
**Каждый материковый вход ведёт в свой круг.** Глубокий вход **минует** верхние круги → больше хаоса/давления. На плане ворота круг→круг остаются.

Сводка узлов: [`world/lore/razlom-i-zavesa.md`](../../world/lore/razlom-i-zavesa.md)  
Круги/лорды: [`world/locations/dom-vladyki-nine-circles.md`](../../world/locations/dom-vladyki-nine-circles.md)

## Итоговая таблица (лок)

Принцип: **аутентичная рифма** места/угрозы с характером круга и лорда.

| Узел на материке | Статус | → Круг | Лорд круга | Почему так |
|---|---|---|---|---|
| **Лунный Мост** (Аэлендор) | активен | **1 Avernus / Авернус** | **Зариэль** | Самый закрепившийся; Первое Зеркало; фронт; чаще всего проницаем |
| **Империя Звёздной Пыли** | активен | **2 Dis / Дис** | **Диспейтер** | Имперская тирания, стены, шпионаж — рифма Диспа |
| **Хостия** | активен | **3 Minauros / Минаурос** | **Маммон** | Чужой мир, сделки/долг/алчность; «грязь» контакта |
| **Империя Драконьего Хребта** | активен | **4 Phlegethos / Флегетос** | **Белиал + Фиерна** | Огонь/ярость; меч разрушений рядом |
| **Ледяной Союз** | активен | **5 Stygia / Стигия** | **Левистус** | Лёд, заточение; доспехи смерти у Разлома |
| **Тёмные леса вечной тени** | **спит** | **6 Malbolge / Мальболж** | **Глазия** | Лес-интрига, ловушки, «вечная тень»; гниль войны без открытого портала |
| **Королевство пепельных земель** | **спит** | **7 Maladomini / Маладомини** | **Баалзебул** | Руины ложного порядка, пепел; южный пояс между Хостией и Хребтом |
| — | нет стабильного входа | **8 Cania / Кания** | **Мефистофель** | Только изнутри плана / ритуал / сделка уровня архимага |
| — | нет стабильного входа | **9 Nessus / Нессус** | **Асмодей** | Только двор Владыки / его воля / исключение сюжета |

Точные **города/ландмарки внутри** Тёмных лесов и Пепельных земель — уточнить позже (достаточно государства).

## Следствия для стола

- Партия из **Лунного Моста** → по умолчанию **Авернус** (если не нацелили иначе / другой узел).  
- **Ледяной Союз** → сразу **Стигия**, минуя 1–4.  
- Спящие **6–7** не открыты сейчас; пробуждение = отдельный сюжетный рычаг.  
- Круги **8–9** — не дверью с материка.
