# Бриф карты — Линдэван

Мелкий город-приют **у ручья**. Силуэт с региональной v11: **речной / песенный посад**.  
Тон: мягкий свет сквозь кроны, мох, верёвочные мостки, **не** спартанский плац.

## Композиция

- **Ручей** режет посад с запада на восток (или дугой): #1 мост → #10 переправа.  
- **Южный берег (открытое лицо):** #2 гостевой · #8 рынок · #9 ива · #3 сад · #4 зал · #5 купальни.  
- **Северный берег / корни (тень):** #6 архив · #7 Ухо · #11 Совет · #12 тайник (полускрыт).  
- **Вход с запада** (от Порога / развилки с Тириэласом): #1.  
- **Выход на восток** (стрелка Силвания / mq-03): #10.

## Тропы

Порог/развилка → #1 → #2/#9.  
#3 ↔ #4 ↔ #5.  
#4 ↔ #6 (ключи).  
#7 ↔ #11 ↔ #12.
