## Идея

**Тихий приют Леса:** знахари, медики, купальни, архив рецептов.  
Под пологом — **разведка** («Ухо Тишины»): слухи, агенты, тайники для раненых.  
Контраст **Тириэласу** (Спарта): здесь шьют, там куют.

## Кризис

Украден **Свиток Зелёного Шва** · убит глава разведки **Ваэлорн**.
