# Маяк душ — seed playbook

> Prep-сид для стола сессии 2 двери A. Полный скрипт бита: [`../../arcs/arc-3/quests/mq-01-sessions-1-2-detail.md`](../../arcs/arc-3/quests/mq-01-sessions-1-2-detail.md) §2.5–2.7.  
> **Не** Алтарь / Филактерий / Око. Side ниже — **не** spine mq-01.

## Паспорт

| Поле | Значение |
|---|---|
| Регион | План демонов за фиолетовым потоком |
| Масштаб | **site** — маяк + лагерь + пустошь у клеток |
| Власть | Нет; Сарель держит изгоев |
| Угроза | Сборщик Огарков (врок) — **основной** бой сессии; мелочь в клетках |
| Детализировано | 5 мест-сид + side q-mayak-01…03 |
| Заглушки | полная карта пустоши; Алтарный тракт |

## Атмосфера

Пепельно-багровая пустошь. Небо-синяк. Запах меди и горячего камня. Маяк — грязно-фиолетовый столб над клетками и цепями. Тихо. Слишком тихо.

## 5 фактов «сейчас»

1. Легион **бросил** маяк; жгут дальше у дымов.  
2. Изгои-тифлинги прячутся в остове клетки; нужен проводник = сделка/бой со Сборщиком (mq-01).  
3. В клетках ещё тлеют личные вещи пленных — топливо для side.  
4. Мелочь (импы / дретчи) иногда возвращается «подметать».  
5. Без Сарель каждый переход — Survival 16 (скрипт mq-01).

## Если партия медлит

1. Сборщик жрёт ещё одного безымянного изгоя.  
2. Кеш уходит в клетки один → ранен / пропал амулет глубже.  
3. Дымы ближе на горизонте (атмосфера, не бой Алтарного).
