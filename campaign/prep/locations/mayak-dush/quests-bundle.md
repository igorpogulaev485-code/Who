# q-mayak-01 — Амулет в клетке

## Hook (30 сек)

**Кеш** дрожит: в средней клетке остался **амулет сестры** — деревянный кружок с выжженным именем. Без него он «не помнит голос». Сарель орёт, что лезть в клетки до Сборщика — глупость. Можно сходить **тихо**, пока охотник у дымов.

## Якорь

| Поле | Значение |
|---|---|
| Место | Ряд клеток |
| Выдаёт | **Кеш** |
| Триггер | разговор в лагере до/после сделки со Сарель |

## Ставка

Личный долг изгоя. **Не** заменяет бой со Сборщиком и не даёт проводку.

| | |
|---|---|
| Успех | Амулет у Кеша; он стабильнее в бою (не паникует 1-й раунд) |
| Провал | Амулет сжёван импом / потерян; Кеш враждебен к «живым» |
| Игнор | Кеш лезет сам → 1к8 урона; амулет глубже |

## Цель

1. Достать амулет из клетки.  
2. Не поднять Сборщика раньше времени (если ещё не дрались).

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Стелс** | Stealth 14 между цепями | — | шум → 1× Dretch нюхает |
| **B · Сила** | Athletics 13 сорвать решётку | — | грохот; Сарель −тон |
| **C · Орра** | она знает «тихую» клетку; Insight 13 + просьба | — | отказ, пока не помогут с водой (q-02) |

## Моральный узел

На цепях рядом — амулет **другого** пленного с ещё тёплым именем. Взять оба = Кеш рад, но Орра: «чужое имя зовёт Сборщика». Оставить чужое = совесть.

## Сцены

| Узел | |
|---|---|
| Лагерь | Кеш |
| Клетки | поиск |
| Возврат | Сарель ворчит |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Шум | 1× **Dretch** | dnd.su — опционально |

## Награда

| | |
|---|---|
| Золото | 25–80 зм (всё, что Кеш спрятал) |
| Прочее | Кеш: помощь в бою (Dodge / Help раз в бой) |
| `xp_quest` | 300–600 |

## Репутация

| Кеш / изгои | + успех | − если бросили его лезть одного |
| Сарель | нейтрал / − шум | − если разбудили охоту рано |

## Liveliness

Игнор: Кеш ранен; в бою со Сборщиком он **не** помогает.

## Связка

Можно до или после Сборщика. Не блокирует проводку.

# q-mayak-02 — Чаша без влаги

## Hook (30 сек)

**Орра** у основания маяка: руна «жажды» трещит — в плане нет воды, но **ритуальная влага** ещё теплится в треснувшей чаше у круга приземления. Если чашу не «напоить» (кровь демона / святая вода с Материала / слёзы изгоя), руна вспыхнет и выдаст лагерь дымам. Это не Сборщик и не Алтарь.

## Якорь

| Поле | Значение |
|---|---|
| Место | Чаша у круга · руна на остове |
| Выдаёт | **Орра** |
| Триггер | осмотр маяка; Arcana 13; или Орра зовёт после знакомства |

## Ставка

Локальная стабильность лагеря. Отголосок Разлома; spine mq-01 не двигает.

| | |
|---|---|
| Успех | Руна спит; лагерь не «светится» для мелочи 1 сутки |
| Провал | Вспышка → +1 dretch в следующем столкновении / у Сборщика |
| Игнор | То же, что провал, через короткое время у стола |

## Цель

1. Добыть «влагу» для чаши.  
2. Провести короткий ритуал с Оррой у руны.

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Кровь дретча** | убить мелочь у клеток; наполнить чашу | бой | шум |
| **B · Святая вода / кислота** | из инвентаря Материала | — | нет предмета → A/C |
| **C · Слеза изгоя** | Persuasion 14 у Кеша/Сарель; цена — секрет ПК | — | отказ; руна злится |

## Моральный узел

Орра предлагает каплю **своей** крови (бывший культист): сработает, но она потеряет связь с «тихими» рунами на сессию (не поможет читать маяк). Принять = успех ценой её силы.

## Сцены

| Узел | |
|---|---|
| Чаша | круг 1 |
| Руна | остов 4 |
| Клетки | добыча крови |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Добыча | 1–2× **Dretch** | dnd.su |

## Награда

| | |
|---|---|
| Золото | 40–100 зм |
| Прочее | Орра: Advantage на **один** Arcana у маяка; или *bead* с 1 зарядом *spare the dying* вкуса |
| `xp_quest` | 400–700 |

## Репутация

| Орра | + | − если насмеялись над руной |
| Сарель | + тихий лагерь | − если вспышка привлекла охоту |

## Liveliness

Игнор: руна вспыхивает в бою со Сборщиком — dim light → bright на 1 раунд (помеха Stealth; +видимость для дретчей).

## Связка

Хорошо **до** боя со Сборщиком. Не даёт проводку сама по себе.

# q-mayak-03 — Кости имён

## Hook (30 сек)

**Сарель** цедит: мелкий имп **Визг** таскает из клеток **кости с вырезанными именами** — топливо для костров у дымов. Каждый унесённый набор = ещё один «забытый» изгой. Остановить Визга — услуга лагерю, не карта к Алтарному тракту.

## Якорь

| Поле | Значение |
|---|---|
| Место | Клетки → тропа к дымам |
| Выдаёт | **Сарель** / сами видят Визга (Perception 13) |
| Триггер | после приземления; или между сделкой и боем |

## Ставка

Сохранить имена/кости изгоев. Мягкий удар по снабжению мелочи у дымов — **не** осада Алтарного.

| | |
|---|---|
| Успех | Кости возвращены; Визг мёртв/изгнан; +Сарель |
| Провал | Визг уносит груз к дымам; лагерь −мораль |
| Игнор | Ещё 1к3 «имени» исчезают к клиффу |

## Цель

1. Перехватить Визга с мешком костей.  
2. Вернуть кости Орре/Сарель **или** сжечь честно на месте (мораль).

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Охота** | Survival 14 след; бой с импом | — | уходит к 5 |
| **B · Сделка** | Визг: «ещё одна душа-секрет» за мешок | Deception/Persuasion 15 | врёт и кусает |
| **C · Засада у тропы** | Stealth 15 у края 5 | — | 2× dretch с импом |

## Моральный узел

Среди костей — череп с руной культа Орры. Вернуть ей = боль + прощение; отдать Сарель без слов = Орра уйдёт из лагеря за кадром; разбить = «освобождение», −Орра.

## Сцены

| Узел | |
|---|---|
| Клетки | кража |
| Пустошь | след |
| Тропа 5 | перехват |
| Лагерь | возврат |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Визг | **Imp** | dnd.su «Бес» |
| Засада | + 1–2× **Dretch** | dnd.su |

## Награда

| | |
|---|---|
| Золото | 80–200 зм (в мешке мелочь легиона) |
| Предмет | редко: *кость-оберег* (uncommon: 1/день Resistance necrotic 1 мин) |
| `xp_quest` | 800–1200 |

## Репутация

| | Успех | Провал |
|---|---|---|
| Сарель / изгои | + | − |
| Орра | + если вернули её череп честно | − разбили / скрыли |
| Дымы (фон) | мелочь злее на 1 вставку позже | + снабжение |

## Liveliness

Игнор: Визг возвращается с «друзьями» в случайной вставке пустоши (+imp).

## Связка

Не открывает Алтарь. Можно параллельно с q-mayak-01. Сборщик (mq-01) — отдельный стол.
