# q-kupel-01 — Фокус из обвала

## Hook (30 сек)

**Илвесс** в лазарете (обожжён плетением) шепчет: в обвале архива остался его **хрустальный фокус** — без него он «глух» к рунам. Маги запечатают крыло к вечеру. Это не про одобрение входа и не про Маяк.

## Якорь

| Поле | Значение |
|---|---|
| Место | Купель — лазарет / обрушенное крыло архива |
| Выдаёт | **Илвесс** (или сестра-лекарь **Нинаэ** у носилок) |
| Триггер | осмотр раны / разговор с обожжёнными (бит 2.2) |

## Ставка

Локальный долг Купели. **Не** двигает mq-01 spine (Алтарь / Филактерий / Око).

| | |
|---|---|
| Успех | Фокус у Илвесса; +реп магов Купели (мелочь) |
| Провал | Фокус разбит / украден культистом; Илвесс в отчаянии |
| Игнор | Крыло запечатано; фокус «съеден» пылью раны за кадром |

## Цель

1. Достать фокус из обвала **до** печати крыла.  
2. Не сорвать руны сдерживания и не привлечь выброс.

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Лаз** | Athletics 13 + Acrobatics 12 под балками | — | 1к6 дробящего; шум → внимание Ваэры |
| **B · Магия** | Mage Hand / *mage hand*-эквивалент; Arcana 14 навести | — | фокус соскальзывает глубже |
| **C · Торг с Нинаэ** | она знает ход слуг; Persuasion 13 + обещание «не рвать руны» | — | отказ; только A/B |

## Моральный узел

В пыли рядом — чужой дневник-обрывок с именем живого из низа города. Отдать Дозору = донос; оставить = совесть; сжечь = Илвесс спокоен, но улика mq-05/культа теряется (не обязательно для mq-01).

## Сцены

| Узел | Где |
|---|---|
| Лазарет | Илвесс / Нинаэ |
| Обвал | балки, пыль серебра |
| Печать | маг с воском у входа в крыло |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Обвал (опц.) | 1× **Quasit** (засел в пыли) | dnd.su «Квазит» — только если шумели / рвали руны |

## Награда

| | |
|---|---|
| Золото | 50–120 зм (дар Нинаэ / Илвесса) |
| Прочее | Илвесс: 1× совет по сгусткам прохода (Advantage на **один** Int-сейв прохода, если ещё не вошли) |
| `xp_quest` | 400–700 |

## Репутация

| | Успех | Провал |
|---|---|---|
| Элиан / маги Купели | + мелочь | − если рвали руны |
| Ваэра | нейтрал / − шум у рун | − если бой у печати |

## Liveliness

Игнор до печати: фокус потерян; Илвесс отказывается говорить о проходе.

## Связка

Не пересекается с одобрением Элиана. Можно закрыть **до** бита 2.3.

# q-kupel-02 — Кровь на руне

## Hook (30 сек)

**Ваэра** указывает копьём на ступень: свежая **кровь** на руне сдерживания. Не партии — паломник или вор. Пока кровь «поёт», края раны дрожат сильнее. Нужно найти виновного и **очистить** руну — без штурма Купели и без смены потока.

## Якорь

| Поле | Значение |
|---|---|
| Место | Ступени / руны у раны |
| Выдаёт | **Ваэра Ночной Клинок** (или Элиан, если Ваэра молчит) |
| Триггер | Perception 14 у ступеней; или Ваэра останавливает партию после одобрения |

## Ставка

Мягкий отголосок Разлома: кровь усиливает дрожь. **Не** открывает Алтарь и не меняет маршрут к Маяку.

| | |
|---|---|
| Успех | Руна чиста; Ваэра чуть мягче; помеха на Con в проходе **не** копится от крови на ступенях |
| Провал | Руна трескается; при открытии потока +1 дретч в выбросе |
| Игнор | К вечеру дрожь слышна на периметре Дозора |

## Цель

1. Найти, кто оставил кровь.  
2. Очистить руну (ритуал / вода Купели / огонь дроу-клятвы).

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Сыск** | След босых ног → лазарет / двор | Investigation 14; Survival 13 | ложный след → обвиняют лекаря |
| **B · Очистка** | Religion/Arcana 14 с Ваэрой | — | 1к4 force; повтор; шум |
| **C · Признание** | Найти **Торвена** (паломник-вор) — Persuasion 15 / Intimidation 14 | — | он бежит в низ; кровь остаётся |

## Моральный узел

Торвен резал ладонь «чтобы Зеркало услышало умершую сестру». Сдать Ваэре = порка/изгнание; отпустить после очистки = Ваэра узнает позже (−); солгать «это случайность» = Insight Ваэры 16.

## Сцены

| Узел | |
|---|---|
| Ступени | кровь / руна |
| Двор Купели | след |
| Кладовка слуг | Торвен прячется |
| Ритуал | очистка с Ваэрой |

## Противники

Обычно нет. Если Торвен в панике дерётся — **Commoner** с ножом; Ваэра вмешается на 2-м раунде.

## Награда

| | |
|---|---|
| Золото | 0–80 зм |
| Прочее | Ваэра: кивок = +1 к тону при **повторном** входе в Купель; Элиан спокойнее на 2.3 |
| `xp_quest` | 400–800 |

## Репутация

| | Успех | Провал |
|---|---|---|
| Ваэра / дроу-хранители | + | − |
| Торвен / низы | + если отпустили честно | − сдача без суда |

## Liveliness

Игнор: +1 дретч при следующем открытии фиолетового; слух «герои не чистят кровь» у Дозора.

## Связка

Лучше **до** или сразу после одобрения, **до** заплыва. Не блокирует mq-01.
