# Бриф — атлас 5 государств плана мёртвых

**Статус:** геометрия LOCKED · имена государств — **draft** (опрос [`survey-dead-plane-state-names-v1.md`](../../plot/survey-dead-plane-state-names-v1.md)).  
После ok имён → отрисовка → LOCK.

## Иерархия (не путать)

```
Атлас (этот бриф)
 └─ 5 государств-островов     ← крупные подписи
     └─ города внутри         ← НЕ рисовать (кроме микро-Причала)
```

Пайплайн позже: **атлас государств → карта государства → города** (как Серый Причал уже LOCKED).

## Layout (просторный spine)

Цепь **слева → направо** (или лёгкая дуга СЗ→ЮВ) по пепельному морю:

| # | Подпись (draft) | Роль на картинке |
|---:|---|---|
| 1 | **Берег Памяти** | входной остров; **микроточка** «Серый Причал» у берега раны |
| 2 | **Край** | следующий остров по цепи; без лагерей/НПС |
| 3 | **Молчаливая Коса** | узкий/длинный силуэт острова-ступени |
| 4 | **Нижние Дворы** | дальний именованный край |
| 5 | **Второй Берег** | самый дальний / намёк на акт D |

Между соседями — **пунктир переправ** + мелкие лодки/паромы (без имён капитанов).

## Среда

- **Пепельное море** — серо-зольная вода/туман между островами (не «океан с волнами»).  
- Небо без звёзд, свет снизу — тон **Серого Причала**.  
- **Не** рисовать: план демонов, бурю Кардиана как регион, Велиана, пятёрку, Лайру, имена диверсий.

## Стиль

Как обзор демонов **v24** / Причал: читаемые подписи, один композиционный план, без коллажа карточек.  
Отличие от демонов: **не** кольца — **архипелаг** в пепле.
