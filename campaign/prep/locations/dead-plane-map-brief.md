# Бриф — атлас 5 государств плана мёртвых

**v1 нарисован** → [`dead-plane-map.md`](dead-plane-map.md) · asset `assets/maps/dead-plane/dead-plane-atlas-v1.png`  
Ждём ok мастера → LOCK.

## Иерархия

```
Атлас
 └─ 5 государств-островов     ← крупные подписи
     └─ города                ← НЕ рисовать (кроме микро-Причала)
```

## Layout (просторный spine, Л→П)

Цепь по **пепельному морю**, лёгкая дуга СЗ→ЮВ:

| # | Подпись | Силуэт / роль |
|---:|---|---|
| 1 | **Берег Памяти** | самый левый/входной остров; **микроточка** + мелкая подпись «Серый Причал» у северного/входного берега |
| 2 | **Край** | следующий остров по цепи, чуть южнее/восточнее |
| 3 | **Молчаливый Пролив** | узкий/вытянутый остров-ступень (проливная форма) |
| 4 | **Вечный Путь** | средний-дальний остров; можно намекнуть длинным берегом/грядой |
| 5 | **Устье Забвения** | самый дальний справа/внизу — намёк на акт D |

Между соседями: **пунктир переправ** + 1–2 мелкие лодки/паромы (без подписей).

## Среда

- Пепельное море — серо-зольная вода/туман (не яркий океан).  
- Небо без звёзд, свет снизу — тон Серого Причала.  
- **Не** рисовать: демонов, бурю Кардиана, НПС, лагеря, второй город детально.

## Стиль

Как атлас демонов v24 + тон карты Причала: читаемые кириллические подписи, один план, без карточек/коллажа.  
Архипелаг, **не** кольца.
