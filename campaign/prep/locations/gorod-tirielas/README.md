## Идея

**Спарта Леса:** город подготовки **элитной** армии Хранителей. Основа строя — **жрецы · друиды · следопыты**. Дисциплина, общие пайки, испытания, клятвы. Не тяжёлая «стена» (паспорт Леса) — а кузня, без которой Лес не войдёт в войну готовым.
