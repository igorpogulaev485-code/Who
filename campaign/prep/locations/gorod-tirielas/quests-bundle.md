# q-tir-01 — Где мастер следопытов

## Hook (30 сек)

**Нимраэль** (или Каэнор) коротко: «Лиэсса Безлунная пропала. Без неё полевые учения — мясо. Найдите — или строй войдёт в войну слепым.»

## Якорь

| Поле | Значение |
|---|---|
| Место | #8 · #4 · #2 · восточная тропа |
| Выдаёт | **Каэнор** (приказ) / **Нимраэль** (мольба) / **Таэрис** (если надавить) |
| Триггер | слух у Саэриса · пустой гамак · приказ с #11 |

## Ставка

| | |
|---|---|
| Успех | Лиэсса возвращается (или её улики); учения оживают; нитка к mq-03/печатям |
| Провал | Таэрис ломает роту травмами; Лиэссу перехватывают враги |
| Игнор | через 3 дня след холодеет; Каэнор закрывает восток без проводников |

## Цель

1. Узнать, куда ушла Лиэсса и почему молчали.  
2. Найти её или неопровержимую улику.  
3. Решить: вернуть строю сразу или дать добить её разведку.

## Пути решения (≥2)

| Путь | Суть | Проверки (5e 2014) | Провал пути |
|---|---|---|---|
| **A · След** | #8 → #4 → восточная тропа | Survival 14 → Perception 13 | ложный след к Дуатласу |
| **B · Давить Таэриса** | он видел уход | Insight 14 / Intimidation 15 | Каэнор злится за самоуправство |
| **C · Дневник** | у Саэриса | Persuasion 13 / Sleight 14 | Саэрис запирает двор |
| **D · Сделка с Вирэной** | «её послал Совет?» | Persuasion 15 | Вирэна врёт убедительно |

## Моральный узел

Вернуть Лиэссу **сейчас** (строй цел) или дать ей **добить разведку** чужих печатей (риск смерти, выигрыш для mq-03).

## Карта сцен

| Узел | Где | Зачем |
|---|---|---|
| Стан | #8 | гамак, карты |
| Кроны | #4 | сигнал / след каната |
| Двор | #2 | дневник |
| Архистратиг | #11 | приказ / таймер |
| Восточная тропа | за городом | засада / встреча |
| Лагерь слежки | чаща | Лиэсса или её плен |

## Противники

| Сцена | Кто | Статы | |
|---|---|---|---|
| Тропа | 2× scout + 1 spy | dnd.su | ячейка / наёмники печатей |
| Плен | spy leader | dnd.su «Шпион» | опц. бой |

## Награда

| Тип | Что | Тир |
|---|---|---|
| Золото | 80–150 зм (или пайки строю) | session |
| Предмет | 1× *зелье скорости* **или** карта восточных троп | ok |
| Репутация | строй ++ · soft снятие колючек −4 | |
| Доступ | проводник Лиэссы/Таэриса на восток | mq-03 |

`xp_quest`: 700–1100

## Репутация

| | Успех | Провал |
|---|---|---|
| Каэнор / строй | ++ | −− |
| Нимраэль | предан | отчаивается |
| Вирэна | − если обошли | + если сдали ей инициативу |

## Провал / таймер

| Срок | Эффект |
|---|---|
| 2 дня | приказ Каэнора: закрыть восток |
| 3 дня | след Лиэссы → плен / уход глубже |

## Liveliness

Без партии Таэрис ведёт учения — 1d4 курсантов травмированы; Лиэссу находят враги первыми.

## Связка

Открывает/усиливает **q-tir-04** (печати) и **q-tir-05** (право на восток).

# q-tir-02 — Печать, которая держит копья

## Hook (30 сек)

**Каэнор** через зубы: «Резерв смолы и пайков закрыт **печатью Совета**. Вирэна улыбается. Без резерва строй — голодные палки. Снимите печать — как угодно, кроме убийства посланницы.»

## Якорь

| Поле | |
|---|---|
| Место | #11 · #1 · #10 |
| Выдаёт | **Каэнор** / **Фаэлин** (в панике) |
| Триггер | отказ выдачи на складе · сцена спора |

## Ставка

| | |
|---|---|
| Успех | резерв открыт **или** найден законный обход; строй дышит |
| Провал | Вирэна уезжает с печатью на неделю |
| Игнор | учения встают; дезертирство курсантов |

## Цель

1. Понять, *чья* воля задерживает квоту.  
2. Снять блок: сделка, компромат, давление Совета, ритуал.  
3. Не превратить Тириэлас в мятеж против Силвании.

## Пути

| Путь | Суть | Проверки | Провал |
|---|---|---|---|
| **A · Сделка** | услуга Вирэне (слух/долг) | Persuasion 14 | цена слишком грязная |
| **B · Компромат** | строка Фаэлина + Телран | Investigation 14 · Insight 13 | Фаэлин жжёт книги |
| **C · Закон клятвы** | Руваэла: печать vs клятва строя | Religion 14 · Persuasion 15 | Вирэна игнорирует святилище |
| **D · Давление** | угроза Каэнора «идти без Совета» | Intimidation 16 (с Каэнором) | Вирэна объявляет мятеж слухом |

## Моральный узел

Открыть резерв **ценой долга Совету** (Вирэна потом держит партию) или **подставить Вирэну** (строй свободен, враг в Силвании).

## Карта сцен

| Узел | Где |
|---|---|
| Спор | #11 |
| Склад | #10 |
| Ворота | #1 |
| Святилище | #12 |
| Письмо/курьер | тропа к Силвании (намёк) |

## Противники

| | | |
|---|---|---|
| Охрана Вирэны | 2× guard | если силовое |
| Курьер | spy | если перехват письма |

## Награда

| | | |
|---|---|---|
| Золото | 100–200 зм / лист-марки | session |
| Предмет | нет легендарок | |
| Репутация | Каэнор ++ · Вирэна ± | |
| Доступ | резерв открыт → ускоряет q-tir-03/05 | |

`xp_quest`: 600–1000

## Репутация

| | Успех (сделка) | Успех (компромат) | Провал |
|---|---|---|---|
| Каэнор | + | ++ | −− |
| Вирэна / Совет | ++ долг | враг | уезжает победителем |
| Фаэлин | − | спасён/сломлен | прячется |

## Таймер

| 2 дня | Вирэна готовит отъезд |
| 3 дня | печать уходит из Эллуэнара |

## Liveliness

Без партии Каэнор почти поднимает строй «без печати» — слух о мятеже доходит до Силвании.

## Связка

Блокирует полный успех **q-tir-03**; усиливает давление на **q-tir-05**.

# q-tir-03 — Пустые миски Агогэ

## Hook (30 сек)

На складе **Фаэлин** бледнеет: «Пайков на три дня меньше, чем в книге. Курсанты уже делят сухари. Найдите дыру — или Бреннол получит голодный бунт.»

## Якорь

| | |
|---|---|
| Место | #10 · #5 · #3 |
| Выдаёт | **Фаэлин** / **Бреннол** / **Даэлор** |
| Триггер | пустая полка · драка из‑за пайка |

## Ставка

| | |
|---|---|
| Успех | дыра найдена (кража / печать / порча груза); выдачу восстанавливают |
| Провал | голод → травмы на плацу → дезертиры |
| Игнор | через 2 дня учения встают |

## Цель

1. Сверить книги и бочки.  
2. Найти виновного **или** системную причину (Вирэна / саботаж / вор).  
3. Вернуть паёк строю без погрома склада.

## Пути

| Путь | Суть | Проверки | Провал |
|---|---|---|---|
| **A · Аудит** | книги Фаэлина | Investigation 14 | ложный виновный-курсант |
| **B · След груза** | тропа каравана | Survival 13 · Persuasion 12 | засада на тропе |
| **C · Даэлор** | разбавленная еда/смола | Nature/Medicine 13 | отравление сыщика |
| **D · Ночь у склада** | поймать вора | Stealth 14 · Perception 14 | стража принимает партию за воров |

## Моральный узел

Виноват **Фаэлин** (подделал под Вирэну) — сдать Каэнору или вытянуть сделку и сохранить снабженца.

| Казармы | #5 |
| Плац (голодный бой) | #3 |
| Тропа каравана | запад к Порогу |
| Дом Архистратига | отчёт |

## Противники

| | | |
|---|---|---|
| Воры пайков | 3× bandit | опц. |
| Наёмники на тропе | 2× thug | если груз увели |

## Награда

| | | |
|---|---|---|
| Золото | 60–120 зм | session |
| Предмет | 2× ration special / antitoxin | |
| Репутация | строй + · курсанты + | |
| Доступ | Фаэлин открывает «серый» запас | |

# q-tir-04 — Чужая смола на древках

## Hook (30 сек)

**Орвел** суёт обломок копья: «Это не наша смола. На плацу дважды ломалось в одном месте. Кто-то учит нас умирать заранее.»

## Якорь

| | |
|---|---|
| Место | #3 · #10 · #1 |
| Выдаёт | **Орвел** / **Бреннол** / **Даэлор** |
| Триггер | поломка на плацу · слух Даэлора |

## Ставка

| | |
|---|---|
| Успех | саботажник найден; учебный бой снова безопасен; нитка к поддельным печатям Порога / mq-03 |
| Провал | тяжёлая травма курсанта; паника |
| Игнор | «несчастный случай» на показательном испытании |

## Цель

1. Доказать саботаж (не «плохая партия смолы»).  
2. Найти кто и зачем.  
3. Решить: публичный суд строя или тихая зачистка.

## Пути

| Путь | Суть | Проверки | Провал |
|---|---|---|---|
| **A · Алхимия** | сравнить смолу Даэлора | Investigation 14 · Nature 13 | ложный след на Даэлора |
| **B · Журнал дежурств** | Орвел «не должен был быть» | Investigation 13 | Орвела наказывают вместо врага |
| **C · Ночь** | слежка у склада/плаца | Stealth 15 | бой с саботажниками |
| **D · Печати** | связь с подделками с Порога | Insight 14 у Илуэна | уводит в город Порога надолго |

## Моральный узел

Саботажник — **курсант под шантажом** (спасти и завербовать) или **чужой агент** (сдать Каэнору / допросить для mq-03).

# q-tir-05 — Испытание Копья-Листа

## Hook (30 сек)

**Каэнор** (или **Руваэла**): «Хотите проводников на восток и уважение строя — пройдите **Испытание**. Не цирк для гостей. Клятва. Боль. Если солжёте клятве — Лес запомнит.»

Жёсткий мост в **mq-03**: без метки строя восточная тропа — «чужие с −4».

## Якорь

| | |
|---|---|
| Место | #9 · #12 · #3 |
| Выдаёт | **Каэнор** · **Руваэла** |
| Триггер | после услуги строю (01–04) **или** если сами просят восток |

## Ставка

| | |
|---|---|
| Успех | клятва принята; проводник + письмо Каэнора на восток; soft −4 → уважение здесь |
| Провал | публичный стыд; восток закрыт; строй не даёт людей |
| Игнор | mq-03 на восток идёт без элиты Тириэласа |

## Цель

1. Пройти три круга испытания (тело · дух · клятва).  
2. Выбрать текст клятвы: короткий Каэнора или полный Руваэлы.  
3. Получить право вести/просить строй на путь mq-03.

## Пути / круги

| Круг | Суть | Проверки / бой | Провал круга |
|---|---|---|---|
| **1 · Тело** | плац: выдержать строй / спарринг | Athletics 14 · Con 12 · или бой vs Бреннол (несмертельно) | позор; повтор завтра |
| **2 · Дух** | роща/круг: правда о −4 и целях | Insight/Religion 13 · честный разговор | Ориэн/Телран отказывают |
| **3 · Клятва** | #12 при свидетелях | Persuasion 12 + выбор текста | клятва «пустая» — нет проводника |

Альтернатива силе: **чемпион** (один ПК) + остальные помогают навыками.

## Моральный узел

Клятва **Каэнора** (быстрее в войну, короче текст) vs клятва **Руваэлы** (полная, обязывает не стать «солдатами чужой короны») — влияет на то, как строй пойдёт в mq-03.
