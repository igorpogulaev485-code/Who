# q-tir-03 — Пустые миски Агогэ

## Hook (30 сек)

На складе **Фаэлин** бледнеет: «Пайков на три дня меньше, чем в книге. Курсанты уже делят сухари. Найдите дыру — или Бреннол получит голодный бунт.»

## Якорь

| | |
|---|---|
| Место | #10 · #5 · #3 |
| Выдаёт | **Фаэлин** / **Бреннол** / **Даэлор** |
| Триггер | пустая полка · драка из‑за пайка |

## Ставка

| | |
|---|---|
| Успех | дыра найдена (кража / печать / порча груза); выдачу восстанавливают |
| Провал | голод → травмы на плацу → дезертиры |
| Игнор | через 2 дня учения встают |

## Цель

1. Сверить книги и бочки.  
2. Найти виновного **или** системную причину (Вирэна / саботаж / вор).  
3. Вернуть паёк строю без погрома склада.

## Пути

| Путь | Суть | Проверки | Провал |
|---|---|---|---|
| **A · Аудит** | книги Фаэлина | Investigation 14 | ложный виновный-курсант |
| **B · След груза** | тропа каравана | Survival 13 · Persuasion 12 | засада на тропе |
| **C · Даэлор** | разбавленная еда/смола | Nature/Medicine 13 | отравление сыщика |
| **D · Ночь у склада** | поймать вора | Stealth 14 · Perception 14 | стража принимает партию за воров |

## Моральный узел

Виноват **Фаэлин** (подделал под Вирэну) — сдать Каэнору или вытянуть сделку и сохранить снабженца.
