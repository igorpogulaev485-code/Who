# q-porog-02 — Не трогай камень

## Hook (30 сек)

Тэвин в панике: кто-то из гостей (или любопытный служитель) почти вынул **обратный камень** Леса из ниши. Без него линия домой молчит. Нужно вернуть порядок и понять, **зачем** тянули.

## Якорь

| Поле | Значение |
|---|---|
| Место | Площадка Порога |
| Выдаёт | **Тэвин Счётчик Чаш** (или Оррен) |
| Триггер | Perception у арки / Тэвин орёт / камень чуть сдвинут |

## Ставка

| | |
|---|---|
| Успех | Камень закреплён; правила обратного пути ясны партии |
| Провал | Камень вынут → линия домой мертва, пока не позовут хранителей Леса (дни) |
| Игнор | Случайный NPC сдвигает камень за кадром к утру |

## Цель

1. Закрепить камень в нише (ритуал Тэвина + руки, которые не дрожат).  
2. Выяснить мотив «кто тянул».

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Ритуал** | Тэвин ведёт; ПК помогает | Arcana/Religion 13 | 1к4 force; повтор |
| **B · Сыск** | Кто сдвинул: слуга / ПК / гость | Investigation 14; Insight 13 | ложное обвинение (−реп) |
| **C · Охрана** | Оррен ставит печать-клятву «не трогать» | — | — |

## Моральный узел

Если тянул союзник «на всякий случай унести» — признаться Тэвину или спрятать.

## Сцены

| Узел | |
|---|---|
| Ниша | камень на ребре, серебро трещит |
| Допрос | Мирэла видела тень у арки |
| Печать | Оррен выжигает знак гостя на коре |
