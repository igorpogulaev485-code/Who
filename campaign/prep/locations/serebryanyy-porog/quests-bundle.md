# q-porog-01 — Свиток, которого нет

## Hook (30 сек)

Илсара не пускает дальше чая, пока нет **гостевого свитка**. Кавил — адъютант, но Порог требует бумагу Леса или равноценное поручительство. Без этого — «незваные» навсегда в глазах двора.

## Якорь

| Поле | Значение |
|---|---|
| Место | Зал гостевых имён |
| Выдаёт | **Илсара Пепельнолист** |
| Триггер | Партия отказалась записаться / Илсара упёрлась в протокол |

## Ставка

| | |
|---|---|
| Успех | Гостевой статус; подсказки mq-03 без холода |
| Провал | Провожают к тропам **без** указаний; двор узнаёт «хамы с моста» |
| Игнор | Ночёвка запрещена; Саэла не ведёт |

## Цель

1. Закрыть дыру протокола (свиток / поручительство / исключение).  
2. Не оскорбить обычай Порога.

## Пути (≥2)

| Путь | Суть | DC | Провал пути |
|---|---|---|---|
| **A · Кавил** | Печать Теневого Совета + объяснение линии | Persuasion 14 / показать знаки | Илсара: «Совет ≠ Лес» → нужен путь B/C |
| **B · Временный свиток** | Мирэла пишет «Незваные приняты под клятвой» | Insight 13 + обещание не лгать о цели | клятва ломается позже = −реп |
| **C · Услуга** | Закрыть q-porog-02 или принести весть двору | время | задержка |
| **D · Сила** | Запугать | Intimidation 17 | Оррен + статус сожжён |

## Моральный узел

Солгать о цели визита (король / совет / шпионаж) ради свитка — Мирэла позже «вспомнит» чернила.

## Сцены

| Узел | |
|---|---|
| Пюпитр | пустой; запах старого лака |
| Спор Тэвина | «Без чаши и свитка — не гости» |
| Мирэла | предлагает временный свиток за правду |

## Противники

Обычно нет. Если D — Оррен (Guard).

## Награда

| | |
|---|---|
| Золото | 0 |
| Прочее | гостевой статус; +Илсара |
| `xp_quest` | 200–400 |

## Репутация

| | + | − |
|---|---|---|
| Служители Порога | закрыли протокол честно | сила / ложь |
| Двор Силвании | — | гонец узнал о скандале |

## Liveliness

Без решения к утру: Илсара шлёт гонца в Силванию «проверить незваных».

## Связка

| | |
|---|---|
| mq-03 | мягче выдаёт подсказки после статуса |
| q-porog-02 | может закрыть путь C |

# q-porog-02 — Не трогай камень

## Hook (30 сек)

Тэвин в панике: кто-то из гостей (или любопытный служитель) почти вынул **обратный камень** Леса из ниши. Без него линия домой молчит. Нужно вернуть порядок и понять, **зачем** тянули.

## Якорь

| Поле | Значение |
|---|---|
| Место | Площадка Порога |
| Выдаёт | **Тэвин Счётчик Чаш** (или Оррен) |
| Триггер | Perception у арки / Тэвин орёт / камень чуть сдвинут |

## Ставка

| | |
|---|---|
| Успех | Камень закреплён; правила обратного пути ясны партии |
| Провал | Камень вынут → линия домой мертва, пока не позовут хранителей Леса (дни) |
| Игнор | Случайный NPC сдвигает камень за кадром к утру |

## Цель

1. Закрепить камень в нише (ритуал Тэвина + руки, которые не дрожат).  
2. Выяснить мотив «кто тянул».

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Ритуал** | Тэвин ведёт; ПК помогает | Arcana/Religion 13 | 1к4 force; повтор |
| **B · Сыск** | Кто сдвинул: слуга / ПК / гость | Investigation 14; Insight 13 | ложное обвинение (−реп) |
| **C · Охрана** | Оррен ставит печать-клятву «не трогать» | — | — |

## Моральный узел

Если тянул союзник «на всякий случай унести» — признаться Тэвину или спрятать.

## Сцены

| Узел | |
|---|---|
| Ниша | камень на ребре, серебро трещит |
| Допрос | Мирэла видела тень у арки |
| Печать | Оррен выжигает знак гостя на коре |

## Противники

Нет (или 1× **Shadow** если мастер хочет «чужой» след — редко; не Орден-вторжение).

## Награда

| | |
|---|---|
| Золото | 25–50 зм (благодарность Тэвина) |
| Прочее | знание: обратный путь = камень + хранители **с обеих** сторон |
| `xp_quest` | 200–400 |

## Репутация

| | + | − |
|---|---|---|
| Тэвин/Оррен | помогли | трогали камень тайком |

## Liveliness

Игнор 1 ночь → камень «гуляет»; утро без линии домой.

## Связка

| | |
|---|---|
| q-portal-stone | парный камень на мосту уже найден в с.2 |
| mq-03 | без обратного камня уезд дороже |
| q-porog-01 | услуга для свитка |

# q-porog-03 — Письмо в Силванию

## Hook (30 сек)

Илсара: двор **должен** узнать о незваных с Лунного моста — гостевой обычай. Можно отнести **письмо-печать** в **Силванию** самим (первая дорога) или отпустить гонца и остаться. Если сами — получаете проводника на первый отрезок и мягкий вход к воротам столицы.

## Якорь

| Поле | Значение |
|---|---|
| Место | Двор чаш → тропа «лист в кольце» |
| Выдаёт | **Илсара** / **Саэла** |
| Триггер | После записи имён; перед уходом к Силвании |

## Ставка

| | |
|---|---|
| Успех (сами) | +реп двора; Саэла ведёт N часов; ворота Силвании «Порог записал» |
| Успех (гонец) | двор узнаёт без партии; встреча в столице холоднее |
| Провал | письмо потеряно / вскрыто → подозрение шпионажа |
| Игнор | гонец сам; −1 к соц. в Силвании при первой встрече |

## Цель

1. Доставить печать Илсары до пункта передачи (застава гонцов **или** ворота Силвании).  
2. Не вскрывать / не подменять текст.

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Дорога** | Идти с Саэлой по знаку листа | Survival 12 ориентир; 1 вставка леса | заблудились +1 день |
| **B · Гонцы** | Догнать/передать на полпути | Athletics 13 / Persuasion 12 | гонец ушёл без вас |
| **C · Подмена** | Вскрыть и править | Sleight of Hand 15; Insight Мирэлы 14 | скандал |

## Моральный узел

В письме честно написано «незваные, портал, Кавил». Сгладить правду = легче соц. в столице, но Илсара узнает по ответу двора.

## Сцены (карта)

| Узел | |
|---|---|
| Двор | печать в серебряном тубусе |
| Тропа листа | мох, указатели |
| Застава гонцов | смена; проверка гостей |
| Ворота Силвании | клифф в столицу *(playbook столицы — позже)* |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Тропа (опц.) | 2× **Scout** (бандиты опушки, не Орден-армия) | dnd.su |
| Или | 1× **Awakened Tree** / dryad test | если свернули в глушь |

## Награда

| | |
|---|---|
| Золото | 100–250 зм (дар двора / Илсары) |
| Прочее | мягкий вход в Силванию; Саэла как проводник 1 переход |
| `xp_quest` | 800–1500 |

## Репутация

| | + | − |
|---|---|---|
| Двор Силвании | доставили целым | вскрыли / потеряли |
| Порог | уважение | — |

## Таймер

Гонец Илсары уходит через **1 короткий отдых**, если партия не берёт письмо.

## Liveliness

Без партии: гонец доходит; двор ждёт «героев» с досье незваных.

## Связка

| | |
|---|---|
| mq-03 | естественный мост к акту «Силвания» |
| q-porog-01 | проще, если уже гости |
