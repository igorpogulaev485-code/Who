# q-prichal-01 — Имя на трещине

## Hook (30 сек)

На площади плита с **стёртым именем**. Лайра кивает: «Живые иногда чинят то, что мёртвые боятся трогать.» Илса плачет у скамьи — имя сестры. В Низах Гретта знает, *куда* уходят стёртые… за цену.

## Якорь

| Поле | Значение |
|---|---|
| Место | Площадь Угасших Имён · Нижний двор Пепла |
| Выдаёт | **Лайра** / **Илса** / заказ **Орвеля** |
| Триггер | Perception трещины; или Илса просит |

## Ставка

Чистый локальный долг памяти. **Не** двигает Велиана / Кардиана / mq-04 spine.

| | |
|---|---|
| Успех | Имя восстановлено на плите; Илса спокойна; +реп площади |
| Провал | Имя уходит в Низы навсегда; Илса враждебна к «живым» |
| Игнор | Трещина растёт; через день плита «съедена» |

## Цель

1. Узнать полное имя / получить табличку.  
2. Вернуть имя на площадь **или** выкупить у Гретты без сделки с Йореном.

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Архив** | Орвель / писцы | Investigation 14; History 13 | ложное имя → скандал площади |
| **B · Низы** | Гретта: табличка за услугу (не кровь на плитах) | Persuasion 15 / бартер | Йорен перехватывает |
| **C · Ритуал** | Religion 15 на плите + жертва памяти (серое воспоминание ПК на сессию) | — | 1к6 psychic |

## Моральный узел

Гретта просит взамен **чужое** мелкое имя с края площади «на хранение». Отдать чужое = успех Илсы, −Лайра.

## Сцены

| Узел | Где |
|---|---|
| Трещина | площадь 1 |
| Илса | скамьи 7 |
| Орвель | дом писцов 3 |
| Гретта / Йорен | низы 15 |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Низы (опц.) | 2× **Shadow** | dnd.su — если лезли без сделки |

## Награда

| | |
|---|---|
| Золото | 80–200 зм (дар Илсы / Орвеля) |
| Предмет | редко: *перо писца* (uncommon: 1/день Advantage History про имена) |
| `xp_quest` | 800–1200 |

## Репутация

| | Успех | Провал |
|---|---|---|
| Лайра / площадь | + | − |
| Гретта | + если сделка | − если обошли жёстко |
| Йорен | − если обошли его | + если продали ему след |

## Liveliness

Игнор 1 «здешний день»: имя исчезает; Илса уходит в Низы сама.

## Связка

q-prichal-03 можно задеть у Нуресс, если имя «скупили».

# q-prichal-02 — Фонарь без огонька

## Hook (30 сек)

Мелила: огонёк-душа сорвался с колбы и увяз в переулке. Без него фонарщик «слеп», а тень уже нюхает. Поймать — вернуть. Убить тень — тоже выход, но огонёк может погаснуть навсегда.

## Якорь

| Поле | Значение |
|---|---|
| Место | Колбочный ряд · край переулка 4 |
| Выдаёт | **Мелила** |
| Триггер | 1к6 ряда / видят гаснущий фонарь |

## Ставка

Локальная милость площади. Не след Велиана.

## Цель

1. Поймать огонёк **или** отогнать тень так, чтобы огонёк сам вернулся.  
2. Вернуть Мелиле до «часа пыли».

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Ловля** | Dexterity 14 / Animal Handling 13 (как к душе) | — | огонёк рвётся глубже |
| **B · Приманка** | История/песня ПК — Performance 14 | — | привлекает тень сразу |
| **C · Бой** | 1× **Shadow** | — | огонёк гаснет на 50% |

## Моральный узел

Огонёк показывает лицо живого ребёнка из Материала — «отпустить наверх» = он исчезнет с Причала; Мелила потеряет фонарь.

## Сцены

| Узел | |
|---|---|
| Колбы | Мелила |
| Переулок | тень + огонёк |
| Возврат | фонарь загорается |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Переулок | 1× Shadow | dnd.su |

## Награда

| | |
|---|---|
| Золото | 40–100 зм |
| Прочее | Мелила: бесплатный «гостевой свет» 1 ночь (dim light, не привлекает плащей) |
| `xp_quest` | 400–700 |

## Репутация

| Мелила / фонарщики | + успех | − если огонёк погиб |

## Liveliness

Игнор: переулок 4 становится опаснее (+1 к вставкам N при проходе).

## Связка

Цира (пустые колбы) → намёк на q-prichal-03, но не обязательно.

# q-prichal-03 — Скупка имён

## Hook (30 сек)

Цира торгует «пустыми колбами». Insight: товар Чёрных плащей. Нуресс скупает имена в Низах. Саэрн даст ордер, если принесёте доказательство — **не** войну с mq-04, а местный закон площади.

## Якорь

| Поле | Значение |
|---|---|
| Место | Колбочный ряд · переулок · кузница · Низы |
| Выдаёт | **Саэрн** (закон) / **Дромик** (пропажа) / сами против **Нуресс** |
| Триггер | пустой прилавок; слух; ордер |

## Ставка

Давление на Чёрные плащи **локально**. Не раскрывает Велиана и не запускает серую бурю обязательной.

| | |
|---|---|
| Успех | Скупка свернута / Нуресс оштрафован; +Саэрн |
| Провал | Плащи метят партию (Stealth патрулей −) |
| Игнор | Ещё 1к3 имени исчезают с края площади |

## Цель

1. Собрать доказательства скупки.  
2. Передать Саэрну **или** разрушить склад имён без суда (цена).

## Пути (≥2)

| Путь | Суть | DC | Провал |
|---|---|---|---|
| **A · Закон** | Ордер Саэрна → обыск | Investigation 15; Persuasion 14 у Циры | Цира предупреждает Нуресс |
| **B · Стелс** | Склад в Низах | Stealth 15; thieves' tools 14 | бой с плащами |
| **C · Сделка** | Браск/Хальд: крюки vs имена | бартер | долг кузнице |
| **D · Сила** | Налёт | бой | гражданские в пыли; −Лайра |

## Моральный узел

Среди скупленных — имя, которое Гретта обещала вернуть (q-01). Отдать закону = Илса ждёт дольше; вернуть Илсе тайком = Саэрн без полного досье.

## Сцены

| Узел | |
|---|---|
| Цира | колбы |
| Переулок 4 | слежка |
| Кузница 14 | крюки / сигнал |
| Низы 15 | Нуресс |
| Саэрн | пост 12 |

## Противники

| Сцена | Кто | Статы |
|---|---|---|
| Склад | 2× Bandit + 1× Spy (плащ) | dnd.su |
| Нуресс (если бой) | Spy HP+10 | сдаётся при ½ HP к Саэрну |

## Награда

| | |
|---|---|
| Золото | 150–350 зм (штраф/конфискат) |
| Предмет | uncommon редко: *колба-глушитель* (1/день Advantage Stealth 10 мин в городе) |
| `xp_quest` | 1000–1500 |

## Репутация

| | Успех | Провал |
|---|---|---|
| Саэрн / площадь | + | − хаос |
| Нуресс / плащи | − | + метка |
| Лайра | + если без крови на плитах | − кровь |

## Liveliness

Игнор: скупка растёт; Лайра закрывает ночёвку «живым» на площади.

## Связка

С q-prichal-01 пересекается по именам; mq-04 не требует успеха здесь.
