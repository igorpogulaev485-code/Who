# Бриф карты — Драконий Хребет

## Геометрия (лок [`canon-lock-2026-09-23-mq06-ridge-geometry.md`](../../plot/canon-lock-2026-09-23-mq06-ridge-geometry.md))

1. **Полуостров**, не остров.  
2. **З** — горный стык с материком, граница с **Амиратом**.  
3. **СВ** — **маленькая полоска суши** к **Болотам Скорби** (не только залив).  
4. **Ю** — открытое море.  
5. **В** — **крупный остров вулкана + мелкие острова**; столица **Город Пламени** у **подножия**. Основная лента = полуостров (не «весь Хребет = остров»).  
6. Соседей **не** подписывать; снаружи пунктира — пергамент + горы З / топи СВ намёком.  
7. **Без снега/ледников** на карте; зона Корвара = каменные горы (имя/иконка — опрос имён).

## Разлом

**Да, активен** (5 из 7). Точка **далеко** от Пепельного Гребня (обычно запад ленты).

## Вайб

Как Ледяной Союз / Лес Хранителей: hand-painted parchment, живые иконки. v6 ≈ направление вайба.

## Версии

| | |
|---|---|
| v1–v5 | откл. / черновики |
| v6 | вайб ок; **ошибка:** выглядит островом |
| **v7** | полуостров + полоска + столица у вулкана + 8–9 городов (после имён) |
