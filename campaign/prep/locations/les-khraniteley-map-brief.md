# Бриф карты — решения мастера

## Процесс
Делать **как лучше**: рельеф+иконки → контролируемые точные подписи (не принципиально «один промпт на всё»).

## Вид
- **Снаружи** пунктира: пергамент (соседей визуально не прорабатывать).
- **Западные горы** у левого края — **оставить как сейчас** (нравятся).
- Силуэт = `contour-locked` (лес З / залив В).

## Подписи соседей
**Не нужны.**

## Регионы
По удобству: **не подписывать** (меньше шума). Достаточно городов + заголовок.

## Города (расположение)

| Место | Где |
|---|---|
| **Силвания** | **центр** леса (столица) |
| **Мировое Древо** | **рядом со столицей** |
| **Серебряный Порог** | **запад** |
| **Северная Заводь** | **у воды** (на берегу, не в заливе) |
| **Восточные Врата** | **восток** (материковый берег у залива, на суше) |
| **Пепельный Рубеж** | **ближе к хребту** (зап. предгорья) |

## Зелёные Топи
Как удобно: либо лёгкий ЮВ материковый marsh без отдельной подписи, либо без акцента.
