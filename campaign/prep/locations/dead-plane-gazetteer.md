# Gazetteer — 5 островов плана мёртвых

Геометрия: **LOCKED** [`canon-lock-2026-09-23-dead-plane-geometry.md`](../../plot/canon-lock-2026-09-23-dead-plane-geometry.md).  
**Имена ниже — draft.** Ждём ok / правки мастера.

## Цепь (путь mq-04)

`Серый Причал → (переправа) → Край → (переправа) → Молчаливая Коса → (переправа) → Нижние Дворы / Второй Берег`

На v1 карты акцент: **Причал → Край → намёк на даль** (лок K).

## Острова (whitelist player, draft)

| # | Имя (draft) | Роль | На обзоре |
|---:|---|---|---|
| 1 | **Серый Причал** | Вход с Купели; хаб mq-04 | **микроточка** + берег острова |
| 2 | **Край** | След Велиана; диверсии у стены быта / соседний берег | обычная подпись |
| 3 | **Молчаливая Коса** | Ступень между Краем и далью; караваны имён / тихие пристани | обычная |
| 4 | **Нижние Дворы** | Охотники, архивы имён, риск рассекречивания (акт D) | обычная |
| 5 | **Второй Берег** | «Второй город» акта D | обычная |

Имя **Молчаливая Коса** — предложение агента (5-й остров вместо отменённых «Пепельных Плёсов»). Можно заменить.

## Переправы (не подписи-спойлеры)

Между соседними по цепи — **пепельные паромы / лодочные фарватеры**.  
На player-карте: иконки лодок / пунктир фарватера, без имён капитанов.
