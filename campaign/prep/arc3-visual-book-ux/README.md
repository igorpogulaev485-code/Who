# Ранбук UX · Арка 3

> **Это копия для экспериментов.**  
> Оригинал (не ломать): [`../arc3-visual-book/`](../arc3-visual-book/)  
> Здесь: сворачиваемые блоки (`<details>`), короткий хаб, меньше портянки.

## Как листать

1. Открой **эту** папку Preview (не оригинал).  
2. В главе раскрой **один** `<summary>` — веди его — закрой — открой следующий.  
3. Картинки по-прежнему HTTPS + **⬇**.

Если Preview не сворачивает `<details>` — скажи: сделаем вариант «тонкий индекс + листы битов».

## UX-идеи в этой копии

| Приём | Зачем |
|---|---|
| `<details>` / `<summary>` | бит закрыт, пока не нужен |
| Шапка главы всегда открыта | цель / тайминг / чеклист видны |
| Пакеты вставок свёрнуты | гл. 13 не портянка |
| Галерея по лицам | не скроллить 40 портретов |

## Не здесь (ещё можно попробовать)

- Отдельный файл на каждый бит (`02/1-0.md`) — ещё короче экран  
- HTML one-pager с табами (раньше отвергали как «книгу»)  
- Callouts только для **Сказать**  

Пиши, что зашло / что бесит — перенесём в оригинал только после ok.

Канон планов / карты — как в оригинале (LOCKED). Картинки = те же URL (`image-urls.json`).
