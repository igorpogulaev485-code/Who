# 1.3 — Милана / кольцо

> Битый лист UX · назад → [индекс с.1](../02-index.md) · оригинал: `arc3-visual-book`

#### Милана
*дочь Маэстро · почти-речь · кольцо*

![Милана](https://iili.io/nACfs49.jpg)

> **Кадр:** Милана · [⬇ скачать](https://iili.io/nACfs49.jpg)

| | |
|---|---|
| **Кто** | **Милана** — внебрачная дочь **Маэстро Келебрима**, эльфийка-чародейка. Канон-имя (не Фириэсса). |
| **Зачем** | Похороны: почти-речь через **кольцо**, обрывает себя. Дверь C / mq-05 seed. |
| **Стоп** | Не раскрывай третью стражу дневника при свидетелях. |


**Факты:** связь уже есть; помогали; она собирает инфу; кольцо Маэстро.

**Сказать:**

> Кольцо теплеет — знакомое давление, но тембр моложе, жёстче от слёз.  
> *«Я здесь. Я вижу вас. Я должна…»*  
> Шум толпы. Она обрывает.  
> *«Не сейчас. Не с помоста. Держите дневник. Я на связи.»*  
> Кольцо стынет. На краю площади капюшон разворачивается и растворяется между шатрами делегаций.

Проницательность Сл 13: это она, остановила себя.  
Если крикнуть имя вслух — толпа шепчется; она **не** возвращается сегодня.

**После (если ищут дверь C):** кольцо: *«Северные склады. Ночь. Одна. Без толпы.»* → короткая сцена 10 мин: она просит не открывать «третью стражу» дневника при свидетелях; уходит. Имя для партии можно закрепить: **Милана**.
