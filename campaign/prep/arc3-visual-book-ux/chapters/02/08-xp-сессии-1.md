## Чеклист мастера · сессия 1

- [ ] [Гл. 1](01-do-stola.md) — слухи игрокам **до** игры  
- [ ] Выбран **1** боковой очаг (B / C / D / E)  
- [ ] Речи **Селенис** + **Тандил**  
- [ ] Кольцо / **Милана** (почти-речь)  
- [ ] Дверь названа вслух  
- [ ] Если **A или F** — Тандил про **два потока** (до Элиана)  
- [ ] Ровно **1** новость мира (1.5)  
- [ ] Клифф = дверь; открыта **одна** глава 3–10  
- [ ] Если A/F — карты гос-ва под рукой ([гл. 12](12-karty.md)); жертва чёрного → [гл. 13](13-vstavki-i-zhertvy.md)

**Не на с.1:** полный дневник · Лианэя по имени · яйца вслух у Кезарра · Элессар вживую · вход в Купель без магов.
