# Маяк душ

**Дверь A** · mq-01 · государство **Пепельный Порог** · [карты: гл. 12](12-karty.md#дверь-a--пепельный-порог-государство--маяк) · скрипт: [3 · Дверь A](03-dver-a.md)

## Паспорт

| | |
|---|---|
| Регион | План демонов · **Пепельный Порог** (круг 1) |
| Масштаб | site — маяк + лагерь + клетки (внутри государства) |
| Власть | нет; Сарель держит изгоев |

## Атмосфера

Пепельно-багровая пустошь. Небо-синяк. Медь и горячий камень. Маяк — грязно-фиолетовый столб. Тихо. Слишком тихо.

## 5 фактов сейчас

1. Легион **бросил** маяк; жгут у дымов.  
2. Изгои-тифлинги в остове клетки; проводник = сделка/бой со Сборщиком.  
3. В клетках — личные вещи пленных (топливо сайдов).  
4. Мелочь иногда «подметает».  
5. Без Сарель каждый переход — Выживание **Сл 16**.

# Серый Причал

**Дверь F** · mq-04 · государство **Берег Памяти** · [карты: гл. 12](12-karty.md#дверь-f--берег-памяти-государство--причал) · скрипт: [4 · Дверь F](04-dver-f.md) · вставки: [гл. 13 M/N/P](13-vstavki-i-zhertvy.md)

## Паспорт

| | |
|---|---|
| Регион | План мёртвых · **Берег Памяти** · у раны Разлома |
| Масштаб | малый город = центр региона · **15** мест |
| Власть | Совет Писцов + Молчаливые |
| Угроза | душа Кардиана (бури); Чёрные плащи; риск Велиана |

## Атмосфера

Серый свет снизу. Зола, мокрая бумага, остывший чай. Крик осуждают взглядом. Здесь **живут** загробную жизнь. Зло — в переулках и Нижнем дворе.

## 5 фактов сейчас

1. Трещина чёрного потока над площадью открывается редко; живые = сенсация.  
2. Шестеро эльфов в серых плащах ушли к Краю — след слабый (Велиан).  
3. Серые бури у Края участились.  
4. Чёрные плащи скупают стёртые имена.  
5. Кровь/шум на площади → выдворение к Краю; следы дорожают.

# Серебряный Порог

**Дверь D** · mq-03 · [карта](12-karty.md#дверь-d--серебряный-порог) · скрипт: [5 · Дверь D](05-dver-d.md) · совет: [гл. 16](16-sovet-druidov.md)

## Паспорт

| | |
|---|---|
| Регион | Лес Хранителей (не Силвания) |
| Масштаб | site — храмовый комплекс |
| Власть | смотрительница + служители |
| Угроза | фон Ордена (партия рано не слышит) |
| Не сегодня | Элессар вживую; полный двор |

## Атмосфера

Мокрая кора и холодное серебро. Свет пятнами сквозь листву-крышу. Тишина вежливая. Внезапный портал = чашки звенят, все смотрят слишком долго.

## 5 фактов сейчас

1. Ждут **объявленных** посланников (календарь пуст).  
2. Камень обратного портала на стороне Леса на месте.  
3. Совет друидов — тихий слух; Малфурион с уважением.  
4. Элессара здесь **не** ждут как гостя храма.  
5. Хамство / оружие на смотрительницу → гостевой статус сгорает.

|---:|---|
| 1 | Площадка Порога (портал) |
| 2 | Зал гостевых имён |
| 3 | Двор серебряных чаш |
| 4 | Крыло служителей |
| 5 | Тропы ухода: **Силвания** / **Малфурион** / глушь |

# Лагерь Туманного Щита

**Дверь E·льды** · mq-06 · [карта Ледяного Союза](12-karty.md#ледяной-союз-доспехи) · скрипт: [6 · E·льды](06-dver-e-ldy.md) · дальше: [Гирмхельм · гл. 15](15-spine-posle-s2.md#гирмхельм)

## Паспорт

| | |
|---|---|
| Регион | южная кромка Ледяного Союза |
| Масштаб | форт-лагерь · 6 зон |
| Власть | **Хельда Щитолом**; купец **Брорр** |
| Угроза | армия мёртвых; Леди Льда (Лианэя) |

## Атмосфера

Мороз. Дым кузни + серый туман с равнины. Щиты, рога, мат по-дварфски. За частоколом тишина двигается.

## 5 фактов сейчас

1. Портал с Моста редко; гости без гонца = скандал.  
2. За ночь потеряли один дозор — следы в туман и обрыв.  
3. Дварфы зовут врага **Леди Льда**; «сестра эльфа» — пока не знают.  
4. Брорр был на похоронах — может узнать партию.  
5. Туман густеет к вечеру.

## 6 зон

| # | Зона | За столом |
|---:|---|---|
| 1 | Площадка портала | высадка; «живые!» |
| 2 | Частокол севера | стычка с.2 |
| 3 | Кузница-дым | починка, слухи |
| 4 | Палатка Хельды | бриф фронта |
| 5 | Лазарет | «она смотрела» |
| 6 | Южный склад | Брорр |

## НПС

| Имя | Роль |
|---|---|
| **Хельда Щитолом** | комендант |
| **Брорр** | купец / связь с Мостом |
| **Тринн Секирный** | сержант стычки |
| **Олдри Кровь-на-Снегу** | раненый; шёпот о взгляде |

## Слухи (d6)

1 туман пахнет могилой и сталью · 2 Гирмхельм ждёт подкрепления · 3 кто смотрит в туман — слышит имя · 4 у Леди Доспехи · 5 культисты режут тепло · 6 с Моста: дыра орёт

**Не** гнать на равнину / к Лианэе в этот вечер. Доска Гирмхельма — после с.2.
