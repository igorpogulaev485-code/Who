# UX-копия ранбука — инструкция

## Зачем

Оригинал `arc3-visual-book/` — **канон за стол**.  
Эта папка `arc3-visual-book-ux/` — песочница: можно ломать вёрстку, не портя оригинал.

## Что сделано

1. Полный **форк** всех глав + `image-urls.json`.  
2. Биты сессий / дверей обёрнуты в **`<details>`** (свёрнуто по умолчанию).  
3. Очаги и карточки НПС внутри с.1/A/F — вложенные `<details>`.  
4. Гл. 13 — каждый пакет вставок сворачивается.  
5. Галерея — каждое лицо сворачивается.  
6. README = **пульт** на один экран.

## Как проверить за 2 минуты

1. Preview → `arc3-visual-book-ux/README.md`  
2. Открой [гл. 2](chapters/02-sessiya-1-pokhorony.md)  
3. Должны быть кликабельные строки-заголовки битов; контент скрыт, пока не кликнешь  
4. Сравни с оригиналом `arc3-visual-book/chapters/02-…` — там портянка без details

Только после твоего ok: копируем понравившийся паттерн в `arc3-visual-book/` и правим скил visual-runbook.
