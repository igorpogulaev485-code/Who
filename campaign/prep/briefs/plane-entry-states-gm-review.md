# Сверка карт входных государств (для мастера)

Документ для проверки: **соответствуют ли карты v1 брифу и канону**.  
Карты игрокам; этот файл — тебе.

## Канон (уже LOCKED — не спорим заново)

| | |
|---|---|
| Демоны | **9 кругов = государства** · атлас v24 |
| Мёртвые | **5 островов = государства** · атлас v2 |
| Вход мёртвых (Лунный мост) | чёрный поток → город **Серый Причал** ⊂ **Берег Памяти** |
| Вход демонов (Лунный мост) | фиолетовый → **Маяк душ** ⊂ **Пепельный Порог** |

Лок опроса: `campaign/plot/canon-lock-2026-09-24-plane-entry-state-maps.md`

## Правило слоя

```
Атлас плана
 └─ карта государства (то, что сверяем)
     └─ 5–8 центров РЕГИОНОВ
         └─ детализация региона / site позже
```

- Подпись **места**, без слова «Появление».  
- Причал = **город** (центр региона).  
- Маяк = **мелкий объект**, не город.  
- Site Маяка / Причала не перерисовываем.

# 1. Берег Памяти — бриф

**Файл карты:** `campaign/prep/locations/bereg-pamyati/map.png`  
**Asset:** `assets/maps/bereg-pamyati/bereg-pamyati-map-v1.png`

### Должны быть 6 подписей

| # | Центр региона | Что проверить на картинке |
|---:|---|---|
| 1 | **Серый Причал** | заметный **город** (не микроточка) |
| 2 | **Зольные Пристани** | пристани / паромы у пепельного моря |
| 3 | **Южный Брод** | юг; намёк «к Краю» ок |
| 4 | **Поля Стёртых** | открытые поля внутри острова |
| 5 | **Обрыв Раны** | обрыв / край «раны» |
| 6 | **Архивный Увал** | холмы / увал |

### Компоновка

- Один остров, пепельное море вокруг.  
- Тон серый / зола (как атлас мёртвых).  
- Нет Велиана, бури Кардиана, демонов, слова «Появление».

### Чеклист ок / правка

- [ ] Все 6 имён читаются и верные  
- [ ] Причал выглядит как город-хаб  
- [ ] Юг ведёт «к Краю»  
- [ ] Нет лишнего спойлера

# 2. Пепельный Порог — бриф

**Файл карты:** `campaign/prep/locations/pepelnyy-porog/map.png`  
**Asset:** `assets/maps/pepelnyy-porog/pepelnyy-porog-map-v1.png`

### Должны быть 6 подписей

| # | Центр региона | Что проверить на картинке |
|---:|---|---|
| 1 | **Маяк душ** | **шпиль / мелкая метка**, не крепость-город |
| 2 | **Рваный Берег** | каменистый край (подпись **один раз**) |
| 3 | **Пепельная Пустошь** | центральная равнина |
| 4 | **Жертвенные Гряды** | гряды / клетки как регион |
| 5 | **Дымный Тракт** | дорога к дымам |
| 6 | **Первые Ворота** | ворота к Дворам Желания |

### Компоновка

- Только круг 1 / одно государство, не все 9 кругов.  
- Стиль атласа демонов (пепел, слабый фиолет).  
- Нет Филактерия, Ока, Алтарного данжа, имён изгоев, слова «Появление».

### Чеклист ок / правка

- [ ] Все 6 имён читаются и верные  
- [ ] Маяк не раздут в столицу  
- [ ] Нет дублей подписей  
- [ ] Нет спойлеров глубже Порога

Коротко в чат, например:

- `оба лок`  
- `берег ок; порог: …` (что поменять)  
- `имена регионов: заменить X на Y`

После ok — LOCK карт + правки если нужны.
