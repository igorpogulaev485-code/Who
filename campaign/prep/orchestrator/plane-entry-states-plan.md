# План — карты входных государств

## Цель

Карты **входных государств** с **центрами регионов** (5–8).  
Канон 9/5 государств и входов Лунного моста — уже LOCKED; не переутверждаем.

## Статус

| | |
|---|---|
| Опрос | **LOCKED** |
| Берег Памяти | бриф + отрисовка |
| Пепельный Порог | после Берега |

## Маршрут

| # | Шаг | Статус |
|---|---|---|
| 1 | Опрос + лок | **done** |
| 2 | Карта **Берег Памяти** | **in progress** |
| 3 | Карта **Пепельный Порог** | wait |
| 4 | LOCK каждой после ok | wait |

## Правило

Точки = центры регионов → потом детализация.  
Причал = город-центр региона. Маяк = мелкое место. Без слова «Появление».
