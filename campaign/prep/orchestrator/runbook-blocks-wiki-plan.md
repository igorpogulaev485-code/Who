# План — ранбук блоками + ссылка на канон

## Цель

Разделить **ранбук Arc 3** на понятные входы (как «вики за стол»), не превращая его во второй канон.  
Сверху — всегда живая ссылка на `CANON.md` / open-threads / timeline.

## Вердикт

**Запрос годный.** Ранбук уже разросся в плоский список 00–19; блоки спасут навигацию.  
Риск один: **не копировать** паспорта стран и карточки НПС целиком — иначе два источника истины разъедутся.  
Правило: **канон = истина** · **ранбук = портал + стол**.

## Слои (зафиксировать)

| Слой | Где | Что |
|---|---|---|
| **Канон** | `CANON.md` → `world/` · `campaign/plot/` | Случилось / локнуто / мир-установка |
| **Prep** | `campaign/prep/` | Ещё не сыграно; можно перешить |
| **Ранбук** | `arc3-visual-book/` | За стол: биты · HTTPS · ⬇ · сжатые шпаргалки **со ссылками** на канон |

## Три блока README (предложение)

```
Ранбук · Арка 3
├── 🔗 Канон сейчас          ← CANON · open-threads · timeline · последние локи
├── A · СТОЛ                 ← готовимся / ведём сессию (как сейчас)
├── B · МИР                  ← страны → города → карты (вики-навигация)
└── C · ЛИЦА                 ← ключевые +/− (галерея + роли)
```

### A · СТОЛ (сессии)

То, чем пользуешься **вечером**: 00–10, 17–19 (+ вставки/spine по нужде).

- До стола · хаб · двери A/F/D/E/B/C/R  
- Живой мир · сны  
- Вставки / spine / совет — как **приложения стола**, не как вики мира

### B · МИР (вики-навигация)

Не новый лор. **Индекс**:

1. План / государство → карта HTTPS  
2. Коротко «что за столом» (1 абзац)  
3. Ссылка на паспорт `world/locations/states/…` или playbook  
4. Города/сайты вниз: Причал · Маяк · Порог · …

База уже есть: гл. **12** (карты) + **14** (playbook). Оборачиваем хабом «Мир», не дублируем тексты.

### C · ЛИЦА

Гл. **11** → два поддерева:

- **Свои / нейтральные** (партия-якоря, союзники, хаб)  
- **Угрозы / антагонисты** (Кардиан, Зариакс, фронты…)  

Карточка листа: портрет · Кто/Зачем/Стоп · **ссылка на `world/npcs/…`**.  
Face-lock (Маэстро, Кардиан) — в канон-карточке + здесь зеркало.
