# План — карта плана мёртвых

## Цель

Обзорный **атлас всего плана мёртвых** (как Девять Кругов у демонов).  
Причал уже LOCKED — это входной город; нужна география **за ним** и «как устроен план».

## Шаг 0 — canon

- Ветка: `cursor/quest-skill-arc3-bd87`
- Уже есть: Серый Причал LOCKED · spine mq-04 · локи входа A + B–E · отряд Велиана
- Маршрут из spine: Купель (чёрный) → **площадь Причала** → **Край** → диверсии / буря Кардиана → позже «второй город / Нижние дворы»
- Дырка: **атласа плана нет**; имена регионов за Краем почти не заданы

## Что уже канон (не трогаем)

| Факт | Источник |
|---|---|
| Чёрный поток → сразу **город**, не пустошь | mq-04 B–E |
| Причал = нейтральный загробный быт; зло в переулках/Низах | B–E · playbook |
| **Край** = юг/за стеной; след Велиана | door-f · playbook |
| Душа Кардиана = **серая буря песка** | B–E |
| Демонов на этой карте нет | геометрия демонов `h_none` |

## Моя рекомендация (коротко)

1. **Не копировать 9 кругов Данте** — план мёртвых должен читаться иначе, чем демоны.  
2. Топология: **берег / пепельное море имён** + **материк загробных краёв** (не кольца ада).  
3. Причал на обзоре = **явный порт-город** (не микроточка как Маяк на демонах) — это хаб mq-04.  
4. Регионы атласа ≈ **5–7 именованных краёв** под spine (не 666 и не 9 ради симметрии).  
5. Player-карта: имена краёв + путь Причал→Край→…; **без** имён Велиана/Кардиана/НПС.  
6. Стиль: как Причал / атлас демонов v24 — пепел, серое небо, без «готического ада Данте».

Детали и варианты → опрос.
