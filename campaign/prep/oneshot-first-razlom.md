# Ваншот: История Первого Разлома

Ещё **не сыграно**. Замысел мастера.

## Цель ваншота

Погрузить игроков в **историю мира** через событие **Первого Разлома**.

## Рамка

- Персонажи выдаются мастером, **10 уровень**.
- Цель: найти **артефакт, усиливающий огонь плавки**.
- Этот артефакт **в дальнейшем** использовали для создания **Зеркала**, которое удерживало Разлом в **Лунном Мосте**.
- Поиски — в **Империи драконов** (Драконьего Хребта); сила артефакта связана с **дыханием драконов**.
- Связь с **исторической книгой для Вирры** (отдельный материал для игроков).

## Хронология до «настоящего»

Мастер спросил, сколько лет прошло с Первого Разлома до текущей кампании.  
Qwen предложил **~1200 лет** — **не утверждено** мастером (чат оборвался на предложении). См. черновик: [`drafts/first-razlom-timeline-1200.md`](../../drafts/first-razlom-timeline-1200.md).
