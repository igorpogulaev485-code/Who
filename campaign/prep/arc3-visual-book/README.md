2. Открой `campaign/prep/arc3-visual-book/chapters/02-sessiya-1-pokhorony.md`
3. Включи Preview — кадры должны быть сразу под «1.0 — Утро в приюте».

Потом веди главу 2; после двери — одну из 3–7.
