## Что сделать тебе (3 шага)

1. В Cursor открой файл  
   `campaign/prep/arc3-visual-book/chapters/02-sessiya-1-pokhorony.md`
2. Включи Preview у markdown (иконка глаза / Open Preview).  
   Если вкладка была открыта раньше — **закрой и открой файл снова**.
3. Веди сверху вниз по главе 2. Когда выберут дверь — открой **одну** главу 3–7.

Больше ничего скачивать не нужно.
