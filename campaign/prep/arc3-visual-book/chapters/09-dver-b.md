# СЕССИЯ 2 — «Третья стража» (дверь B · mq-05)

**Цель:** Кузница / приют → чтение с **пером** → игроки видят **оглавление** → выбирают, куда копать дальше (страницы — позже) → клифф: том не кончен.

### 2.2 — Перо и правило

| Правило | |
|---|---|
| Перо при открытии | преимущество понять, **какой блок** оглавления «горячий» сейчас |
| Сегодня | показывают **оглавление** + 1–2 строки форзаца; **не** полные страницы |
| Следующие вечера | игроки называют номер/заголовок → тогда пишем/читаем страницу |
| Проницательность **Сл 12** | том отсекает мелочь — голос тысячелетней честности |

**Сказать:**

> Перо само ложится в пальцы. Чернила находят **оглавление**, не случайную страницу.  
> На форзаце: *«Не дочери — третью стражу при чужих глазах.»*

Канон дочери = **Милана**.  
Полное имя: **Келебрим Иллуминар** · чародей · распорядитель празднеств Лунного моста.
