# XP · E · меч · с.2

> ← [07-index.md](../07-index.md)

---

## Как вести

**Где:** после клиффа 2.5.

После клиффа. XP за **сведения**, не за трофей.

| | |
|---|---|
| Расследование | по проверкам |
| `xp_quest` с.2 | 2500–3500 |
| `xp_personal` | 500 тому, кто вытянул ключ о пике / Зариаксе |

**Сказать:**

> Меча нет. Нитка есть. Вечер закрыт.

---

## Чеклист

- [ ] Выбор меча = партия  
- [ ] Портал → **двор**, не пик  
- [ ] Сведения кодом, не «карта сокровищ»  
- [ ] Меч **не** изъят; яйца **не** тема  
- [ ] Нет Кардиана  
- [ ] Клифф = Пепельный Гребень / Зариакс  
- [ ] Ровно **1** новость дома  
- [ ] После сессии → [тик 17](../17/03-тик-процедура.md)

## Стоп

Не XP за изъятие Меча / яйца / бой на пике. Не забывай тик.
