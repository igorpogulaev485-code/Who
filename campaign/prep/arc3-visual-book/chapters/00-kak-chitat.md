# 0 · Как читать

Эта книга — **раздатка визуала** для арки 3, собранная из уже готовых кадров.

1. Иди по оглавлению сверху вниз.
2. В каждой главе: сначала **сцены** (куда партия смотрит), потом **лица** (кого встречает).
3. Глава 1 — только стиль города «как было до фестиваля». Глава 2 — тот же город в день похорон.
4. После похорон партия выбирает **дверь** → главы 5–9 независимы; читай ту, которую открыли за столом.
5. Глава 10 — запасной алфавитный указатель лиц, если нужно быстро найти портрет.
