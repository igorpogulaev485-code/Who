# 2.3 — Разговор-штурм (ядро)

> ← [10-index.md](../10-index.md) · [оглавление](../../README.md)

Три обязательных якоря. Остальное — импров.

#### Якорь 1 — Отец / вина

**Сказать (seed):**

> *«Он отдал три печати дыре, думая, что держит фестиваль. Я убила Пиппина. Это не делает меня вашей солдаткой.»*

#### Якорь 2 — Третья стража / дневник

Если уже была **B** — проверяет, не болтали ли. Если нет — предупреждает; может дать **один** намёк без полной страницы.

**Сказать:**

> *«В томе есть слой, который нельзя открывать при чужих глазах. Не потому что я капризная. Потому что Разлом слушает имена.»*

#### Якорь 3 — Что она делает параллельно (выбери 1)

| | Она уже… | Даёт партии |
|---|---|---|
| A | Ищет **чёрный** поток / следы Велиана | толчок к **F** |
| B | Охотится на заказчиков кражи дневника | защита книги / **B** |
| C | Готовит ритуал «голос отца» (опасно) | мораль: помочь / остановить / отпустить |

**Штурм:** вопрос → короткий жёсткий ответ. Не знаешь факт → «давай решим сейчас» → запиши после игры.
