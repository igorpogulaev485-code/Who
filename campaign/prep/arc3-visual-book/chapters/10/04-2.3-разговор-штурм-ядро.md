# 2.3 — Разговор-штурм (ядро)

> ← [10-index.md](../10-index.md) · скрипт [`mq-05-sessions-2-door-c`](../../../arcs/arc-3/quests/mq-05-sessions-2-door-c.md) · [оглавление](../../README.md)

---

## Как вести этот бит

70–100 мин: **ядро двери C**. Как дверь B — условный мозговой штурм, только через НПС.

Партия спрашивает → Милана отвечает коротко, жёстко, по-эльфийски точно.  
Держи **три обязательных якоря**. Остальное — импров; факты докручиваете за столом → после вечера в канон.

**Не делай:**  
- Допрос по чеклисту в лицо.  
- Весь mq-04 / mq-06 / список архимагов «на блюде».  
- Путать её путь с **R** (сосуды / крышка / Амират).

**Делай:**  
- Три якоря закрыть.  
- Выбрать **один** параллельный ход (A/B/C ниже) и запомнить.  
- Не знаешь факт → скажи вслух: «давай решим сейчас» → запиши.

**Её линия воскрешения (лок):** боги + великие заклинатели; сейчас — **сбор информации**, кто поможет. Сосуды = дверь **R**, не её план.

---

## Где

Тот же тёмный проход между складами. Только свои (партия). Том — если принесли — молчит в сумке.

---

## Сказать

### Якорь 1 — Отец / вина

Она знает: артефакты → демоны → смерть. Может винить город, Героев, себя, отца — **партия выбирает тон**, ты подстраиваешь.

**Сказать (seed):**

> *«Он отдал три печати дыре, думая, что держит фестиваль. Я убила Пиппина. Это не делает меня вашей солдаткой.»*

### Якорь 2 — Третья стража / дневник

Связь с дверью B. Если **уже читали B** — проверяет, не болтали ли при свидетелях.  
Если **ещё нет** — предупреждает и может дать **один** намёк без полной страницы.

**Сказать:**

> *«В томе есть слой, который нельзя открывать при чужих глазах. Не потому что я капризная. Потому что Разлом слушает имена.»*

### Якорь 3 — Что она делает параллельно (выбери 1)

Она **не ждёт** партию. Зафиксируй после игры в канон.

| | Она уже… | Даёт партии |
|---|---|---|
| A | Ищет следы **чёрного** потока / кто открыл не то у Купели; нить «кто из великих ещё отвечает» | толчок к **F** / к именам заклинателей (не GPS) |
| B | Охотится на тех, кто платил за кражу дневника | защита книги / **B** |
| C | Готовит свой ритуал «голос отца» через **молитву / зов** (опасно; не сосуд) | мораль: помочь / остановить / отпустить |

**Сказать (seed параллели, подставь выбранное):**

> *«Я не сижу в приюте. Пока вы выбираете дыру или Лес — я уже иду своей тропой. Пересечёмся — если не предадите то, что сказано в темноте.»*

Если спрашивают про **крышку / нишу / песок**:

> *«Это его ужас, не мой. Ищите крышку без меня — или не ищите. Я иду иначе.»*  
> → трение C≠R; не открывай Амират.

**Как вести штурм:**  
- Вопрос → короткий ответ.  
- Не знаешь факт → «давай решим сейчас» → запиши.  
- Не выдавай весь mq-04/06 за один вечер.
