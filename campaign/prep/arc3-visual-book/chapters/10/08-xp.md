# XP

> ← [10-index.md](../10-index.md) · скрипт [`mq-05-sessions-2-door-c`](../../../arcs/arc-3/quests/mq-05-sessions-2-door-c.md) · [оглавление](../../README.md)

---

## Как вести этот бит

Лист **после вечера**. XP + обязательная запись импрова в канон. Без записи параллельный ход Миланы умрёт в чате.

**Не делай:** XP за несыгранный полный путь воскрешения; награда «за спасение принцессы».

**Делай:** группа + личные за ведущего разговор / кольцо; бой — только если был.

---

## Где

Вне стола / 2 минуты после клиффа.

---

## Сказать

> За вечер: живой разговор, правила тишины, один её параллельный ход. Она ушла своей тропой — кольцо осталось.

| | |
|---|---|
| `xp_quest` | 1200–2000 группе |
| `xp_personal` | 400–700 кто вёл разговор / кольцо |
| Бой | только если был |

---

## Проверки (RU)

Бросков нет. Чеклист мастера:

## Чеклист

- [ ] Без толпы; она торгуется о правилах  
- [ ] Три якоря закрыты  
- [ ] Один параллельный ход выбран и записан  
- [ ] Нет воскрешения / полного тома сегодня  
- [ ] C≠R: сосуды / крышка не выданы как *её* план  
- [ ] Список «что решили за столом» → канон  

## После вечера (обязательно)

Список решений за столом → правка [`milana.md`](../../../../world/npcs/milana.md) + `open-threads` (1 абзац).  
Иначе импров умрёт в чате.

**Случайности:** [вставки C · гл. 13](../13-index.md#вставки--дверь-c--милана) (слух d6 · событие d6 · бой d4).
