# 1.4 — Двери = выбор направления

## Как вести этот бит (важно)

Конец церемонии → **выбор двери** на сессию 2. Один групповой выбор (split только с ok мастера).

1. Тандил сам (не гонец) ставит рамку.  
2. Если смотрят на **A/F** / Купель / Велиана — **обязательно** лор двух потоков (лок mq-04 A) **до** Элиана.  
3. Таблица — перевод в речь мира, не «выберите квест из списка мета».  
4. Клифф с.1 = дверь названа. Потом **1.5** (одна новость).

**Не делай:**  
- Открытие Купели силой.  
- Несколько дверей «успеем все».  
- Полный дневник вместо выбора.

**Делай:**  
- 15–25 мин. Выбор вслух. Стык с главой двери.

---

## Где

Площадь после церемонии / у Тандила / путь к Купели если тянут туда.

**Сказать (Тандил после церемонии — сам, не гонец):**

> Город отплакал полдня. Дальше — не поминки. Дальше — выбор, куда нести долг.

#### Тандил — два плана Разлома (лок mq-04 A)

**Когда:** обязательно, если партия смотрит на дверь **A** или **F** (или спрашивает про Купель / Велиана). Это **первый** лор про два плана — не Элиан.

> Купель — одна рана. Но маги открывают из неё **разные потоки**.  
> Один — **фиолетовый**: план демонов. Туда бьёт легион. Туда же — клык, маяк, то, что жрёт низ.  
> Другой — **чёрный**: план мёртвых. Туда ушёл **Велиан** с отрядом. Не «мстить дыре наугад» — операция.  
> Сами вы поток не включите. **Элиан** и его люди выбирают, что открыть — и за открытие всегда **плачут**: из раны лезет то, чей план зовёте. Демонов — демоны. Мёртвых — мертвецы и тот, кто ими крутит.  
> Без слова магов шаг внутрь я оформлю как самоубийство. Хотите войти — **договаривайтесь**. Я могу поручиться. Силой ломать Купель — значит отдать низ городу.

Проницательность **12**: он не блефует про выброс; боится обоих потоков одинаково.

| Дверь | Куда физически | План / гос-во | Глава |
|---|---|---|---|
| **A · Разлом (демоны)** | Купель → фиолетовый | **Пепельный Порог** · Маяк | [3 · A](../03-index.md) · [карты](../12-index.md) |
| **B · Дневник** | Кузница; чтение = время | — | [9 · B](../09-index.md) |
| **C · Милана** | ночь / северные склады | — | [10 · C](../10-index.md) |
| **R · Воскрешение** | ниша / улики в Мосту → позже Амират (~с.15) | — (с.2 локально) | [18 · R с.2](../18-index.md) · *после стр. 16–17* |
| **D · Лес** | Элиэлор / камень → Порог | Серебряный Порог | [5 · D](../05-index.md) |
| **E · льды** | северная ниша → Туманный Щит | Ледяной Союз | [6 · E льды](../06-index.md) |
| **E · меч** | союзный портал → Хребет | Драконий Хребет | [7 · E·меч](../07-index.md) |
| **E · сапоги** | портал → Розалия → Пыль | Звёздная Пыль | [8 · E·сапоги](../08-index.md) |
| **F · Велиан (мёртвые)** | Купель → чёрный | **Берег Памяти** · Причал | [4 · F](../04-index.md) · [карты](../12-index.md) |
| **G · Политика** | Ириэн / Сильванара | фон / трон | **не** spine с.2 |

Несколько ПК могут тянуть в разные стороны — **один** групповой выбор на сессию 2 (или split только с ok мастера).  
A и F — **одна Купель**, **разный открытый проход** (не развилка глубоко внутри).

**Клифф сессии 1:** дверь названа. Если A или F — Купель + торг с магами.

## RU checks

| Проверка | Сл | |
|---|---:|---|
| Проницательность (Тандил / потоки) | 12 | не блеф про выброс |
| Убеждение (группа → один выбор) | — | мета: дай 2 мин спора, потом спроси «что говорите городу?» |
| История (двери / Разлом) | 13 | напомнить: Велиан ушёл; Купель под магами |

**Сказать (если спорят):**

> Долг один вечер не унесёт во все стороны. Назовите **одну** дверь. Остальные часы мира всё равно тикнут без вас.
