# 1.2 — Центральный помост

> ← [02-index.md](../02-index.md) · [оглавление](../../README.md)

---

## Как вести этот бит (важно)

**Сердце сессии 1.** Церемония на помосте: кадры → речи → опц. узлы → стык с Миланой (**1.3**).

1. Порядок: кадр площади → **Селенис** → минута тишины → **Тандил** → (речь Героев?) → фоновые НПС по нужде.  
2. Не прыгай вниз файла за речами — читай **по порядку**.  
3. Карманник / пустой шатёр — только если есть минуты; не вместо речей.  
4. Кольцо Миланы = отдельный бит **1.3** (можно сразу после Тандила / в конце церемонии).

**Не делай:**  
- Политику Селенис (это Тандил).  
- Открытие Купели без магов.  
- Яйца вслух у Кезарра.  
- Сильванара вживую на площади.

**Делай:**  
- 40–60 мин церемонии с паузами для игроков.

#### Речь Героев (если сами)

1–2 минуты. Толпа: Проницательность Сл **12** — страх / любовь / расчёт.  
**Мораль mq-05 (опц.):** сказать правду про артефакты→демоны **или** молчать.  
- Правда → шёпот ужаса; Тандил позже: «Спасибо. И проклятье тебе за честность.»  
- Молчание → Милана (если узнает) читает как холод / сговор.

#### Узлы площади (пока портреты ещё «на столе»)

##### Карманник → дневник

| | |
|---|---|
| Кто | **«Паучок» Нелл** — подросток, нанят культом/хаосом (не знает заказчика) |
| Механика | пассивная Внимательность **14+** замечает руку; иначе состязание Скрытности **16** против Внимательности |
| Успех партии | Нелл бежит; Атлетика/Акробатика Сл **14** погоня по крышам 1 сцену → дневник цел; Нелл сдаёт: «Платили серебром. Сказали: книга мага.» |
| Провал | Дневник уходит на 1 сцену; найти Анализ **15** у рынка или кольцо Миланы подскажет направление |

##### Пустой шатёр

Подойти к пеплу: Анализ **12** — след когтя демона **старый** (уже знали); новый — отпечаток женской туфли (Милана? или воровка).
