# XP

> ← [09-index.md](../09-index.md) · скрипт [`mq-05-sessions-2-door-b`](../../../arcs/arc-3/quests/mq-05-sessions-2-door-b.md) · [оглавление](../../README.md)

---

## Как вести этот бит

Не сцена стола — **лист после вечера**. Выдай XP, пробеги чеклист, запиши новые номера страниц и случайности, если катили.

**Не делай:** XP «за весь том»; награды за несыгранный контакт C.

**Делай:** группа + личные за перо/чтение; бой — только если был (кража).

---

## Где

Вне стола / 2 минуты после клиффа. Игроки могут ещё сидеть в кузнице — цифры говоришь ты.

---

## Сказать

> За вечер: оглавление, правило тишины, шесть старых страниц на месте, список новых номеров. Книга не кончена — и мир это заметил.

| | |
|---|---|
| `xp_quest` | 1000–1600 группе (скрипт-дверь B в ранбуке; полный скрипт mq — до 1200–2000, если вечер был плотнее) |
| `xp_personal` | 300–500 читающему / держащему перо |
| Бой | только если был (кража) |

---

## Проверки (RU)

Бросков нет. Чеклист мастера:

## Чеклист

- [ ] Чтение не на площади  
- [ ] Оглавление + статус ★ **16, 17, 52–55** (уже open)  
- [ ] Не сочинять закрытые страницы сегодня  
- [ ] Имя дочери = **Милана**  
- [ ] Стр. 16–17 = **Двойник** / Clone (не Mirror Image)  
- [ ] Записаны **новые** номера, которые хотят открыть  
- [ ] Не весь том; не воскрешение за один вечер  
- [ ] Давление (если было) не превратилось в данж  

**Случайности:** [вставки B · гл. 13](../13-index.md#вставки--дверь-b--дневник) (слух d6 · событие d6 · бой d4 редко).
