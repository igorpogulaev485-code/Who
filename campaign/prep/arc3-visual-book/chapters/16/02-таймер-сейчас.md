| Осталось | ориентир **~1 месяц** игрового времени |
| Следствие | дверь D — не только Элессар: для **Дранника** ещё **срок совета** |

Держать **давление месяца**, не «совет через год». Точные даты — за столом.

# Элессар I

| | |
|---|---|
| Кто | король / власть Леса (канон мира) |
| Где ждать | **Силвания** (столица) — не храм Порога |
| В с.2 | **нет** лицом; только указатель тропы и слух |
| Зачем партии | корона, политика, аудиенция — вторая ось mq-03 |

На Пороге смотрительница/Саэла называют два пути ясно: **Силвания** и **круги Малфуриона**. Третий — глушь без провожатых.

# Две вводные · как сплетать

| Ось | Ставка | Для кого |
|---|---|---|
| **Элессар** | корона / политика / Орден на фоне | вся партия |
| **Малфурион + совет** | природа vs Разломы; личный крючок | **Дранник** + любой друид/природа |

### За столом после Порога

1. Клифф с.2: два пути названы.  
2. Спросить Дранника: помнит ли видение / сколько «осталось до совета».  
3. Не форсить обоих боссов одной ночью: одна дорога = одна сессия-фокус.  
4. Другая ось тикает (liveliness): гонцы, слухи, «совет ближе».

### Если идут к Малфуриону раньше Силвании

- Круги друидов готовят места к совету.  
- Малфурион лицом — **позже** с.2 (подступы / проводник / испытание порога природы).  
- Совет как событие ≈ через месяц: можно «прибыть рано» и получить задание/испытание.

### Если идут к Элессару раньше

- Аудиенция / отказ / задание двора.  
- Имя Малфуриона и таймер совета — всплывают у двора или во сне Дранника снова.  
- Орден = фон; не путать с Элдерин/вторжением (лок с.2).
