# XP · E · льды · с.2

> ← [06-index.md](../06-index.md)

---

## Как вести

**Где:** после клиффа 2.7, до или сразу после тика 17.

Считай XP **после** клиффа. Не выдавай XP «за сестру в бою» — её не было в бою.

| | |
|---|---|
| Расследование / бой | камень + стычка |
| `xp_quest` с.2 | 2500–3500 |
| `xp_personal` | 500 Элариону (сестра на горизонте); 250 за лагерь/Брорра |

**Сказать (за столом, коротко):**

> Вечер закрыт. Камень вернули, линию открыли, прорыв у Щита отбили. Сестра — на гребне, не в клинке.

---

## Чеклист (прочитай вслух себе)

- [ ] Толчок = Эларион (видение / сестра)  
- [ ] Северная ниша ≠ Порог; камень **до** прыжка  
- [ ] Шпионы = Орден; нет Элдерин  
- [ ] Прыжок → **Туманный Щит**  
- [ ] Обязательная стычка  
- [ ] Нет изъятия Доспехов / боя с Лианэей  
- [ ] Нет Кардиана; только льды (не меню меча)  
- [ ] Ровно **1** новость дома  
- [ ] После сессии → [тик 17](../17/03-тик-процедура.md)

## Стоп

Не XP за бой с Лианэей / изъятие Доспехов / меню меча. Не забывай тик после сессии.
