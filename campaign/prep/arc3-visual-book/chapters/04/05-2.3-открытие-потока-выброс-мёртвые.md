# 2.3 — Открытие потока → выброс (мёртвые)

> ← [04-index.md](../04-index.md) · [оглавление](../../README.md)

![Выброс нежити](https://iili.io/nACFYTQ.jpg)

> **Кадр:** Выброс нежити · [⬇ скачать](https://iili.io/nACFYTQ.jpg)


**После жертв.** Элиан + 2 мага тянут **чёрную** нить. Партия у ступеней / рун.

**Сказать:**

> Серебряная рана вспыхивает **чёрным**. Пепел летит горизонтально. Из разреза — запах мокрой земли и холодной золы, не серы. Что-то **выходит в зал**, пока поток ещё не держит форму. Глаза без света. Кости. Голос без горла считает имена.

#### Бой — выброс открытия (Купель, чёрный)

| Сост | Статы |
|---|---|
| Волна | **4× зомби** ([dnd.su](https://dnd.su/bestiary/39-zombie/)) **или** 3× **скелет** ([dnd.su](https://dnd.su/bestiary/36-skeleton/)) |
| Некромант | **Priest** CR 2 ([dnd.su](https://dnd.su/bestiary/)) — homebrew имя **«Пепельный Зов»**; *inflict wounds* / вкус *animate dead* |
| Тактика | зомби/скелеты на фронт; некромант со ступеней у раны; не рвать руны |
| Союзники | Ваэра держит периметр (не умирает); 1 маг Элиана — *Sacred Flame*-эквивалент 1/раунд по зомби |
| Победа | поток **стабилен** — чёрная тишина зовёт внутрь |
| Бегство партии | поток схлопывается; вход сегодня закрыт; город +1 раненый маг |

**Если Кардиан «давит» уже здесь** (редко на сессии 2): только если мастер объявил — бафф undead из лока B–E. По умолчанию **не** давить: партия ещё не шумит на плане.
