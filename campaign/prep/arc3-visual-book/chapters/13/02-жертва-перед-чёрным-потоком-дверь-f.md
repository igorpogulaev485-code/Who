# Жертва перед чёрным потоком (дверь F)

> ← [13-index.md](../13-index.md) · [оглавление](../../README.md)

Вставить **после** социала одобрения, **до** открытия потока и выброса undead.  
Только **чёрный** / mq-04. Фиолетовый (A) — **без** меню (старые три дебаффа).

## Биты

| # | |
|---:|---|
| 1 | Элиан / маг у раны объясняет плату |
| 2 | Каждый ПК выбирает жертву вслух (или шепотом магу) |
| 3 | Цена «сразу» применяется |
| 4 | Открытие чёрного → выброс → проход (сейвы + дебаффы по жертве) |

## Речь Элиана

> Фиолетовый поток бьёт в тело и волю — там плата **внутри**.  
> Чёрный… берёт **до**. План мёртвых хочет знать, чем вы готовы быть беднее.  
> Каждый — свою жертву. Память. Кровь. Голос. Тепло. Или примите слизь плана на кожу.  
> Без жертвы он не узнает вас. Сожрёт как чужих. Выбирайте.

Ваэра: *«Клятва не запрещает плату. Клятва запрещает врать о ней.»*  
Тандил: *«Я поручитель за вход. Не за то, что вы отдадите.»*

## Меню для игроков (карточка на стол)

| Жертва | Сразу | Риск в проходе (провалы сейвов) |
|---|---|---|
| **Память** | серое воспоминание | HP / слоты / Проницательность |
| **Кровь** | 1к8 некротика + рана | ×2 урон / ложный путь / шёпот мёртвых |
| **Голос** | только шёпот (проход+1ч) | скорость / тишина / −10 Внимательность |
| **Тепло** | помеха vs холод/некротика 1ч | холодный набор дебаффов |
| **Слизь** | помеха Ловк. сразу | Ловк. / карта / союзник-«труп» |
