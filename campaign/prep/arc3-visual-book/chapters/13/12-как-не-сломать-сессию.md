# Как не сломать сессию

> ← [13-index.md](../13-index.md) · [оглавление](../../README.md)

1. Не кидай таблицу **в** Алтаре / носителе / Милане / Велиане / дипл. кульминации.  
2. Событие важнее боя: улика > мясо.  
3. mq-02 стелс → B/D1–3, не C5.  
4. Запиши: «шум / без шума» после вставки.  
5. **Сначала ситуация → потом куб** (см. «Когда кидать»).

Карты: [глава 12](../12-index.md). Spine дальше: [глава 15](../15-index.md).
