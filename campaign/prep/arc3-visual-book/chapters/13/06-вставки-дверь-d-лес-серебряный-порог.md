# Вставки · дверь D · Лес / Серебряный Порог

> ← [13-index.md](../13-index.md) · [оглавление](../../README.md)

**Тон:** шпионы Ордена, портальный камень, тихий лес. Скрипт: [5 · D](../05-index.md).

## Когда кидать

| Ситуация | Бросок |
|---|---|
| Улицы Моста / поиск ячейки | **d8** событие **или** **d6** слух |
| Провал Скрытности у ячейки | **d6** бой |
| В храме Порога / тропы | **d8** событие |
| Ночёвка у троп | **d6** слух |
