# Вставки · дверь E·меч · Хребет

> ← [13-index.md](../13-index.md) · [оглавление](../../README.md)

**Тон:** дипломатия, чешуя, пик. Яйца **не** произносить. Скрипт: [7 · меч](../07-index.md).

## Когда кидать

| Ситуация | Бросок |
|---|---|
| Двор / архивы | **d6** слух **или** **d8** событие |
| Провал этикета / шум | **d6** бой (патруль) |
| Ночь в посольстве | **d6** слух |

## Слухи (d6)

| | |
|---:|---|
| 1 | «На пике лежит то, о чём не спрашивают.» |
| 2 | «Обсерватория Эридана считает чужие звёзды.» |
| 3 | «Саэрис улыбается тем, кого сочтёт.» |
| 4 | «Камнеград помнит обиду — и ждёт повода.» |
| 5 | «Яйца „не там“ — не повторять при Кезарре.» |
| 6 | «Зариакс смотрит с пика.» |

## События (d8)

| | | Механика |
|---:|---|---|
| 1 | Писец намекает на архив | подкуп / Анализ 15 |
| 2 | Медный дозор считает сумки | Проницательность 14 |
| 3 | Приглашение на «чай» Саэриса | соц; Стоп — пик |
| 4 | Карта без подписи пика | История 14 |
| 5 | Слуга шепчет «Пепельный Гребень» | крюк клиффа |
| 6 | Ложный проводник | Проницательность 15 |
| 7 | Дуэль взглядов с офицером | Запугивание 14 / Убеждение 14 |
| 8 | Тихий сад двора | короткий отдых ок |

## Бои (d6) — только если сорвали дипломатию

| | Состав |
|---:|---|
| 1 | 3× guard |
| 2 | 2× guard + 1× veteran |
| 3 | 1× gladiator (драконорожд.) |
| 4 | 2× scout + mastiff |
| 5 | 1× mage (младший двор) + 2× guard |
| 6 | 1× knight + 2× guard |

По умолчанию **не** кидать бой на дипл. дворе.
