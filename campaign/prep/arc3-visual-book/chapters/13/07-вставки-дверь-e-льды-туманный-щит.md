# Вставки · дверь E · льды · Туманный Щит

> ← [13-index.md](../13-index.md) · [оглавление](../../README.md)

**Тон:** туман, строй мёртвых, **не** Лианэя по имени. Скрипт: [6 · E](../06-index.md). Playbook слухи: [гл. 14](../14-index.md).

## Когда кидать

| Ситуация | Бросок |
|---|---|
| Лагерь / кузница | **d6** слух **или** **d8** событие |
| Линия тумана / стычка | **d6** бой |
| Ночёвка | **d6** слух |
| После стычки | **d8** событие |

## Слухи (d6)

| | |
|---:|---|
| 1 | Туман пахнет могилой и сталью |
| 2 | Гирмхельм ждёт подкрепления |
| 3 | Кто смотрит в туман — слышит имя |
| 4 | У Леди — Доспехи (без «кто она») |
| 5 | Культисты режут тепло у края |
| 6 | С Моста: дыра орёт |

## События (d8)

| | | Механика |
|---:|---|---|
| 1 | Силуэт в тумане | Внимательность 14 — строй; не гнаться |
| 2 | Раненый «видел взгляд» | Медицина 12 → слух 3/4 |
| 3 | Щит с чужим гербом | История 13 |
| 4 | Костёр гаснет сам | Мдр Сл 12 или испуг |
| 5 | След орденского камня | Расследование 14 |
| 6 | Брорр пьёт молча | соц; слух с Моста |
| 7 | Барабан за линией | Тел Сл 13 или −5ft до отдыха |
| 8 | Час ясной мглы | можно двигаться; иначе бой |

## Бои (d6)

| | Состав |
|---:|---|
| 1 | 4× zombie |
| 2 | 3× skeleton + 1× shadow |
| 3 | 2× ghoul + 1× ghast |

| 5 | 1× priest (некро) + 3× zombie |
| 6 | 1× specter + 2× shadow |
