# 15 · Spine после сессии 2

Каркасы **~20** битов по веткам. После клиффа с.2 — открывай нужный блок.  
Вставки: [глава 13](13-vstavki-i-zhertvy.md). Карты: [глава 12](12-karty.md).

Номера = сессии **этой** ветки (микс с другими дверями съезжает).

# mq-01 · Разлом / легион (дверь A)

**Победа ветки ≈ победа арки 3:** напор демонов сломан (~14 ур.).  
Не закрывает все Разломы мира; Кардиан жив (арки 4–5).

## Три якоря

| # | Якорь | Функция | Как ломать |
|---:|---|---|---|
| 1 | **Алтарь Крови Легионов** | кровь → бесконечный призыв | штурм / ритуал / особое оружие |
| 2 | **Серебряный Филактерий** | души → нежить | соц/мелодия/имя; не только DPS |
| 3 | **Око Затмения** | держит Разлом; «взгляд» Кардиана | финал; арена фаз |

# mq-02 · Три трофея (стелс / круг 2)

Охота за **тройкой Падения** (маска · кинжал · медальон). Тон: стелс, расследование.  
Лок: два режима одного Разлома — сила (mq-01) vs тишина (mq-02); скрещивание по пути.

## Круги

| Круг | Что | mq |
|---|---|---|
| 0 | Купель → поток → проход | вход |
| 1 | Пустошь, Маяк, тракты | mq-01; **крючки** mq-02 |
| Ворота | первые ворота / печать | переход |
| 2 | дворы носителей, архивы | **ядро mq-02** |
| 3+ | Филактерий / Око | mq-01; тройка может **бежать** сюда |

Арты **не** у Маяка — за воротами.

## Пролог охоты (1–3)

Слух о трофеях · Сарель/пленный: «ушли глубже» · след у первых ворот.

## Акт A · Ворота (4–6)

Разведка · проход (стелс / отвлечение / сделка) · первый двор — правила тишины.

## Акт B · Охота по одному (7–14)

Порядок носителей **свободный**; после первого остальные осторожнее.

| # | Цель |
|---:|---|
| 7–8 | **Шепчущий Взор** (маска) — двор шёпотов |
| 9 | изъятие маски → **1/3** |
| 10–11 | **Жнец Жилы** (кинжал) — бойня, вход тихий |
| 12 | кинжал → **2/3** |
| 13–14 | **Зов-без-Голоса** (медальон) — риск слияния / побег на кр.3 |

## Акт C · Судьба тройки (15–17)

Вынос · решение: уничтожить / сдать / нести · последствия в городе/Разломе.

## Эпилог (18–20)

Ответ легиона · стык с якорями mq-01 · дверь в mq-04 если кровь звала.

## Стыки с mq-01

| Момент mq-01 | mq-02 |
|---|---|
| Маяк / Сарель | «унесли за ворота» |
| После Алтари (бит 7) | ворота слабее **или** ускоряют слияние |
| Филактерий | боковой двор / медальон усиливает нежить |
| Только mq-02 | якоря живут (liveliness) |

Вставки: [гл. 13 · B/D/E](13-vstavki-i-zhertvy.md).

# mq-04 · дальше Причала (после с.2)

После клиффа Лайры: хаб Причала · биты **3–5** spine · inserts M/N · playbook места 2+.  
Цель ветки: след **Велиана** / диверсии у Края; буря Кардиана — давление, не босс с.2.  
Подробный 20-бит файл — на quest-ветке (`mq-04-dead-spine-20`); за столом достаточно: площадь → писцы → Край → низы + [вставки](13-vstavki-i-zhertvy.md).

# Гирмхельм

**Когда:** после с.2 двери E·льды, когда партия едет/зовётся с Туманного Щита вглубь Союза.  
**Кто выдаёт доску:** воентан **Дунгар Седощит** (бирка Совета).

## Доска войны

Партия берёт **1–2** за вечер (или пачкой). Слои: фронт · город · магия.

| id | Название | Слой | Дуга |
|---|---|---|---|
| q-girm-01 | Разведка к Старому Разлому | фронт | hard |
| q-girm-02 | Караван на Туманный Щит | фронт | soft |
| q-girm-03 | Хлеб с Фьордов | город | soft |
| q-girm-04 | Культ в нижнем городе | город | soft |
| q-girm-05 | Печати Храма | магия | soft |
| q-girm-06 | Эхо ледника | магия | soft |

**Путь к встрече с Лианэей:** закрытие фронтовых/магических бирок → знание о поле у Разлома → полевая встреча (не форсить с лагеря Щита в с.2).

Seed Щита: [гл. 14](14-playbooks-i-side.md#лагерь-туманного-щита). Карта: [Ледяной Союз](12-karty.md#ледяной-союз-доспехи).
