## Как вести

**Где:** после клиффа 2.5.

После клиффа. XP за **ход** и факты, не за трофей.

| | |
|---|---|
| Социал / стелс / стычка | по проверкам |
| `xp_quest` с.2 | 2500–3500 |
| `xp_personal` | 500 тому, кто вытянул ход / факт об Адмиралтействе |

**Сказать:**

> Сапог нет. Ход есть. Вечер закрыт.

## Чеклист

- [ ] Выбор сапог = партия  
- [ ] Портал → **Розалия**, не в Пыль  
- [ ] Портал **в** Пыль остаётся закрытым  
- [ ] Закреплён ход к Звёздному Причалу  
- [ ] Ещё **не** в Империи / Форте; сапоги **не** изъяты  
- [ ] Нет Кардиана; нет боя с Вейлом  
- [ ] Ровно **1** новость дома  
- [ ] После сессии → [тик 17](../17/03-тик-процедура.md)

## Стоп

Не XP за сапоги / Форт / бой с Вейлом. Не забывай тик.
