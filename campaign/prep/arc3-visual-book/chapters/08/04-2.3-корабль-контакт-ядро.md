# 2.3 — Корабль / контакт (ядро)

> ← [08-index.md](../08-index.md) · скрипт [`mq-06-sessions-2-door-e-boots`](../../../arcs/arc-3/quests/mq-06-sessions-2-door-e-boots.md)

---

## Как вести этот бит (важно)

Ядро вечера: **закрепить ход** к **Звёздному Причалу** (`d_berth`). Не сесть в Форт. Не украсть сапоги.

1. ≥2 пути из таблицы.  
2. Выдай **1–2** факта + **имя корабля** / место на борту.  
3. Выбери **одно** seed-имя судна на стол.  
4. Через 60–90 мин → давление **2.4**.

**Не делай:**  
- Рейс сразу в Небесный Форт.  
- Изъятие сапог.  
- Бой с Вейлом.

**Делай:**  
- Одна сцена сделки/стелка → ход закреплён.

---

## Где

Причалы, трюмы, таверна «серого хода», кабинет Сериса.

**Сказать (цель в мире):**

> Вам нужно не королевское благословение. Вам нужно **место на палубе** к воде Пыли — к порту, который ещё лежит на море, не в небе. Имя корабля. Молчание. Цена.

---

## Пути и RU checks

| Путь | Как | Проверки | Провал |
|---|---|---|---|
| Социал | капитан / Серис | Убеждение / Обман **15–17** | отказ; цена выше; донос в ратушу |
| Стелс | трюм / манифест | Скрытность **16**; воровские инструменты | дозор; −реп Розалии |
| Золото | место / рейс / молчание | 800–2000 зм + Проницательность **14** на развод | обманщик с авансом |
| Сила | шлюп / экипаж | Запугивание / бой | шум; Пыль узнаёт раньше; ход сгорает |

**Выдать 1–2 факта + ход:**

1. Внешний порт на воде — **Звёздный Причал**; оттуда суда поднимают **магией** на парящую землю.  
2. Столица — **Небесный Форт**; **Сапоги покрова** — в **Адмиралтействе**.  
3. Адмирал **Каэлен Вейл** лоялен **Кайросу**; император Вентариус IV «в медитации».  
4. Портал **в** Пыль из Аэлендора не откроют. «У Разлома Пыли» = ложный путь.

**Seed корабля (одно имя на стол):** «Пепельная Чешуя» / «Ночной Лицензиат» / «Слепая Звезда».

**Сказать (успех — место закреплено):**

> Йоррен плюёт за борт. *«Место в трюме. Курс — **Звёздный Причал**. Дальше сами. Я до Форта не вожу — там уже не моя виселица.»*

## Стык

| | |
|---|---|
| Ход закреплён | → [2.4 Давление](05-2.4-давление.md) |
| Ноль к 90 мин | форсни через Сериса: одно имя + цена — иначе клифф пустой |
| Ход сгорел | дай запасной корабль дороже; не прыгай в Форт |

**Успех 2.3:** есть **имя судна + место**; факты про Причал/Адмиралтейство на столе.

---

## Стоп

- Нет Форта.  
- Нет изъятия сапог.  
- Нет Вейла в бою.  
- Нет Кардиана.
