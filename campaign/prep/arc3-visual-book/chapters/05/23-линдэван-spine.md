## Как вести

Линдэван = **тихий приют**: целители + **тень-разведка** (Ухо Тишины). Партия с −4 **soft**. Цель вечера — **вернуть свиток и/или правду об убийстве**, затем **Тишину для востока** (ключ mq-03).

0. **[27 · Карта](27-линдэван-карта.md)** — numbered 1–12.  
1. **[24 · Вход](24-линдэван-вход.md)** — мост, вопрос «кого лечишь», мягкий мох.  
2. Меню припонов (ниже).  
3. Желательно **≥2** из 01–04, затем **[25 · Восток](25-линдэван-восток.md)** (`q-lin-05`).  
4. Не успели — клифф: Архив пуст / Ухо слепо / фальшь на рынке.

**Делай:** одна живая сцена → услуга приюту → «что ещё горит?».  
**Не делай:** читать playbook сверху вниз; публично кричать «здесь шпионы»; закрывать Силванию.

## Стоп

- Не Спарта. Не публичный ростер Уха.  
- −4 soft.  
- Свиток ≠ автоматически убийца (два узла).  
- Убийство Вирэны/война с Советом — не этот город.
