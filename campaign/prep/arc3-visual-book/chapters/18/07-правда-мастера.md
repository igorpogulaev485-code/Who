# Правда мастера (не лить на с.2)

> ← [18-index.md](../18-index.md)

## Как использовать

Открой **себе** перед вечером или если партия копает слишком глубоко.  
**Не читай** этот лист игрокам. На с.2 из таблицы ниже на стол можно вынести только то, что уже дали улики (пустая ниша, «юг/песок», душа не у мёртвых).

| | |
|---|---|
| Готовый сосуд | Храм в пустыне **Амирата** (~с.**15**) |
| Растущий | **Кузад-Дум** |
| Душа | У **демонов** |
| Ниша | Первый клон / история |
| План мёртвых | **Не** про душу Маэстро |
| Гонка с C | **Один** победитель |
| Сейчас | Только улики (`i_not_yet`) |

**Стоп:** Амират-точка · Кузад GPS · переезд души · «7 сосудов» списком.
