# Улики сейчас (не Амират)

> ← [18-index.md](../18-index.md) · лок `i_not_yet`

Пока партия в Мосту / на других дверях — максимум **улики**, не адрес сосуда.  
Храм пустыни — цель около **с.15**, не раньше.

| Улика | Где добыть | Что даёт |
|---|---|---|
| Ниша под мостом (пустая / следы старого сосуда) | Исследование низа / История / местный лор | Подтверждает дневник; **не** актуальный сосуд |
| 1–2 «провала» взрослости (осколки ритуала) | Редкий Investigation | Тон: Clone дорогой даже ему |
| Намёк «юг / песок / не здесь» | Перо тянет · Милана · закрытая стр. позже | Вектор на **Амират** без точки храма |
| Душа не на похоронах | Insight у Купели / демоны во сне | «Его нет среди мёртвых имён» |
| Связь с демонами | После контакта с A / арты | Без них крышка бесполезна |

**Запрет рано:** карта Амирата с крестиком; готовый сосуд на столе; полный лор «7 сосудов»; **Кузад-Дум** как GPS растущего; телепорт к храму до ~с.15.
