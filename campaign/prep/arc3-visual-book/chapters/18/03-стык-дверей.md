# Стык с A / F / B / C

> ← [18-index.md](../18-index.md)

| Дверь | Связь с R |
|---|---|
| **B · дневник** | Открыла R (стр. 16–17). Дальше том = улики, не финал воскрешения |
| **C · Милана** | Её путь = **боги / великие заклинатели**, не сосуды. Союз с **трением**; сейчас — **сбор информации**, кто поможет. Может спорить с R |
| **A · демоны** | **Ключ души.** Пока демоны держат душу — сосуд в Амирате = пустая оболочка |
| **F · мёртвые** | **Не** про душу Маэстро. Велиан / другие цели. Не обещай «там найдёте его» |
| **D/E…** | Параллель; R не отменяет |

**Порядок успеха R (мастер):** душа свободна (A-ветка) → храм Амирата (~с.15) → переезд (J).

**Один победитель (лок хвостов):**

| Кто раньше | Что происходит |
|---|---|
| **Милана** решила свою задачу | Маэстро **жив**; **сосуд сохраняется** (крышка не «сгорает») |
| **Сосуд** (партия / R) раньше | Милана **останавливает** свой путь — отец уже жив |

Растущий сосуд в **Кузад-Думе** = фон-таймер / вторая нить (не GPS рано).
