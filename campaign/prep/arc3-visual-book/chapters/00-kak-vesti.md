# 0 · Как вести по этой книге

Открыл **индекс** главы → кликнул **один лист** → ведёшь. Внешние скрипты не нужны.

## За вечер

1. **[Глава 1](01-do-stola.md)** — слухи игрокам.  
2. **[02-index](02-index.md)** — похороны: биты по одному файлу.  
3. После двери — **один** `03-index`…`10-index`.  
4. Портрет → **[11-index](11-index.md)**.  
5. Карта / вставка / playbook / spine / живой мир → **12–17-index**.
