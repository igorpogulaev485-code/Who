# 0 · Как вести по этой книге

Это **ранбук за столом**: тексты «Сказать», проверки, бои и картинки в одном потоке.  
Открыл главу → ведёшь. Не прыгай по внешним файлам.

## За вечер (порядок)

1. **[Глава 1](01-do-stola.md)** — выдай слухи игрокам (чат / бумага) до старта.  
2. **[Глава 2](02-sessiya-1-pokhorony.md)** — весь вечер похорон (общий хаб).  
3. После выбора двери — **одна** из глав 3–7.  
4. Нужен только портрет → **[Галерея](08-galereya.md)**.

## Условные обозначения

| Метка | Что делать |
|---|---|
| **Сказать:** | читай почти дословно игрокам |
| таблица с DC | бросок / механика |
| таблица боя | выложи монстров сейчас |
| кадр под текстом | покажи картинку игрокам |
| портрет | покажи лицо НПС |
| чеклист в конце | пробегись перед клиффом |

## Юзабилити

- Внизу каждой главы — ссылки «назад / оглавление / далее».  
- Картинки = прямые пути в `assets/images/…` (должны открываться в Cursor и на GitHub).  
- Если превью не грузит картинку — кликни путь / открой файл из `assets/images/`.
