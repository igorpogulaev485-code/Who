# Фоновые фронты

> ← [17-index.md](../17-index.md)

Тикай, когда логично или когда ★ уже «закрыты» партией на вечер.  
Коротко: один шаг = одна строка новости.

---

<a id="милана"></a>
## Милана / дневник

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Она собирает нити сама; кто-то ищет «книгу мага» | кольцо: короткое «не сейчас» / тень у окна |
| 1→2 | Попытка кражи дневника вне партии | Паучок / новый агент |
| 2→3 | Третья стража почти вскрыта при чужих **или** она уходит в Разлом без вас | форма C меняется |

**Тормоз:** двери **B/C**; хранить том; помочь ей.

---

<a id="велиан"></a>
## Велиан

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Отряд жив; слухи противоречивы | «кто-то видел фиолетовый не там» |
| 1→2 | Потери / дезертир; ложные вести доходят до магов | Тандил хмурится |
| 2→3 | Отряд гибнет **или** возвращается искажённым | спасать некого / другой Велиан |
| **3** | Контакт ~с.6 mq-04 сдвигается / дороже | |

**Тормоз:** дверь **F**, поиск в плане мёртвых.

<a id="долина"></a>
## Теневая Долина (отрезанные)

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Голод в котле | беженцы / трофеи |
| 1→2 | Мародёрство / резня в тылу | стыд Аэлендора |

<a id="леса"></a>
## Тёмные леса (атташе)

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Атташе едут | тишина на похоронах (уже seed) |
| 1→2 | Перемирие **без** партии (условия хуже) | письмо Филлера |
| 2→3 | Срыв → новый фронт | война на два леса |

**Тормоз:** перехват дипломатии (K).

<a id="элессар"></a>
## Элессар / Лес Хранителей

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Король в тени; совет друидов готовится | слух «месяц» |
| 1→2 | Манифест / гонцы Леса без партии | легитимность без Героев |
| 2→3 | Армия Леса на марше **или** король раскрыт врагам | дверь D дороже / Орден бьёт раньше |

**Тормоз:** дверь **D**; не светить GM-удар Ордена рано.

## Артефакты Кардиана

| Жар | Шаг | Новость |

<a id="двойник"></a>
## Сосуд Двойника (после стр. 16–17)

*По опросу E: `e_now` / `e_later` / `e_merge`.*

| Жар | Шаг | Новость |
|---:|---|---|
| 0→1 | Кто-то ищет «крышку» / нишу под мостом | слух могильщиков / культ |
| 1→2 | Сосуд найден **не** партией **или** повреждён | гонка |
| 2→3 | Пустой / занят / уничтожен | форма воскрешения меняется |

Пока E=`e_later` — держи как **крюк**, не крути каждый тик.
