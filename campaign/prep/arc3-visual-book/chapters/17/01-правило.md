# Правило

> ← [17-index.md](../17-index.md)

## Принцип

Партия может сидеть в «У Последней Завесы» **N** вечеров подряд.  
Мир всё равно делает **N** шагов по 1–2 горячим часам.  
Сидячая арка = **выбор с ценой**, не пауза кампании.

## Жар (0–3)

| Жар | Смысл | Что чувствует стол |
|---:|---|---|
| **0** | Давление есть | Слух, фон |
| **1** | Больно | Жертвы / гонцы / реквизиции |
| **2** | Плохо | Потеря квартала / срыв сделки / смерть союзника |
| **3** | Кризис | Форма квеста **меняется** (спасать некого / эвакуация / артефакт ушёл) |

Ключевой квест **не удаляется** — становится хуже или другим.
