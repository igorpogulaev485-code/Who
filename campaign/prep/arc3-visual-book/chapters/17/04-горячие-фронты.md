# Горячие фронты · шаги

> ← [17-index.md](../17-index.md) · лок C: семь ★

Каждый фронт: шаги 0→3. На тике бери **следующую** строку от текущего жара.  
За тик двигай **1–2** из ★ + обязательная новость.

---

<a id="разлом"></a>
## Демоны / Лунный Разлом ★ · старт жар **1**

| Жар | Если не вмешиваться | Новость партии |
|---:|---|---|
| 0→1 | Вылазки в нижний ярус; пропавшие без трупов | «Ночью из Купели снова тянуло фиолетовым» |
| 1→2 | Жертвы у раны; паника торговцев; Тандил — комендантский час в низу | «Тар-Аминон закрыл три улицы» |
| 2→3 | Разлом **расширяется**; вход без магов = самоубийство | «Верхний город слышит крики снизу даже днём» |
| **3** | Форма: **эвакуация низа** / герои как щит | A/F дороже |

**Тормоз:** двери **A/F**, контроль Купели.
