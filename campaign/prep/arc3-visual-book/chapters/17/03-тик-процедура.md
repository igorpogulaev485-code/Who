# Тик · процедура

> ← [17-index.md](../17-index.md)

## Когда

| Триггер | Делай тик? |
|---|---|
| Конец сессии (после клиффа) | **да** (рек. A=`a_both`) |
| Интерлюдия (действия между сессиями) | **да**, если мир «жил» без партии у стола |
| Партия активно тушит фронт всю сессию | этот фронт **не** шагает вверх; можно **снять** 1 жар |
| Только таверна / шоппинг | шагают ★-фронты |

## Шаги (2 минуты)

1. Открой [трекер](02-трекер-сейчас.md).  
2. Выбери **1–2** фронта из ★ (или те, что логично «не ждали»).  
3. Подними жар на **+1** (или отметь конкретный шаг из листа фронта).  
4. Запиши одну **новость партии** — [доставка](06-доставка-новостей.md).  
5. Если жар стал **3** — перечитай «форма квеста меняется» на листе фронта.

## Если партия вмешалась

| Результат сессии | Жар |
|---|---|
| Существенно помогли фронту | −1 (мин. 0) или стоп роста |
| Частично | рост отложен на 1 тик |
| Провалились / игнор | +1 как обычно |

## Правило таверны

N вечеров «ничего» → N тиков по 2–3 ★-часам → N новостей (можно пачкой в начале следующего вечера: «пока вас не было…»).
