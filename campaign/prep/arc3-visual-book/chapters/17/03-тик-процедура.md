# Тик · процедура

> ← [17-index.md](../17-index.md) · лок A=`a_both` · B=`b_2plus`

## Когда

| Триггер | Тик? |
|---|---|
| Конец сессии (после клиффа) | **да** |
| Интерлюдия (мир жил без стола) | **да** |
| Только чтение дневника (уже open) | **нет** (F=`f_no`) |
| Партия всю сессию тушила фронт | этот фронт не +; можно −1 жар |
| Таверна / шоппинг | ★ шагают |

## Шаги (2 минуты)

1. [Трекер](02-трекер-сейчас.md).  
2. Выбери **1–2** фронта из ★.  
3. Жар **+1** (или конкретный шаг с листа).  
4. **Обязательно** выдай новость партии — [доставка](06-доставка-новостей.md) (`g_mix`).  
5. Жар **3** → «форма квеста меняется» на листе фронта.

## Если вмешались

| Результат | Жар |
|---|---|
| Существенно помогли | −1 (мин. 0) или стоп роста |
| Частично | рост отложен на 1 тик |
| Провал / игнор | +1 |

## Правило таверны

N вечеров «ничего» → N тиков → N новостей (пачкой в начале вечера ок: «пока вас не было…»).
