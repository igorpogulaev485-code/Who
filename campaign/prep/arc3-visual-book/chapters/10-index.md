# СЕССИЯ 2 — «Северные склады» (дверь C · mq-05)

**Цель:** ночь, склады → **живой разговор с Миланой** → её план воскрешения (**боги / великие заклинатели**, не сосуды) → она **собирает информацию**, кто поможет → союз с трением → клифф: уходит параллельно.  
**Не цель:** закрыть воскрешение за вечер; увести в Амират по GPS; бой «спасти принцессу»; список архимагов «на блюде».  
**Длина:** 3.5–4.5 ч.

> **Лок C≠R:** Милана **не** идёт путём Двойника. Сосуды = дверь **[R](../18-index.md)**.  
> Союз с трением · гонка: **один** победитель.
