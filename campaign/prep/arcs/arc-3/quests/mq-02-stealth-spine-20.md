## Два режима одного **плана** (вход = Разлом)

| | **mq-01** | **mq-02** |
|---|---|---|
| Цель | ослабить **легион** (якоря) | изъять **тройку** Падения |
| Тон | сила, штурм, ритуал силы | **стелс, расследование, поиск** |
| География | круг 1 плана → ворота | **круг 2** плана (за Первыми Воротами) |
| Бои | кульминации якорей | точечные / срыв стелса / вставки из таблиц |

Скрещивание **по пути**; жёсткая развилка — позже.

## Каркас ~20 (номера = биты *этой* охоты)

### Пролог · крючки на круге 1 (сессии 1–3 охоты)

| # | Биты | Цель |
|---:|---|---|
| **1** | Общий старт = похороны *(уже скрипт)*; слух о трофеях | дверь Разлом |
| **2** | Купель: социал → открытие фиолетового → выброс демонов → проход → Маяк — Сарель или пленный: «трофеи ушли глубже» | крючок |
| **3** | След у **первых ворот** (печать, кровь ритуала, имя носителя) | карта круга 2 |

*(Если mq-01 уже в пустоши — биты 2–3 вплетаются в сессии 3–4 spine mq-01.)*

### Акт A · Прорыв / проход ворот (4–6)

| # | Биты | Цель |
|---:|---|---|
| **4** | Разведка ворот: патрули, расписание, слабое звено | план |
| **5** | Проход: стелс **или** отвлечение **или** сделка с изгоем | на круге 2 |
| **6** | Первый двор круга 2 — правила тишины (шум = охотники) | закрепиться |

### Акт B · Охота по одному (7–14)

Порядок носителей **свободный**; после первого остальные осторожнее.

| # | Биты | Цель |
|---:|---|---|
| **7–8** | Расследование: где **Шепчущий Взор** (маска) — слухи, отпечатки зрения | двор шёпотов |
| **9** | Маска: кража / сделка / короткий удар | **1/3** |
| **10–11** | След **Жнеца Жилы** (кинжал) — бойня, но вход тихий | бойня клинка |
| **12** | Кинжал: стелс-изъятие или дуэль в тени | **2/3** |
| **13–14** | **Зов-без-Голоса** (медальон) — круг зова; риск слияния | **3/3 или побег на круг 3** |

### Акт C · Судьба тройки (15–17)

| # | Биты | Цель |
|---:|---|---|
| **15** | Вынос с круга 2 (погоня / тихий выход) | за воротами |
| **16** | Решение: уничтожить / сдать Филлеру / нести (цена) | моральный узел |
| **17** | Последствия в городе / Разломе | mq-01 давление меняется |

### Эпилог охоты (18–20)

| # | Биты | Цель |
|---:|---|---|
| **18** | Ответ легиона: слияние сорвано или ускорено | liveliness |
| **19** | Стык: без тройки якоря слабее / с тройкой у партии — соблазн | мост mq-01 |
| **20** | Дверь в остаток арки / mq-04 если кровь звала | дальше |

## Стыки с mq-01 (где скрещивать)

| Момент mq-01 | Как вплывает mq-02 |
|---|---|
| Маяк / Сарель | слух «унесли за ворота» |
| После Алтари (бит 7 spine) | легион ослаб → ворота охраняют хуже **или** паникуют и ускоряют слияние |
| Филактерий | медальон/маски могут усиливать нежить — стелс-рейд боковым двором |
| Если только mq-02 | якоря живут (liveliness mq-01); охота всё равно на круге 2 |

## Решения (ok 2026-09-23)

2. Носители — имена **оставить** (на player-атласе не подписывать).  
3. Первые ворота — **архитектура** (крупные демонические ворота).  
4. Вставки — тон **как в файле**.  

Детали битов охоты — по мере стола / после ok имён кругов на атласе.
