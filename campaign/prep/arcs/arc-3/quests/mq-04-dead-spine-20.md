# mq-04 — каркас плана мёртвых

Локи: [вход A](../../../../plot/canon-lock-2026-09-22-mq04-entry-a.md) · [B–E](../../../../plot/canon-lock-2026-09-22-mq04-dead-plane-be.md)

## Отличие от mq-01/02

| | **mq-01/02** | **mq-04** |
|---|---|---|
| Поток | фиолетовый | **чёрный** (слизь) |
| Выброс при открытии | демоны | **мертвецы + некромант** |
| Выход прохода | пустошь / Маяк | **площадь Серого Причала** |
| Тон | легион, штурм/стелс | загробный быт + скрытые диверсии + **серая буря** |
| Кардиан | нет аватара | душа: незаметна / буря / бафф undead |
| Велиан | крючки | цель контакта ~**сессия 6 пути** |

## Чёрный проход (сводка)

1. Социал с магами (как mq-01) → просят **чёрный** поток.  
2. Открытие → бой выброса (таблица ниже).  
3. Проход ≈ 5 мин, слизь, Con/Int/Wis **15/15/16** — эффекты пакет **«Память»** (или выбранный).  
4. Кардиан: только если Perception/Insight 16 по инициативе игроков.  
5. Выход → [`mq-04-seryy-prichal.md`](mq-04-seryy-prichal.md).

### Выброс открытия (Купель, чёрный)

| Сост | Статы |
|---|---|
| Волна | **4× зомби** ([dnd.su](https://dnd.su/bestiary/39-zombie/)) **или** 3× **скелет** ([dnd.su](https://dnd.su/bestiary/36-skeleton/)) |
| Некромант | **Жрец** / Priest CR 2 ([dnd.su](https://dnd.su/bestiary/)) с *inflict wounds* / *animate dead*-вкус — homebrew имя **«Пепельный Зов»** |
| Тактика | зомби на фронт; некромант с ступеней; Ваэра держит руны |
| Победа | чёрный поток стабилен |

## Каркас ~20 (номера = биты **этого** пути)

### Пролог · город → чёрный вход (1–2)

| # | Биты | Цель |
|---:|---|---|
| **1** | Похороны = общий старт; Тандил: два потока; дверь **F** | выбор |
| **2** | Купель: социал → открытие чёрного → выброс undead → проход-слизь → **Серый Причал** | закрепиться в городе |

### Акт A · Причал как хаб (3–5)

| # | Биты | Цель |
|---:|---|---|
| **3** | Правила площади; Писец; слухи о «шестерых эльфах» | тон + слабый след |
| **4** | Архив имён / лавки памяти; **очень трудный** след (Survival/Investigation **17–18**) | направление к Краю |
| **5** | Первая **серая буря** (Кардиан заметил шум?) или злой переулок | цена давления |

Вставки: таблицы **M** / **N** из random-inserts.

### Акт B · Край и охота за следом (6) ← контакт

| # | Биты | Цель |
|---:|---|---|
| **6** | За Краем: диверсия / сигнал отряда → **встреча с Велианом** (+5 плутов) | дружба; обмен целями |
| **6b** | Решение: идти с ним / взять карту целей / не мешать | моральный узел карточки |

До сессии 6: только подсказки, без «найти на площади».

### Акт C · Операция вместе / рядом (7–12)

| # | Биты | Цель |
|---:|---|---|
| **7–8** | Цель диверсии 1: реликвия двора мёртвых / склад имён | ослабить врага |
| **9–10** | Цель 2: перерезать питание Разлома со стороны мёртвых | стык mq-01 |
| **11** | Серая буря на объекте; undead усилены | Кардиан давит |
| **12** | Ослабить душу (не убить): ритуал/реликвия/разрыв антенны | цена |

### Акт D · Углубление плана (13–17)

| # | Биты | Цель |
|---:|---|---|
| **13–14** | Второй город / Нижние дворы / охотники за Велианом | риск рассекречивания |
| **15** | Нить к Маэстро / дневнику (mq-05) на плане | синергия |
| **16** | Эхо Лианэи (если лок связи выбран) — видение/вестник | mq-06 |
| **17** | Развилка: остаться с операцией / вернуться с картой в Материал | |

### Акт E · Мост дальше (18–20)

| # | Биты | Цель |
|---:|---|---|
| **18** | Итог диверсий: напор мёртвых/врага слабее **или** буря чаще | ставка |
| **19** | Возврат через Купель / метка; выброс при обратном открытии возможен | |
| **20** | Двери в mq-01/05/06; душа Кардиана ослаблена, но жива | мост арки 4–5 |
