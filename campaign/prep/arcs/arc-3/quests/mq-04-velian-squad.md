# Отряд Велиана — пять эльфов-плутов

Велиан + эти пятеро. Все **эльфы**, все **плуты** (мастера), операция на плане мёртвых после неверного потока.  
Контакт с партией ~**сессия 6** пути mq-04; до того — следы. Встречают как **друзей**.

Бой: не враги партии. CR ориентир 5–6 каждый (Assassin/Spy/Swashbuckler-вкус); полные статы — по нужде стола (dnd.su «Шпион» / «Убийца» / Veteran+rogue).

## Встреча (~сессия 6)

Велиан первым; пятёрка из тени, оружие вниз.  
Тон: радость, объятия, быстрый обмен («неверный поток», «диверсии», «буря — не погода»).  
Моральный узел карточки mq-04: идти с ними / взять карту целей / не мешать.
