# mq-04 — Тень, что ушла первой

## Hook (30 сек)

Велиан ушёл «закрывать Разлом». Маги **открыли не тот поток** — отряд оказался на **плане мёртвых**. Он жив, с пятью эльфами-плутами делает диверсии. Партия может догнать… не раньше, чем следы сойдутся (~сессия 6 пути).

## Направление

| Поле | Значение |
|---|---|
| География / маршрут | Купель (чёрный) → Серый Причал → Край → операция |
| Фракция / заказчик | Тандил (ввод); сам Велиан; давление души Кардиана |
| Зачем партии | Союзник, карта плана мёртвых, ослабление врага, нить к Маэстро/Лианэе |

## Ставка арки (успех)

Контакт с **живым** Велианом; диверсии ослабляют питание Разлома/врага со стороны мёртвых; душа Кардиана **ослаблена**, не уничтожена.

## Последствия (обязательно раздельно)

| Исход | Эффект | Навсегда? |
|---|---|---|
| **Провал** | Враг раскрывает отряд; Велиан мёртв/плен/скомпрометирован; буря чаще | да — `failed` |
| **Не взяли** | Отряд работает сам; след для партии стынет | нет |
| **Окно закрылось** | Рассекречивание без партии **или** отряд ушёл слишком глубоко | `expired` |

## Окно / таймер

Контакт ~**6-я сессия этого пути**. Давление = рассекречивание + серые бури Кардиана. Уезд в Лес/льды = след стынет.

## Цель успеха

1. Войти чёрным потоком (социал магов + выброс undead).  
2. Закрепиться в Сером Причале; собрать **трудный** след.  
3. Контакт с Велианом (~6); решить — идти с ним / взять цели / не мешать.
