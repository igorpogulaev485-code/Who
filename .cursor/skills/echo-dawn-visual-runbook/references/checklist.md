# Чеклист сдачи визуального ранбука

## Источники и канон

- [ ] Прочитан ритуал канона (ветка, CANON/SOURCES/open-threads по задаче)
- [ ] Скрипты дверей/хаба сверены с quest-веткой или `arcs/` — не выдуманы
- [ ] Имена канона (дочь = **Милана**; актуальные локи потоков/жертв/совета)
- [ ] Тон визуала хаба = язык локации-рефа (для Моста — фестиваль + траур, не grimdark)

## Планы и ассеты

- [ ] Есть план NPC (только face-to-face ближайших сессий)
- [ ] Есть план локаций / KEY-сцен
- [ ] Промпты сохранены в `assets/prompts/` с запретами
- [ ] Кадры лежат в `assets/images/` (исходник в git)
- [ ] Карты в `assets/maps/` (включая locked, если нужны)

## Хостинг

- [ ] `image-urls.json` заполнен
- [ ] Все URL в главах — HTTPS
- [ ] Выборочный или полный `curl -sI` → 200 + image/*
- [ ] Нет `data:`, нет `../assets` в chapters
- [ ] У каждого кадра есть строка **⬇ скачать** с тем же URL

## Книга

- [ ] `README.md`: 3 шага + полное оглавление
- [ ] Глава 0: метки (Сказать / Сл / кадр / речь)
- [ ] Глава 1: только до-стола материал
- [ ] Глава-хаб: полный скрипт, двери в конце
- [ ] По одной главе на дверь; «Открой, если…»
- [ ] Речи под своими портретами
- [ ] Проверки по-русски (Сл, …)
- [ ] Бои с составом и обходом
- [ ] Клифф · XP · чеклист в конце двери
- [ ] Галерея: Кто / Зачем / Стоп / Тон
- [ ] Атлас карт (если география нужна за столом)
- [ ] Вставки / жертвы (если mq их использует)
- [ ] Сжатые playbooks сайтов с.2
- [ ] Spine / доска после с.2
- [ ] Особые локи (совет, таймеры, два режима…)
- [ ] Недописанное (дневник и т.п.) = TOC/заглушка по слову мастера
- [ ] Навигация ← → и ссылки «Дальше: гл.N» согласованы
- [ ] Файлы в оглавлении = файлы на диске (нет битых ссылок)

## Сдача мастеру

- [ ] Commit + push ветки
- [ ] Явно сказано: закрыть старые вкладки Preview
- [ ] Указан вход: `…/chapters/02-….md` (или актуальный хаб)
- [ ] Кратко перечислено, что нового в оглавлении

## Не сдавать, если

- Картинки «должны работать локально, если правильно открыть»
- В книге английские DC/Perception без русской подписи для стола
- Двери ссылаются на inserts/карты, которых нет в книге
- В тексте ещё Фириэсса / устаревший канон
