# Паттерны глав ранбука

Язык глав — **русский**, тон «говоришь мастеру за столом», коротко.

---

## Front matter

```markdown
---
title: "3 · Дверь A — Маяк"
---
```

---

## Шапка двери

```markdown
# 3 · Дверь A · Маяк душ

**Открой, если после похорон выбрали Разлом (фиолетовый поток).**

# СЕССИЯ 2 — «…» (дверь X · mq-YY)

**Цель:** …
**Не цель:** …
**Длина:** …
```

Ссылка на соседнюю дверь, если легко перепутать (A vs F потоки).

## Бит с НПС

```markdown
#### Элиан Вечный Узел
*одобрение потока*

![Элиан Вечный Узел](https://iili.io/….jpg)

> **Кадр:** Элиан Вечный Узел · [⬇ скачать](https://iili.io/….jpg)

#### Элиан

> Речь от первого лица…
```

Несколько НПС подряд: каждый портрет → ⬇ → его речь. Потом общая сцена/таблицы.

## Проверка

```markdown
| Действие | Сл |
|---|---|
| Заметить дрожь плетения | Внимательность **12** |
| Понять ложь | Проницательность **14** |
```

Или в тексте: `Внимательность Сл 12`.

Преимущество / помеха — словами, не advantage.

## Атлас карт

На каждую карту: заголовок · кадр HTTPS · ⬇ · «когда» · ссылка на дверь/playbook.  
Внизу — таблица дверь → карта.

---

## Вставки

```markdown
## Когда кидать
| Ситуация | Бросок |

## F · События (d8)
| | Событие | Механика |

## Как не сломать сессию
1. Не в кульминации
2. Улика > мясо
```

---

## Жертва (дверь F)

1. Биты (когда вставлять).  
2. Речь Элиана.  
3. Меню таблицей (сразу / риск).  
4. Пустая таблица записи ПК.  
5. Явно: фиолетовый (A) **без** меню.

---

## Playbook (сжатый)

Паспорт · атмосфера · 5 фактов · зоны · НПС · сайды · если медлят.  
Без копипасты полного location playbook.

---

## Spine

Якоря / акты с номерами битов · стыки с другими mq · шпаргалка «сыграли с.2 X → открой Y».

---

## Дневник = только TOC

```markdown
> **Лок prep:** текст страниц пока не пишем. За столом — только оглавление.

### 2.3 — Оглавление (показать игрокам)

\`\`\`
… telegram-style TOC …
\`\`\`

#### Мастеру — что в блоках (не читать вслух целиком)
| Блок | Сдвиг | Крючки на потом |
```

Оболочку сессии (место, перо, давление, клифф) сохранить.

---

## README оглавление

Таблица `| # | Файл | Путь |` со **всеми** главами; пометки вроде «только оглавление» / mq-id.

Строка канона под таблицей.
