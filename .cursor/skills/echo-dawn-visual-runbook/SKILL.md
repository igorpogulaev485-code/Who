# Визуальный ранбук за стол

Скил собирает **одну книгу для мастера**, по которой ведёшь сессию сверху вниз:  
текст битов · речи · проверки по-русски · бои · портреты/локации/карты с **публичным HTTPS** и **⬇ скачать** на второй экран.

**Эталон:** [`campaign/prep/arc3-visual-book/`](../../../campaign/prep/arc3-visual-book/) (Арка 3, с.1 хаб + двери A–F/E×3/B/C + справочник 12–16).

Перед работой: ритуал [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md).  
Источники скриптов обычно на ветке квестов (`cursor/quest-skill-arc3-*`) — **не** выдумывать двери поверх канона.

## Когда вызывать

- «Визуалы / картинки к сессии / второй экран»
- «Ранбук / книга за стол / полный пакет текстов+бои+проверки»
- «Доделать пути / карты / вставки / плейбуки / spine»
- Повторить пайплайн Arc 3 для **другой** арки/хаба

**Не использовать для:** глав книг игроков (`echo-dawn-book-chapter`), чистых playbook без визуала (`echo-dawn-location`), карточек артов, Telegraph.

## Решения мастера (лок опыта Arc 3 · 2026-09)

1. Тон похорон/хаба = **язык фестиваля Лунного моста** + траур; **не** grimdark.  
2. Дочь Маэстро = **Милана** (не Фириэсса / не Марина).  
3. Картинки в Preview **только** публичный **HTTPS** (локальные `../`, `media/`, data URI, symlinks — **ломаются**).  
4. На каждый кадр: `![…](https://…)` + строка **⬇ скачать** с тем же URL.  
5. Речь / «Сказать» — **сразу под** портретом этого НПС (не отдельным блоком в конце).  
6. Проверки — **по-русски**: Сл, Внимательность, Проницательность, Анализ, Убеждение, Скрытность, Выживание…  
7. Workflow: глава Preview на ноутбуке · фото **⬇** на планшет/второй монитор.  
8. Одна дверь за вечер = **одна** глава 3–10; хаб = глава 2.  
9. Дневник (дверь B): пока страницы не пишем — **только оглавление**.  
10. Карты locked / сайт — в `assets/maps/` + глава-атлас с HTTPS.  
11. Вставки / жертва / playbook / spine — **в ту же книгу** (сжато), не «потом в другом файле».  
12. Запрет: INDEX.html-табы как «книга»; просить мастера бесконечно качать локальные файлы.

Подробный postmortem пути: [`references/postmortem-arc3-session1.md`](references/postmortem-arc3-session1.md).

## Алгоритм (каждый заход)

```
0. Canon-ритуал + найти скрипты дверей (quest-ветка / arcs/)
1. План визуала: NPC + локации (что face-to-face на с.1–2) → ok мастера порциями
2. Стиль-рефы + промпты → генерация → assets/images/ (+ prompts/)
3. Хостинг: залить кадры → image-urls.json (ключ → https://iili.io/…)
4. Каркас книги: README + главы 00… (хаб → двери → галерея)
5. Вшить кадры в биты: портрет → ⬇ → речь; локация в нужный момент
6. RU-проверки; бои; чеклисты мастера в конце главы
7. Справочник: карты · вставки/жертвы · плейбуки · spine · особые локи (совет…)
8. Самопроверка Preview (HTTPS 200) → commit → сказать мастеру «закрой старые вкладки»
```

**Не** генерировать все портреты мира. Только то, что **выходит на стол** в ближайших сессиях.

## Фаза 1 · План визуала (до GenerateImage)

Два файла-плана (можно объединить, но удобнее раздельно):

### NPC

Критерий: **face-to-face / портретный якорь** на проработанных путях.  
Не включать: чистые слухи, безымянный extras, боссов «через 10 сессий», если мастер не просил волну 2.

Таблица: `# | Имя | Где | Зачем за столом | Кратко | Статус`.  
Группы = хаб / дверь A / D / F / E…

### Локации

Критерий: кадр, который **показываешь** в бите (establishing, выброс, приземление, храм…).  
ID файлов стабильные: `loc-a1-…`, `funeral-a-…`.

**Стоп:** не генерировать, пока мастер не сказал «го» по порции.

## Фаза 2 · Стиль и промпты

1. Зафиксировать **визуальный якорь** (для Лунного моста — `assets/images/lunnyy-most-festival-ref/`).  
2. Промпт-файл: рефы + обязательные маркеры тона + **запреты** (grimdark, Кардиан в кадре, английский текст на вывесках, «праздничный розовый» на похоронах…).  
3. GenerateImage / аналог → сохранить в `assets/images/…`.  
4. Проверить формат: JPEG-байты в `.png` → перекодировать (Pillow), иначе хостинг/превью глючат.

Промпты эталон: [`assets/prompts/lunnyy-most-arc3-s1.md`](../../../assets/prompts/lunnyy-most-arc3-s1.md).

## Фаза 3 · Хостинг картинок (критично)

Cursor / GitHub markdown Preview:

| Попытка | Результат |
|---|---|
| `../assets/...`, `../../..` | часто 404 / пусто |
| symlinks `media/` | игнор / не резолвятся |
| `data:image/…` в md | **вырезаются** |
| «скачай файл сам» | мастер устаёт; путь тупиковый |
| **HTTPS на iili.io (freeimage.host)** | **работает** |

### Пайплайн заливки

1. Собрать список файлов кадров.  
2. Залить на **freeimage.host / iili.io** (catbox/0x0 в облаке могут быть заблокированы — пробовать запасной).  
3. Записать `image-urls.json`: ключ (логический путь) → `https://iili.io/….jpg`.  
4. В главах — **только** эти URL.  
5. После заливки: HTTP 200 + `Content-Type: image/*` на каждый URL.

Подробности и антипаттерны: [`references/image-hosting.md`](references/image-hosting.md).

### Обязательный блок кадра в md

```markdown
![Короткое имя](https://iili.io/XXXX.jpg)

> **Кадр:** Короткое имя · [⬇ скачать](https://iili.io/XXXX.jpg)
```

Под портретом НПС — сразу **Сказать:** / реплика этого лица.

## Фаза 4 · Каркас книги

### README

- 3 шага мастера («закрой старые вкладки → открой гл.2 → Preview»).  
- Таблица оглавления со **всеми** главами.  
- Канон-строка (Милана; особые локи вроде «дневник = TOC»).

### Глава 0 · Как вести

Метки: **Сказать** · таблица Сл · бой · кадр · речь под портретом.

### Глава 1 · До стола

Только то, что **игрокам** до сессии (слухи). Без спойлеров дверей.

### Глава 2 · Хаб

Полный скрипт: цель · не цель · длина · биты с минутами · кадры · речи · двери в конце со ссылками на главы 3–10.

### Главы дверей

Одна дверь = один файл. В шапке: **Открой, если…**.  
Структура бита: кадр → НПС(и) → **Сказать** → таблицы Сл/бой → клифф → XP → чеклист → «Дальше: гл.12–16».

### Галерея

Портрет + таблица **Кто / Зачем / Сказать / Стоп / Тон**. Не лор-простыня.

### Справочник (после галереи)

| Тема | Зачем в книге |
|---|---|
| Атлас карт | второй экран географии |
| Вставки + жертвы | d-таблицы за столом; меню F |
| Плейбуки/сайды | сжатый сид сайта без ухода в другой репо |
| Spine после с.2 | куда расти после клиффа |
| Особые локи | совет друидов, таймеры, два режима mq… |

Шаблоны абзацев: [`references/chapter-patterns.md`](references/chapter-patterns.md).

## Фаза 5 · Русские проверки и бои

Заменить PHB-английский в таблице мастера:

| EN | RU в ранбуке |
|---|---|
| DC | **Сл** |
| Perception | Внимательность |
| Insight | Проницательность |
| Investigation | Расследование / Анализ (как принято в главе; единообразие внутри книги) |
| Arcana | Анализ (или «магия/Анализ» — не мешать с Investigation без нужды) |
| Persuasion / Deception / Intimidation | Убеждение / Обман / Запугивание |
| Stealth | Скрытность |
| Survival | Выживание |
| Medicine | Медицина |
| advantage / disadvantage | преимущество / помеха |

Бой: состав · заметка · как обойти Скрытностью. Ссылки dnd.su допустимы.  
Не босс-арена в случайной вставке.

## Фаза 6 · Карты

1. Взять файлы из `assets/maps/` (locked часто только на quest-ветке → `git show` / checkout path).  
2. Залить HTTPS → отдельный map-urls или секция `image-urls.json`.  
3. Глава-атлас: каждая карта = кадр + ⬇ + «когда показывать» + ссылка на дверь.  
4. Шпаргалка дверь → карта внизу главы.

---

## Фаза 7 · Вставки, жертвы, playbook, spine

Сжимать исходники в **стол-формат**:

- inserts: когда кидать · таблицы · DC · «не в кульминации»;  
- жертва F: речь Элиана · меню · лист записи ПК;  
- playbook: паспорт · 5 фактов · зоны · НПС · сайды · «если медлят»;  
- spine: якоря / биты ~20 · стыки mq · доска войны (Гирмхельм и т.п.).

Не копировать 800 строк playbook целиком — мастер утонет. Полный файл остаётся в `locations/`; в книге — **сид**.

---

## Фаза 8 · Дневник и «недописанное»

Если мастер сказал «не продумывай X»:

- в главе оставить **оболочку сессии** (где читают, правила пера, давление, клифф);  
- контент X = **оглавление / заглушка**, явно: «страницы пишем по запросу»;  
- не выдумывать прозу «на всякий случай».

## Антипаттерны (запрещено повторять)

1. Чинить превью бесконечными `../../../` и symlinks.  
2. Вшивать data URI в markdown.  
3. Делать HTML INDEX с табами вместо md-книги (путает вкладки, устаревает).  
4. Просить мастера «просто скачай png и открой локально» как основной UX.  
5. Grimdark-похороны вместо языка фестиваля.  
6. Старое имя дочери (Фириэсса).  
7. English-only DC/Perception в тексте для стола.  
8. Речи всех НПС скопом в конце главы.  
9. Карты/вставки «потом» вне книги, когда мастер уже ведёт по главам.  
10. Писать 58 страниц дневника без запроса.
