# Побочные квесты

Эталон мысли: побочки Камнеграда (`examples/locations/kamnegrad-klinkerov.pdf`) — песочница, несколько путей, таймеры, последствия.  
Скил **ужимает воду**, фиксирует каркас, жёстко режет награды, пишет в **prep**.

Перед работой: [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md) → playbook локации [`echo-dawn-location`](../echo-dawn-location/SKILL.md).

## Когда вызывать

- «Сделай / допиши побочку к локации X»
- «Пачка квестов на район / город»
- Якорь в playbook пустой — нужно наполнить

Не использовать для: главного квеста арки (отдельный скил), глав книг, выдачи артефактов сета в лут «за мелочь».

## Главные решения (от мастера)

1. **Длина плавает** — игроки могут закрыть побочку за час или тащить 2 сессии; могут взять 5 квестов и сплести в один маршрут. Скил задаёт `size_hint`, не железный тайминг.  
2. **Полный текст квеста** живёт рядом с локацией; playbook держит только **якорь**.  
3. Для Google Doc — **сборник квестов локации** одним файлом.  
4. Бой **опционален**: враг = имя/тип для [dnd.su](https://dnd.su) / ТТГ; полные статы — только если это **уникальный** домашний NPC.  
5. Награды **жёстко** под уровень партии — без «ещё один очень редкий за поручение».  
6. Можно завести **гостевого** NPC (`transient`) под квест.

## Куда класть файлы

```
campaign/prep/locations/<loc-slug>/
  playbook.md
  npc-registry.md
  quests/
    index.md                 # оглавление побочек локации
    q-<short>-01.md          # один квест = один md (удобно править)
    …
  quests-bundle.md           # ВСЕ квесты локации подряд (для стола)
  quests-bundle.docx         # экспорт в Google Doc
```

Опционально глобальный указатель: `campaign/prep/quests/README.md` (ссылки на локации).

После генерации квеста — **обновить якорь** в `playbook.md` (id, крючок, кто выдаёт, файл).

## Размер и арка

### `size_hint` (не обещание)

| Тег | Ориентир | Пример |
|---|---|---|
| `micro` | ~30–90 мин, если идут напрямую | Драка в таверне, доставка |
| `session` | нормальная «одна линия вечера» | Расследование / хайст |
| `arclet` | легко растянется на 2 сессии, если копают | Кризис с таймером, несколько зон |

В шапке писать: «игроки могут сжать или растянуть».

### `arc_link`

| Тег | Смысл |
|---|---|
| `standalone` | Можно не брать; мир чуть шевельнётся |
| `soft-arc` | Отголосок войны/Разлома/политики; арку не ломает |
| `hard-arc` | Если игнор — заметно хуже для арки/локации (голод, падение репутации, усиление врага) |

## Обязательный каркас квеста

Шаблон: [`templates/quest-side.md`](../../../templates/quest-side.md)

1. **Шапка:** id, title, loc, place, size_hint, priority, arc_link, status:`prep`  
2. **Hook (30 сек)** — что сказать за столом, чтобы взяли  
3. **Якорь:** локация / место / кто выдаёт (или варианты заказчиков)  
4. **Триггер:** как узнают  
5. **Ставка:** что будет с миром/НПС  
6. **Цель:** 1–3 пункта  
7. **≥2 пути** (сила / стелс / соц / …) + DC **5e 2014** + цена провала на пути  
8. **Моральный узел** (хотя бы один выбор с разными последствиями)  
9. **Сцены (карта):** 3–7 узлов «где могут оказаться», не линейный рельс  
10. **Противники:** имена/типы для dnd.su; уникальные — кратко  
11. **Награда** — по экономике ниже  
12. **Репутация** — таблица +/− к фракциям/НПС  
13. **Провал / бездействие / таймер** (если кризис)  
14. **Liveliness** — что сдвинется без партии  
15. **Связка с другими квестами** локации (если можно выполнить пачкой)

## Экономика наград (жёстко)

Ориентир партии сейчас: **ур. 8–9**. Не раздувать.

| Тир квеста | Золото (на группу) | Предметы | Прочее |
|---|---|---|---|
| `micro` | 25–150 зм | расходники / обычный лут | +реп локальная |
| `session` | 100–400 зм | uncommon **редко**, не каждый раз | реп, услуга, доступ |
| `arclet` | 250–800 зм | uncommon или один rare **только** если риск/таймер высокие | сильный доступ / долг НПС |

**Запрещено без отдельного ok мастера:**

- very rare / легендарка за побочку  
- постоянный +1 ко всему / слот мощного артефакта сета  
- гора золота > ~1000 зм за одну простую доставку  

Если награда — информация или рычаг сюжета, золото можно **ниже** табличного.

## Противники

```markdown
### Противники
| Сцена | Кто | Источник статов | Заметки |
|---|---|---|---|
| Погреб | 3× бандит | dnd.su «Бандит» | |
| Босс-путь | «Капитан Корвус» | *homebrew* — кратко HP/AC/фишка | только если не стандарт |
```

Не копипастить огромные статблоки из справочника в файл.

## Гостевые NPC

- Пометить `transient: true` в квесте и **добавить** в `npc-registry.md` локации (чтобы имя не заняли снова).  
- Личное имя уникально **в локации** (правило location-скила).  
- Если гость остаётся в городе после квеста — убрать `transient` и вписать в playbook места.

## Эталоны из Камнеграда (что брать / что резать)

**Брать как образец структуры:**

1. Кризис с таймером («Блокада…») — `hard-arc` / `arclet`, liveliness по дням.  
2. Хайст-песочница («Пивной туман» / коллекционер) — несколько заказчиков и путей.

**Резать при новых квестах (антипаттерны эталона):**

- Простыни предисловий без hook на 30 сек  
- Одинаковые DC 14 на всё подряд без вкуса  
- Пять путей, из которых два клона  
- Награда «ощущается эпик», а риск бытовой  
- Имена вроде третьего Торина на странице  
- Квест не привязан к конкретному месту в playbook  

## Bundle для Google Doc

После пачки квестов локации:

1. Собрать `quests-bundle.md` = `index.md` + все `q-*.md` по порядку приоритета.  
2. `pandoc quests-bundle.md -o quests-bundle.docx`  
3. Один docx на локацию — удобно открыть в Docs за столом.
