# Основные квесты арки

Модель мастера: в арке **одновременно много основных квестов**. Партия **выбирает направления** — всё не успеть; часть линий идёт **параллельно** (живой мир). Можно **не взять ни одного** основного — арка всё равно пройдёт со своими последствиями.

Каждый основной квест **обязан** иметь последствия за:
1. **провал** (взяли и провалили) — квест **закрыт навсегда**;
2. **не взятие** — мир двигается без партии; позже, возможно, ещё успеют взять (пока окно открыто).

Скил пишет **prep**-пакет арки. Не тащить простыни Cirq/Qwen — только то, что ложится в каркас ниже.

Перед работой: [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md). Локации/якоря мест — через [`echo-dawn-location`](../echo-dawn-location/SKILL.md). Побочки — [`echo-dawn-quest-side`](../echo-dawn-quest-side/SKILL.md).

## Когда вызывать

- «Пак основных квестов арки N»
- «Основной квест / направление арки»
- «Последствия если не возьмут / провалят»
- Нужно обновить `mains-overview` арки

Не использовать для: побочек локации, глав книг игроков, выдачи сетовых артефактов «за мелочь».

## Что делает квест «основным»

Не «длиннее побочки», а **направление арки**:

| Признак | Да |
|---|---|
| Меняет состояние арки / региона / фракции, если успех **или** провал **или** игнор | обязательно |
| Партия может выбрать **другое** направление вместо этого | обычно да |
| Живёт в **паке арки**, не только в playbook одной таверны | да |
| Имеет ясное **направление** (география / фракция / цель), даже если дорожный | обязательно |

Дорожный квест ок — но в шапке всегда поле `direction`.

Ранние «10 поручений Маэстро» = исторический пример **многих входов** в мир; сейчас это модель **параллельных основных**, а не один рельс.

## Куда класть файлы

```
campaign/prep/arcs/<arc-slug>/
  mains-overview.md          # сводка: краткая инфа обо ВСЕХ основных
  mains-overview.docx        # для Google Doc / стола
  quests/
    mq-<nn>-<short>.md       # один основной = один файл
    …
  mains-bundle.md            # overview + все mq-* подряд (опционально)
  mains-bundle.docx
```

Примеры slug: `arc-3`, `arc-3-razlom`, `arc-2-aelendor`.

Связь с локациями: в playbook места — только **якорь** (`id`, крючок, файл `…/quests/mq-…`). Полный текст — здесь.

После генерации — обновить строку в `mains-overview.md` и якоря в затронутых playbook.

## Статусы квеста

| status | Смысл |
|---|---|
| `prep` | Не сыгран / можно перешить незатронутые акты |
| `available` | Окно открыто за столом |
| `active` | Партия взяла |
| `done` | Успех |
| `failed` | Провалили → **навсегда** |
| `expired` | Окно невзятия закрылось без взятия (последствия «не взяли» уже сработали) |
| `deferred` | Ещё не взяли, но окно **может** открыться позже |

Правило мастера: **failed ≠ not-taken**. Провал навсегда. Невзятие — пока таймер/`window` позволяет, могут успеть.

## Обязательный каркас одного основного

Шаблон: [`templates/quest-main.md`](../../../templates/quest-main.md)

Только важное (без шума Cirq-полей):

1. **Шапка:** id, title, arc_slug, direction, size_hint, priority, status:`prep`, rules:`dnd-5e-2014`
2. **Hook (30 сек)** — зачем партии это направление
3. **Направление** — куда/к кому/зачем едут (всегда)
4. **Ставка арки** — что меняется в арке при успехе
5. **Последствия провала** (навсегда) и **не взятия** (отдельно!)
6. **Окно / таймер** — дни/сессии; что если партия ушла в побочки
7. **Цель** — 1–3 пункта успеха
8. **Акты** — 2–5 блоков (сцены-узлы внутри акта, не рельс)
9. **≥2 пути** + DC **5e 2014** + цена провала пути
10. **Моральный узел**
11. **Противники** — имена для dnd.su/ТТГ; homebrew кратко только уникальным
12. **Награды** — золото/предметы/доступ + **XP** (см. ниже)
13. **Личные цели** — какие ПК-крючки закрывает (для XP личных целей)
14. **Liveliness** — как линия идёт **без** партии (параллельно другим основным)
15. **Связка** — какие другие `mq-*` / побочки пересекаются; что нельзя успеть вместе

### `size_hint` (ориентир, не обещание)

| Тег | Ориентир |
|---|---|
| `arc-thread` | Несколько сессий, если идут напрямую |
| `arc-spine` | Позвоночник арки / финал направления; легко 3+ сессий |

Писать в шапке: «партия может сжать или растянуть; другие основные идут параллельно».

## Сводный файл арки

Шаблон: [`templates/quest-mains-overview.md`](../../../templates/quest-mains-overview.md)

Кратко по каждому `mq-*`:

- id, название, direction
- hook в 1 предложение
- таймер / окно
- одна строка: успех / провал / не взяли
- status
- путь к файлу

Плюс блок **«выбор направлений»**: что реалистично успеть за арку; что конфликтует по времени; что идёт само.

Экспорт: `pandoc mains-overview.md -o mains-overview.docx` (и при нужде bundle).

## XP и награды

Официальный D&D: XP за **убийства**. У мастера **дополнительно**:

| Источник XP | Как писать в квесте |
|---|---|
| Бой | Стандартные XP мобов (не дублировать таблицу CR целиком — ссылка/имя) |
| Факт выполнения квеста | Явная строка `xp_quest` на группу или на ПК |
| Личные цели ПК | Строка `xp_personal` + какие цели/ПК закрывает |

Ориентир партии: **ур. 8–9**. Скил сам считает награды по экономике ресурсов; не раздувать.

| Тир | Золото (группа) | Предметы | `xp_quest` (ориентир на группу) |
|---|---|---|---|
| `arc-thread` | 400–1500 зм | uncommon часто ок; rare — за риск/таймер/финал направления | ~1500–4000 |
| `arc-spine` | 1000–3000 зм | rare возможен; very rare — только ok мастера | ~4000–8000 |

**Запрещено без ok мастера:** легендарка / слот сетового арта Кардиана·драконов·богов «за средний акт»; XP квеста выше потолка без обоснования; дублировать полный PHB-статблок справочника в файл.

`xp_personal` — обычно меньше квестового (ориентир 250–1000 на ПК за сильный личный момент), не каждый акт.

Если награда — рычаг арки (армия, доступ в Разлом, союз), золото можно ниже таблицы.

## Живой мир и параллель

В каждом основном обязательно:

- **Пока партия на другом направлении** — что происходит по этому `mq` (таблица по дням/сессиям или 2–3 ступени).
- **Если все основные игнорят** — арка всё равно двигается; сводка последствий в `mains-overview`.
- Не писать так, будто партия обязана закрыть все `mq-*`.

## Антипаттерны

- Поля и вода, которые **не ложатся в наш каркас** (Cirq-хвосты, простыни без hook, дубли актов)
- Один «главный» рельс без выбора направлений
- Провал = невзятие (смешивать нельзя)
- Нет последствий за невзятие
- Нет `direction`
- Эпик-лут за бытовой риск
- Одинаковые DC без вкуса
- Квест без связи с аркой / overview
- Полные статблоки справочника в md

## Статус после игры

Сыгранный акт/квест → `active`/`done`/`failed`/`expired`; краткий итог в `campaign/plot/timeline.md`.  
Несыгранные акты в `prep` можно перешивать.  
`failed` не реанимировать без явного слова мастера.
