# Формирование и описание города (кампания)

## Когда включать

- «Опиши город», «баннер-город», «столица / порт / крепость»
- Город **уже есть на карте / в списке центров**, но **нет живого текста**
- Нужен sense-portrait места для prep / чтения вслух
- Новый населённый пункт под сессию (MVP)

Родительская держава / план: skill **`form-state`**. Не подменять государство городом.

## Две задачи (равноправны)

| Задача | Смысл |
|---|---|
| **Создать** | Новый город или добить дыры (районы, NPC, угрозы) |
| **Описать** | Точка на карте есть; нужно погружение + структура за столом |

«На карте есть ≠ описано».

## Режимы

| Режим | Когда | Объём |
|---|---|---|
| **Full** | Столица, священный град, главный порт, ключевой хаб арки | Все слои + полный sense |
| **Lite** | Вторичный баннер / фон | Идентичность, 2–3 района, угрозы, короткий sense |
| **Session MVP** | Партия будет здесь на сессии | Sense + 3–5 локаций + 2–3 NPC + 1 давление |

## Слои (порядок Full)

1. **Место на карте** — государство, соседи, дороги, биом (**только карта**)  
2. **Роль** — столица / порт / святыня / крепость / рынок / врата плана…  
3. **Силуэт** — что видно с дороги за 10 секунд  
4. **Население** — расы, классы, кто «погода улицы»  
5. **Власть на месте** — мэр, гарнизон, храм, гильдии  
6. **Районы / якоря** — 3–7 мест, куда можно поставить сцену  
7. **Экономика / запахи труда** — чем живёт город  
8. **Тень** — преступность, культы, слухи  
9. **Связь с войной / Разломом** — только если нужно; **отдельно** от вечного образа  
10. **Погружение (sense)** — **обязательно**  
11. **Дыры**

## Sense города (обязательно)

Тот же голос, что у государства (см. `form-state` → слой Погружение):

- Лирическая проза, сравнения, сенсорика; не плакат.  
- POV обывателя / прибывшего.  
- **Вечный образ города** без текущего кризиса — отдельно от «сейчас под осадой / под Разломом».  
- 1 сильная метафора города + 3–5 чувственных якорей (запах, свет, звук, камень, толпа).

Ракурсы-минимум: въезд · главная площадь/ось · район труда · священное или власть · ночь · (опционально стена/гавань).

Эталон голоса страны: [`drafts/aelendor-sense-portrait-citizen.md`](../../drafts/aelendor-sense-portrait-citizen.md) — города Аэлендора там даны кратко; **Full по городу** разворачивает каждый в отдельный файл.

## Процесс

1. Уточнить: создать или описать? Full / Lite / MVP?  
2. Сверить карту и досье государства.  
3. Один вопрос → лок → апдейт карточки города.  
4. В конце — sense + список дыр.  
5. Не приписывать городу географию, которой нет на карте.

## Артефакты

```
world/locations/<city>.md                    # карточка города
world/locations/<city>-sense.md              # вечный sense
world/locations/<city>-sense-now.md          # опционально: кризис
campaign/plot/canon-lock-YYYY-MM-DD-<city>-<topic>.md
drafts/<city>-checklist.md                   # при Full
```

Ссылка из `world/factions/<state>.md` и индекса центров.

## Антипаттерны

- Описать город без sense («только население и мэр»).  
- Смешать вечный образ с осадой/Разломом без запроса.  
- Украсть роль другого баннер-города.  
- Игнорировать карту (соседи, расстояние, биом).  
- Подменить описание всей страны (это `form-state`).

## Связь

После пачки баннер-городов — обновить sense государства (короткие абзацы-города) и CANON.
