# Главы книг и кодексы

Скил пишет **текст книг мира**: открытые главы для игроков и (отдельно) мастерские кодексы / скрытый лор.  
Открытая глава = **жёсткий канон**. Telegraph публикует **мастер**, скил готовит репо.

Перед работой: [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md).  
Лок: [`skill-lock-book-chapter-v1.md`](../../../campaign/plot/skill-lock-book-chapter-v1.md).  
Индекс книг: [`world/player-books/README.md`](../../../world/player-books/README.md).

## Когда вызывать

- «Глава / дописать / открыть главу книги X»
- «Черновик закрытой главы» (prep)
- «Мастерский кодекс / скрытый лор» (не для игроков)
- Обновить индекс книги после открытия

**Не использовать для:** playbook локаций, квестов, карточек артефактов, оркестратора.

## Решения мастера (зафиксировано)

1. Обхват = **главы игроков + GM-кодексы / скрытый лор**.  
2. Закрытые (нет «Вы изучили эту главу») — **не канон**; писать только **prep по запросу**.  
3. Файлы — **папка на книгу**: `world/player-books/<book>/…`.  
4. Скил → **репо**; **Telegraph вручную** мастером.  
5. Выход: **md + docx**.  
6. **Голос per-book** (см. ниже).  
7. Каркас: meta + текст + якоря канона + игрок vs мастер.  
8. Длина — **как у соседних глав этой книги**.  
9. Открыть = файл(канон) + индекс «изучено» + telegra-ссылка когда готова.  
10. После открытия — **чеклист разноса** фактов.  
11. Qwen — **можно**, но **сильно править** под голос книги.  
12. За столом изучение = партия **тратит время** на прочтение (указать оценку в meta).  
13. **Запрет:** generic-фэнтези без голоса / имён канона.

```

# Наследие (пока живёт; при касании книги — мигрировать):
world/player-books/chapters/          # старые главы скопом
world/player-books/zerkalo-pamyati.md # старые индексы
```

Шаблоны: [`templates/book-chapter.md`](../../../templates/book-chapter.md) · [`templates/book-codex.md`](../../../templates/book-codex.md)

### Миграция

Новая работа — **сразу** в `world/player-books/<book>/chapters/`.  
При правке старой главы из `chapters/` — перенести в папку книги, в старом пути оставить stub со ссылкой.  
Индекс книги держать в `world/player-books/<book>/README.md` (можно зеркалить краткий список в корневом `zerkalo-pamyati.md` до полной миграции).

### Docx

```bash
pandoc world/player-books/<book>/chapters/<file>.md -o world/player-books/<book>/chapters/<file>.docx
pandoc world/player-books/<book>/README.md -o world/player-books/<book>/README.docx
```

Нет pandoc → сказать путь к md. **Docs = цель.**

## Статусы главы

| status | Смысл | Канон? |
|---|---|---|
| `prep` | Черновик / закрытая по запросу | нет |
| `ready` | Текст готов в репо, ещё не «изучено» / нет telegra | ещё нет для игроков |
| `open` | Открыта: индекс «изучено» + (желательно) telegra | **да** |
| `gm-only` | Кодекс мастера | канон для мастера, не для игроков |
| `superseded` | Заменена | нет |

**Закрытый пункт оглавления** без запроса мастера **не** превращать в `open`.

## Каркас главы игроков

Шаблон: [`templates/book-chapter.md`](../../../templates/book-chapter.md)

1. **Meta:** book, chapter_no, title, status, telegra_url (если есть), voice, time_cost (стол), source  
2. **Хук выдачи / время:** сколько **времени** партия тратит на прочтение (оценки в часах/днях стола или «сцена отдыха»)  
3. **Текст главы** — голос книги, имена канона  
4. **Якоря канона** — таблица: имена / даты / места / артефакты / фракции (для разноса)  
5. **Игрок vs мастер** — что уже в открытом тексте / что ещё скрыто (спойлеры соседних закрытых не раскрывать)  
6. **Связи** — локации, NPC, артефакты, timeline  

## Каркас GM-кодекса

Шаблон: [`templates/book-codex.md`](../../../templates/book-codex.md)

- Явно `audience: gm-only`  
- Факты, тайны, как использовать за столом  
- Что **нельзя** светить в открытых главах без ok  

## «Открыть главу» — чеклист

1. `status: open` в файле главы  
2. Строка в индексе книги: **«Вы изучили эту главу»** + путь к файлу  
3. Telegraph URL — когда мастер опубликовал (скил может оставить `telegra_url: pending`)  
4. **Разнос фактов** (обязательно пройти список):  
   - [ ] `CANON.md` — ссылка, если новая важная тема  
   - [ ] локации / states — имена мест  
   - [ ] NPC — новые лица  
   - [ ] артефакты — [`echo-dawn-artifact`](../echo-dawn-artifact/SKILL.md) / roster  
   - [ ] `campaign/plot/timeline.md` или open-threads — если двигает хронологию/крючки  
5. Docx главы + обновлённый индекс  

## Qwen и черновики

- Брать из `drafts/imports/` можно.  
- **Сильно править** под голос книги и канон-имена.  
- Не оставлять generic-абзацы и чужие топонимы.  
- Не открывать главу из сырого Qwen без правки и чеклиста.

## Антипаттерны

- Generic-фэнтези без голоса Зеркала/Флоры/Драконов  
- Открыть закрытую главу «за компанию»  
- Постить в Telegraph из скила (нет — только репо)  
- Скопировать Qwen почти as-is  
- Забыть время на прочтение за столом  
- Смешать GM-кодекс в player-facing файл  
- Противоречить уже `open` главам без явного лока мастера
