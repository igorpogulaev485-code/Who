# Оркестратор (маршрутизатор)

**Entrypoint кампании.** Почти любая задача по «Эху рассвета» начинается здесь.  
Сам **не** пишет playbook / квесты / арты / главы — только **разбирает → план → ok мастера → вызывает скилы по порядку**.

Лок: [`skill-lock-orchestrator-v1.md`](../../../campaign/plot/skill-lock-orchestrator-v1.md).  
Список скилов: [`AGENTS.md`](../../../AGENTS.md).

## Когда вызывать

- Любая задача по кампании / миру / сессии / канону (по умолчанию **первым**)
- «Подготовь сессию», «что дальше», «пакет на вечер»
- Рекап после сессии
- Неясно, какой узкий скил нужен
- Несколько доменов сразу (страна + город + квесты…)

Узкий скил можно звать **напрямую**, только если мастер явно сказал «только локация / только арт…» и задача однозначна.

## Решения мастера (зафиксировано)

1. Роль = **только маршрутизатор**.  
2. Вызов = **почти всегда первым**.  
3. **Шаг 0** = ритуал [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md).  
4. Маршрут = **жёсткая таблица** (ниже).  
5. Несколько скилов = **последовательно** по плану.  
6. Нет скила → **макс-опросник + сделать топовый скил**.  
7. Опросы стыков — оркестратор; тема скила — тот скил.  
8. Lock пишет **скил темы**; оркестратор требует лок.  
9. Дырка канона → опросник; **не** писать канон до ответа.  
10. Артефакт: `campaign/prep/orchestrator/<slug>-plan.md`.  
11. Сессионный пакет — через делегирование.  
12. Рекап-поток: рекап → timeline → open-threads → canon.  
13. Партия медлит → **спросить фронт** у мастера.  
14. Запрет: простыня плана без файлов/шагов.  
15. Первый ответ: **план → ждать ok → шаги**.

## Алгоритм (каждый заход)

```
0. Canon-ритуал (ветка, CANON, SOURCES, open-threads, timeline)
1. Разобрать запрос → список доменов по таблице §Маршрут
2. Найти дырки канона / отсутствующие скилы
3. Записать plan.md (коротко!) + при необходимости опросник
4. СТОП: ждать ok мастера (и ответов опроса)
5. Выполнить шаги по порядку: читать SKILL узкого скила → сделать → потребовать лок если были решения
6. Обновить plan (статусы шагов) + open-threads при сдвиге «сейчас»
```

**Не** выдавать простыню «вот 40 пунктов идей» без `plan.md` и без конкретного следующего файла.

## Куда класть план

```
campaign/prep/orchestrator/
  README.md
  <slug>-plan.md
  <slug>-plan.docx    # по желанию / по запросу
```

Шаблон: [`templates/orchestrator-plan.md`](../../../templates/orchestrator-plan.md)

Slug: коротко по задаче (`session-arc3-bridge`, `recap-2026-09-05`, `prep-les-khraniteley`).

### Docx (опционально)

```bash
pandoc campaign/prep/orchestrator/<slug>-plan.md -o campaign/prep/orchestrator/<slug>-plan.docx
```

## Каркас plan.md (обязательный выход)

1. **Цель** — 1–2 предложения словами мастера  
2. **Шаг 0** — canon: что прочитал / какие якоря «сейчас»  
3. **Маршрут** — таблица шагов: # · скил · зачем · статус (`wait-ok` / `ready` / `done` / `blocked-survey`)  
4. **Опросы** — только стыки/приоритеты/дыры (или «нет»)  
5. **Файлы-результаты** — что должно появиться после ok  
6. **Не делаем** — явно (чтобы не раздувать)

Держать план **коротким**. Детали контента — в файлах узких скилов.

## Жёсткая таблица маршрутов

| Сигналы в запросе (RU/EN) | Скил |
|---|---|
| канон, лок, опросник формата, SOURCES, «что канон» | `echo-dawn-canon` (+ оркестратор держит процесс) |
| локация, город, район, playbook, таверна, Камнеград-стиль | `echo-dawn-location` |
| побочка, side quest, крючок локации | `echo-dawn-quest-side` |
| основной квест, арка, mq, направление арки, провал/невзятие | `echo-dawn-quest-main` |
| государство, страна, паспорт, регионы страны | `echo-dawn-state` |
| артефакт, сет, предмет, roster «у кого что», Кардиан/драконы/божественный | `echo-dawn-artifact` |
| глава книги, Зеркало, флора, энциклопедия драконов, telegra, кодекс GM | `echo-dawn-book-chapter` |
| подготовь сессию, пакет на стол, повестка вечера | оркестратор → пакет из location/quests/… |
| рекап, итог сессии, что сыграли | оркестратор → поток рекапа |
| фронт войны, «мир двигается», партия медлит | оркестратор → **опрос: какой фронт** |
| оркестратор, дирижёр, что делать дальше | этот скил |

Несколько строк таблицы сработали → **несколько шагов по порядку** в plan (зависимости: сначала state/location, потом quests; artifact после квеста-источника и т.д.).

## Нет нужного скила (B3)

Примеры: чистый NPC-скил, encounter, session-recap как отдельный модуль, economy…

1. **Не** эмулировать долгий процесс «на глаз».  
2. Сразу **максимальный опросник** (HTML dropdown + litterbox, §10 canon).  
3. После ответов — **сразу** написать **топовый** `.cursor/skills/echo-dawn-<name>/SKILL.md` + шаблон + лок + строка в `AGENTS.md`.  
4. Затем продолжить исходную задачу уже через новый скил.

## Опросы: кто что ведёт

| Тип вопроса | Кто |
|---|---|
| Какой фронт / приоритет / стык доменов / какой пакет сессии | **Оркестратор** |
| Устройство playbook / награды побочки / голос книги / сет артефакта | **Узкий скил** |
| Дырка факта канона | Опрос **до** записи в canon (строгий режим) |

Формат всегда: dropdown + litterbox для Safari (см. canon §10).

## Сессионный пакет (D2)

Когда просят подготовить сессию:

1. Plan: цель вечера, место, 1–3 направления  
2. Опрос стыков, если место/фронт неясны  
3. После ok — по порядку, например:  
   - `location` (playbook зоны)  
   - `quest-side` / `quest-main` (якоря + файлы)  
   - `echo-dawn-visual-runbook` — **плотный вечерний spine/биты** (обязательный итог)  
   - при необходимости `artifact` / `state` / `book-chapter`  

**Лок итога (2026-09-29):** пакет не `done`, пока в `arc*-visual-book` нет листа «открыл → ведёшь» (Как вести · Где · Сказать · RU · Стык · Стоп). Playbook/bundle — справочник, не замена spine. Эталон: дверь D `05/14`→`15`→`16`→`17`.
4. В plan — чеклист файлов «готово к столу»

NPC без отдельного скила: пока якоря в location playbook / quest; если объём большой → B3 (новый скил).

## Рекап-поток (D3)

После текста мастера / сессии:

1. Зафиксировать рекап (`campaign/sessions/…` или brief)  
2. Обновить `timeline`  
3. Обновить `open-threads`  
4. Список «что стало canon» → правки карточек **через** нужные скилы / canon  
5. Plan со статусами; локи — у скилов тем

## Партия медлит (E1)

Не выбирать фронт сам.  
Короткий опрос: какой фронт двигать (война / Разлом / Лес / Марин / …) → plan → ok → делегирование.

## Антипаттерны

- Простыня плана в чате **без** `*-plan.md` и без следующего файла  
- Писать локацию/квест/главу **сам**, минуя узкий скил  
- Параллелить пять скилов без плана-порядка  
- Заполнять канон «пока мастер молчит»  
- Спрашивать мелочи узкого скила на уровне оркестратора  
- После plan сразу делать шаги **без** ok мастера  

## Чеклист первого ответа

- [ ] Canon шаг 0 сделан  
- [ ] `campaign/prep/orchestrator/<slug>-plan.md` создан/обновлён  
- [ ] Маршрут по таблице, шаги по порядку  
- [ ] Опросы только если стык / дырка / нет скила / фронт  
- [ ] Явно: «жду ok»  
- [ ] Нет простыни без дела
