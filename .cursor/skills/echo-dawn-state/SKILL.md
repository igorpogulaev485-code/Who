# Государства (страны)

Паспорт страны — **всегда канон**. Слой «на стол» — **отдельная папка prep**, только по запросу («едем в X» / дипломатия / Разлом внутри).

Перед работой: [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md).  
Карта: [`world-map.md`](../../../world/locations/world-map.md).  
Сводка: [`states-overview.md`](../../../world/locations/states-overview.md).

## Когда вызывать

- «Паспорт / карточка страны X»
- «Дозаполнить волну паспорта» (Аэлендор и др.)
- «Регионы государства»
- «Слой на стол для страны X»
- Обновить сводку государств

Не использовать для: playbook города/места (→ [`echo-dawn-location`](../echo-dawn-location/SKILL.md)), полных квестов, **не**-государственных организаций (культ, дом, банда → `world/factions/`).

## Решения мастера (зафиксировано)

1. Паспорт → **канон** сразу.  
2. Нужен **сводный** файл всех стран + карточка на каждую.  
3. Слой стола → **отдельная** prep-папка.  
4. Docx — **да** (сводка, паспорт, table-prep).  
5. Стол — **только по запросу**, не вместе с паспортом по умолчанию.  
6. В паспорте **7–10 регионов** страны.  
7. НПС: важные и **условно известные**; король/голова — **да**; начальник стражи гарнизона — **нет**.  
8. Ситуации «государство ≈ фракция с двумя файлами» — **быть не должно**.  
9. Разлом — якорь в паспорте (см. ниже).  
10. Паспорт заполняется **волнами** (Аэлендор самый полный, но ещё дырявый).  
11. Блок **последствий** обязателен.  
12. Liveliness-календаря по дням в паспорте — **нет**; живой мир = **Сейчас** + последствия.  
13. Экономику продумывать **максимально**, без привязки к уровню партии.  
14. Расы: доминирующие **2–4** + прочие одной строкой.  
15. Приоритет фактов: **голос мастера → карта → книги игроков → Qwen**.  
16. Имена из открытых глав книг — **сразу в канон**.  
17. Бесит: **упрощённость до пустоты** и **простыни Qwen** вне каркаса.

## Куда класть файлы

```
world/locations/
  states-overview.md           # сводка ВСЕХ государств
  states-overview.docx         # экспорт сводки
  states/
    <slug>.md                  # паспорт (canon)
    <slug>.docx
    README.md

campaign/prep/states/<slug>/   # ТОЛЬКО по запросу «на стол»
  table.md
  table.docx
  npc-registry.md              # имена важных лиц этой вылазки / страны
```

Регион из паспорта → когда нужен playbook места: [`echo-dawn-location`](../echo-dawn-location/SKILL.md) → `campaign/prep/locations/`.

Старые короткие карточки (`les-khraniteley.md` и т.п.) при доработке **переносить** в `states/<slug>.md`, на старом пути — stub со ссылкой.

## Волны заполнения

Аэлендор = выше остальных по наполненности; «закончен» не равен.

| Волна | Обязательный минимум |
|---|---|
| **W1 — контур** | тип, карта/соседи, столица (если есть), расы кратко, устои 1–3, **Сейчас**, отношение к Аэлендору/войне/Разлому, рычаг партии, черновик последствий, связи |
| **W2 — тело** | власть (правитель!), 7–10 регионов, экономика (полная качественно), сила, якоря Разломов, важные НПС, законы/табу кратко |
| **W3 — связность** | mq/побочки/локации, дипломатия к соседям, услуги государства, уточнение последствий, сверка карта+книги |

В шапке: `fill_wave: 1|2|3`. Дозаполнение = поднять волну, не сжигать файл.

## Каркас паспорта

Шаблон: [`templates/state.md`](../../../templates/state.md)

1. Шапка: id/slug, title, type, fill_wave, status:`canon`, source  
2. **На карте** — положение, соседи, материк/остров  
3. **Столица** (+ города из книг сразу в канон)  
4. **Рельеф / климат** + опасность пути  
5. **Народы** — 2–4 доминирующих + прочие  
6. **Устои** — 1–3 принципа  
7. **Власть** — кто правит **обязательно**  
8. **Сейчас** — 3–7 фактов  
9. **Отношения** — Аэлендор, война, Разлом, ключевые соседи  
10. **Экономика** — ресурсы, торговля, дефицит, дань/валюта, услуги; **без** level-gate  
11. **Сила** — армия/флот/магия качественно  
12. **Регионы (7–10)** — имя, суть, зачем партии  
13. **Важные лица** — только гос. масштаб / условно известные  
14. **Разлом (якорь)** — есть/нет, где, статус; ссылка на lore/квест  
15. **Рычаг для партии**  
16. **Последствия** — игнор / вражда / союз  
17. **Законы и табу** (W2+)  
18. **Связи** — файлы

### Разлом — как надо

| Слой | Где |
|---|---|
| Якорь | паспорт: есть ли, примерно где, статус «сейчас» |
| Мир | [`razlom-i-zavesa.md`](../../../world/lore/razlom-i-zavesa.md) |
| Игра | mq / побочка + location playbook места |

В паспорт **не** тащить данж и статблоки.

## НПС — отсечение

**Писать:** монарх/голова, наследник, лицо государства (верховный жрец/магистр, если это институт власти), известный гос. предатель/союзник.

**Не писать:** начальник стражи гарнизона, ротационные капитаны, локально важные — они в playbook локации или в `table.md`.

Имена уникальны **внутри страны**.

## Государство vs `world/factions/`

| Это | Куда |
|---|---|
| Аэлендор, Теневая Долина, Орден, Хребет, Звёздная Пыль… как **страны** | `world/locations/states/` |
| Культ Лолс, Дом Вандерли, Хвост Скорпиона… | `world/factions/` |

Один канон-файл на государство. Старые `factions/aelendor.md` и аналоги → **stub** «см. `states/…`» после миграции. Не плодить два «Сейчас».

## Сводка

Живой файл: `world/locations/states-overview.md`  
Дух шаблона: [`templates/states-overview.md`](../../../templates/states-overview.md)

После новой/обновлённой карточки — обновить строку в сводке.  
Экспорт: `pandoc states-overview.md -o states-overview.docx` (и паспорт → docx).

## Слой «на стол» (по запросу)

Шаблон: [`templates/state-table.md`](../../../templates/state-table.md)

- вход для чужаков  
- 1к6 слухов (граница / столица)  
- углубление 1–3 регионов маршрута  
- НПС **этой** вылазки + `npc-registry.md`  
- услуги и цены из экономики паспорта (конкретика)  
- провал дипломатии → последствия паспорта  

Не копировать весь паспорт — ссылка + дельта.  
`pandoc table.md -o table.docx`

## Приоритет источников (страны)

1. Слова мастера  
2. Карта  
3. Открытые главы книг игроков  
4. Qwen — только события, укладываемые в каркас  

## Антипаттерны

- Пустой паспорт («лес, эльфы, король») — запрещённая **простота**  
- Простыня Qwen без полей каркаса  
- Дубль state + faction  
- 40 городов вместо 7–10 регионов  
- Календарь liveliness на 30 дней  
- «Лут для 8 уровня» в экономике  
- Капитан стражи квартала в паспорте  
- Полный данж Разлома в паспорте

## Миграция

1. Собрать факты: overview, карта, книги, старый `factions/<state>.md`, wiki.  
2. Паспорт в `states/`.  
3. Faction-файл государства → stub.  
4. `fill_wave` честно (Аэлендор ≠ автоматом W3).
