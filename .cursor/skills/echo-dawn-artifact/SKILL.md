# Артефакты и магические предметы (канон)

Скил пишет **канон мира**: сводки сетов, карточки предметов (very rare / rare сюжетные и выше), лестницы сет-бонусов/дебафов, живой реестр владения.

Перед работой: [`echo-dawn-canon`](../echo-dawn-canon/SKILL.md).  
Лок решений: [`skill-lock-artifact-v1.md`](../../../campaign/plot/skill-lock-artifact-v1.md).

## Когда вызывать

- «Карточка артефакта / предмета X»
- «Сводка / новый сет»
- «Обновить roster — у кого что»
- «Дебафы / синергия сета»
- Награды уровня **Страж / Овраг** (very rare / rare сюжетные), не мелочь из бочки

**Не использовать для:** обычный лут и расходники (→ квест / локация одной строкой); глав книг; полных квестов; паспортов стран.

## Решения мастера (зафиксировано)

1. Обхват = **сеты + сюжетные уникальные + very rare/rare** сюжетные награды.  
2. Мелочь / расходники — **вне скила**.  
3. Канон = **сводка сета + карточка на предмет**.  
4. **Docx** обязателен (как локации/квесты).  
5. Карточка — **полный стандарт** (см. каркас).  
6. **Официальный** 5e-предмет → только ссылка на источник + где в нашем мире; **homebrew / наша доработка** → **максимум** механики и лора.  
7. Базовые типы: **Кардиан · Драконы · Божественный · unique**; новые сеты — **с мастером**.  
8. Сетовый слот в награду — только **основной квест** или **явный ok** мастера (согласовано с quest-скилами).  
9. Дебафы/синергия: у Кардиана ступени **2…6**; у других сетов — **если есть**, тоже в сводке сета.  
10. Живой **`world/artifacts/roster.md`** (партия + мир).  
11. **Запрет:** легендарка / мощный уникальный предмет **без якоря в мире** (место, владелец, сет-слот или квест).

## Куда класть файлы

```
world/artifacts/
  README.md
  roster.md                 # у кого что (партия + мир) — канон трекинга
  roster.docx
  sets/
    <set-slug>.md           # сводка сета + лестница бонусов/дебафов
    <set-slug>.docx
  items/
    <item-slug>.md          # одна карточка = один предмет
    <item-slug>.docx

campaign/plot/
  skill-lock-artifact-v1.md
```

**Наследие:** сводки Кардиан / Драконы / Божественный пока в `world/lore/artefacts-*.md`.  
При доработке сета — **перенести** (или зеркалить) в `world/artifacts/sets/<slug>.md`, в lore оставить stub со ссылкой. Новые сеты — сразу в `world/artifacts/sets/`.

Шаблоны: [`templates/artifact.md`](../../../templates/artifact.md) · [`templates/artifact-set.md`](../../../templates/artifact-set.md)

### Docx

После `.md`:

```bash
pandoc world/artifacts/items/<slug>.md -o world/artifacts/items/<slug>.docx
pandoc world/artifacts/sets/<slug>.md -o world/artifacts/sets/<slug>.docx
pandoc world/artifacts/roster.md -o world/artifacts/roster.docx
```

Нет pandoc → `python-docx` или сказать Игорю путь к md. **Docs = цель.**

## Типы (`set` / `kind`)

| kind / set | Смысл |
|---|---|
| `kardian` | Артефакты Падения (6); дебафы 2…6 |
| `dragon` | Сет драконов (6) |
| `divine` | Божественная сила |
| `arc-reward` | Сюжетная rare/very rare (Страж, Овраг…) — может быть вне сета |
| `unique` | Уникальный вне сета |
| `set:<new>` | Новый сет — только после согласования с мастером (имя, размер, лестница) |

Поле `rarity`: `rare` | `very rare` | `legendary` | `artifact` (и ниже — только если сюжетно в обхвате скила).

## Официальный vs homebrew (`origin`)

| origin | Что писать в карточке |
|---|---|
| `official-5e` | Имя, редкость, источник (DMG/XGE/… + стр. если есть), аттюнмент да/нет. **Не** копировать полный SRD/DMG-текст. Блок «В нашем мире»: где, у кого, якоря. |
| `homebrew` / `table-mod` | **Максимум**: полный блок 5e 2014 (требования, аттюнмент, свойства, заряды, активация, проклятие), лор, сет, якоря, игрок vs мастер |

Если «официальная база + наши правки» → `origin: table-mod`, в карточке явно: что из книги / что изменено.

## Каркас карточки предмета

Шаблон: [`templates/artifact.md`](../../../templates/artifact.md)

1. **Шапка:** id/slug, title, status:`canon`|`canon-partial`|`prep`, set/kind, rarity, origin, attunement  
2. **Где сейчас** — владелец / локация / «у демонов в Разломе» + ссылка на roster  
3. **История перемещений** (кратко, канон)  
4. **Механика** — по правилам origin выше  
5. **Цена ношения** — проклятие, дебафф ступени сета, социальная/сюжетная цена  
6. **Сет** — слот N из M; что даёт кусок; ссылка на сводку сета  
7. **Якоря поиска** — где слухи / квест / локация (id + одно предложение; полный квест → quest-скил)  
8. **Игрок vs мастер** — что уже известно партии / что скрыто  
9. **Связи** — NPC, локации, квесты, roster  

После записи карточки — **обновить** `roster.md` и строку в сводке сета (если сет).

## Каркас сводки сета

Шаблон: [`templates/artifact-set.md`](../../../templates/artifact-set.md)

1. Имя сета, размер (N предметов), статус, theme  
2. Таблица слотов: # · имя · slug · где сейчас  
3. **Синергия** — бонусы за k предметов (если есть)  
4. **Дебафы / цена** — обязательная лестница, если сет её имеет (Кардиан: **2, 3, 4, 5, 6**)  
5. Правило выдачи: не через побочку без ok мастера  
6. Открытые дыры (TBD) — явно  

Черновики дебафов Кардиана 3+: `drafts/kardian-debuffs-3-artifacts.md` + архив Qwen — **не** канон, пока мастер не залочит ступени 3…6 в сводке сета.

## Roster

Файл: [`world/artifacts/roster.md`](../../../world/artifacts/roster.md)

| Раздел | Содержание |
|---|---|
| Партия | Персонаж → список предметов (slug + краткий ярлык) |
| Мир | Предмет → где / у кого (не у партии) |
| Утеряно / уничтожено | Отдельно |
| TBD | «У партии, кто что неизвестно» (напр. Овраг) |

Обновлять roster **при каждом** канон-сдвиге владения. Не дублировать полную механику — только владение + ссылка на карточку.

## Связь с квестами и локациями

- Побочка / основной: **не** совать сетовый слот или легендарку в лут без ok (см. quest-скилы).  
- В playbook локации — якорь «здесь слух / храм / тайник», не полный статблок.  
- Награда Стража (7 very rare) и Оврага — карточки `kind: arc-reward` + строки в roster, когда мастер скажет кто что взял.

## Антипаттерны

- Легендарка / сет-слот **без** места в мире, владельца или квест-якоря  
- Простыня статов official-предмета вместо ссылки на источник  
- Homebrew в одну строку «меч +1 и ещё что-нибудь»  
- Сетовый кусок в награде побочки  
- Игнор лестницы дебафов при 2+ предметах сета у одного носителя / партии (как заведено сетом)  
- Расходники и обычный лут через этот скил
