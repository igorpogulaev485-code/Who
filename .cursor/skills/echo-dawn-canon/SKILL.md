# Эхо рассвета — канон и репозиторий

Кампания D&D мастера **Игоря**. Репозиторий — источник истины для мира, сюжета и партии.  
Агент в другом чате **не** источник канона. Чат без чтения файлов ≠ «репо пустой».

**Мир живой.** Пока герои медлят, война, Разломы, дворы и фракции всё равно двигаются. Репо и prep не должны описывать застывшую диораму.

### Слои статуса (обязательно)

| Слой | Что это | Когда `canon` / хроника |
|---|---|---|
| **Мир-установка** | Карты, государства, открытые главы книг, факты «так устроен мир» от мастера | Когда мастер сказал — даже если партия не была |
| **Prep / заготовки** | Playbook локаций, квесты, сцены, арты-черновики | Всегда `prep` / `proposal`, пока не сыграли |
| **Хроника стола** | Что реально произошло с партией / NPC на сессии | **Только после игры** → timeline + ужатие в wiki |

Неиспользованные заготовки **не удалять** — можно перешить под другой момент.

## 0. Если кажется, что репо пустой

Сделать **до любого вывода** «ничего нет»:

1. `git branch --show-current` и `git log --oneline -5`  
   Рабочая ветка обычно `cursor/echo-dawn-world-scaffold-*` (не обязательно `main`).
2. Открыть и прочитать:
   - [`CANON.md`](../../../CANON.md) — оглавление
   - [`SOURCES.md`](../../../SOURCES.md) — правила источников
   - [`campaign/plot/open-threads.md`](../../../campaign/plot/open-threads.md)
   - [`campaign/plot/timeline.md`](../../../campaign/plot/timeline.md)
3. `find world campaign assets -type f | head` / посчитать файлы  
   Есть `world/`, `campaign/`, `assets/maps/`, `world/player-books/`, `drafts/imports/` — репо **не** пустой.
4. Только после этого отвечать о состоянии репозитория.

## 2. Иерархия канона (строже сверху)

1. **Слова мастера** в этом чате / канон-локах / сообщениях игрокам  
2. **Карта** (файлы в `assets/maps/` + `world/locations/*-map.md`) — для географии и государств  
3. **Сообщения игрокам** (`campaign/sessions/player-briefs-*.md`) — то, что партия знает  
4. **Открытые главы книг игроков** (Telegraph: фраза-ссылка «Вы изучили эту главу») → `world/player-books/`  
5. Карточки со `status: canon` в `world/`, `campaign/`  
6. Архив Qwen в `drafts/imports/` — **только события**, не советы «что сделать»  
7. `status: prep` / `proposal` / `canon-partial` / `unresolved` — не выдавать за стол как факт без пометки

Для государств см. также [`echo-dawn-state`](../echo-dawn-state/SKILL.md): мастер → карта → книги → Qwen.

При конфликте: правим канон-файлы; **архив не переписываем**.


## 4. Как вносить новый факт

1. Найти **существующую** карточку (`rg` / `CANON.md`) — обновить её.  
2. Обновить `timeline.md` и/или `open-threads.md`, если меняется сюжет «сейчас».  
3. Добавить ссылку в `CANON.md`, если появился новый важный файл.  
4. Сырой длинный текст мастера/шаринга → `drafts/imports/` или `campaign/sessions/player-briefs-*.md`.  
5. Не дублировать один факт в пяти местах разными формулировками: одно место правды + ссылки.

Frontmatter по возможности:

```yaml
---
title: …
status: canon   # canon | canon-partial | prep | proposal | unresolved | archive
tags: […]
source: gm-lock | player-briefs | telegra | qwen-archive
---
```

## 7. Книги игроков

- Оглавление + правило: `world/player-books/README.md`

- Изучение за столом = партия **тратит время**.

Не переписывать текст открытых глав без просьбы мастера.

## 8. Горизонт «сейчас» (не откатывать без нового слова мастера)

- Конец **2-й** арки / старт **3-й**.  
- Партия в **Лунном мосту**.  
- Готовить **оба** пути: Лес Хранителей (Элессар I) **и** Разлом.  
- Не возвращать канон к «едем на осаду Розалии как текущий горизонт», если мастер этого не сказал.

Актуальные якоря читать в `open-threads.md` (война, 5 Разломов, Маэстро, яйца, гарнизон Хребта и т.д.) — файл главнее этого абзаца скила.

## 8a. Живой мир (обязательно)

Мир **не ждёт** партию. Даже если герои ничего не делают (отдых в Лунном мосту, споры, крафт, «пропустим неделю»), события идут.

### Принципы

1. **Часы мира тикают** — фронты, осады, Разломы, дворы, караваны, слухи, смерти NPC не ставятся на паузу из‑за даунтайма партии.  
2. **Бездействие = выбор** — упущенные окна (как награда Хельма в Розалии), потерянные союзники, усиление врага, расширение Разлома — валидные последствия.  
3. **Несколько досок сразу** — война (Долина / Орден / Леса / Хребет / Звёздная Пыль), политика Аэлендора, 5 Разломов, **Марин** (воскрешение Маэстро), яйца в приюте, гарнизон у моста могут сдвигаться **параллельно** с личным квестом партии.  
4. **Глашатай и слухи** — мир сообщает о себе: обновляй / готовь `player-briefs`, фракции, `open-threads`, когда проходит игровое время.  
5. **Prep и советы** — предлагая сессию или «что дальше», всегда закладывай: *что случилось в мире, пока они занимались X*. Не пиши сюжеты вида «все ждут у ворот, пока герои соизволят».  
6. **Канон vs предложение** — движение мира в файлы как `canon` только после слова мастера или явного brief игрокам; как `prep`/`proposal` — можно набрасывать давление фронтов заранее.

### При работе с паузой партии спросить / предложить

- Сколько **игрового** времени прошло?  
- Что сдвинулось на каждом активном фронте из `open-threads.md`?  
- Что игроки **узнают** (глашатай, письмо Филлера, дым над горизонтом, гонец)?  
- Что изменилось **втайне** (только мастер / `prep`)?

### Антипаттерны

- «Пока герои в кузнице, война замирает»  
- «Разлом стабилен, пока не зайдут»  
- «NPC-квесты ждут в таверне вечно без цены»  
- Единственная активная нить = то, на что смотрит партия

## 9. Импорт из Qwen / ссылок

1. URL `/s/...` или Telegraph — сразу полный текст в `drafts/imports/` (или `world/player-books/`).  
2. Порядок ссылок от Игоря: **старые → новые** = хронология.  
3. Извлечь события в канон-карточки; рекомендации Qwen оставить в архиве.  
4. Записать строку в таблицу `SOURCES.md`.

## 10. Вопросы мастеру (обязательный формат)

**Всегда** задавать Игорю вопросы в формате **опросника с вариантами** (выпадающий список / A/B/C), не открытым «что думаешь?».

Правила:

1. Каждый вопрос = **короткий контекст** (что уже в репо / TG) + **закрытые варианты**.  
2. Всегда последний вариант: **«Другое / уточню в заметке»** (+ поле заметки).  
3. Группировать по блокам (A/B/C…), нумеровать стабильными id.  
4. Дублировать: markdown в чате **и** HTML-форма в `campaign/plot/` (как `canon-survey-v2.html`).  
5. Репо **приватный**: raw GitHub / htmlpreview часто **404**. Для Safari — залить самодостаточный HTML на временный публичный mirror (**litterbox.catbox.moe**, ~72 ч) и дать ссылку в чате + в md опросника.  
6. После ответа: `canon-lock-*.md` + правки карточек + `open-threads`/`timeline`. Не оставлять канон только в чате.

Образцы: `canon-survey-v2.html` · `canon-questions-round2.md` · сверка TG: `canon-survey-v3-telegram.html` · `canon-questions-telegram-reconcile.md`.

## 15. Чего не делать

- Не объявлять репо пустым без ритуала §0.  
- Не брать канон из другого чата / саммари агента в обход файлов.  
- Не писать Qwen-советы в `status: canon`.  
- Не сливать два похожих топонима в один.  
- Не переписывать открытые главы книг и архивы imports «для красоты».  
- Не закрывать открытые нити домыслом.  
- **Не замораживать мир**, пока партия простаивает: не предлагать и не фиксировать «ничего не произошло, все ждали героев».
