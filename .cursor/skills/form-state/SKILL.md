# Формирование государства (кампания)

## Когда включать

- «Собери / добей государство», «государственность», «портрет страны»
- Наполнение фракции-державы до уровня, пригодного за столом
- После фиксации прошлого кампании — данные **для будущих** сессий

Не путать с: детальным лором **одного города** (это следующий слой после государства) и с пакетом **квестов** (после якорей «куда пойдут»).

## Граница прошлого

Перед новым лором: что уже сыграно = прошлое; не переписывать. Новое = под будущие сессии.

## Режимы глубины

| Режим | Когда | Объём |
|---|---|---|
| **Full** | Домашняя / центральная держава (как Аэлендор) | Все слои ниже |
| **Lite** | Воюющий сосед / фон войны | Слои 1–2, 4, 7, 10 + короткий 3/6; касты/праздники — только если нужно за столом |
| **Destination MVP** | Куда партия может уйти на сессии (Лес, вход в Разлом…) | Атмосфера, угрозы, 3–5 мест, правила пребывания, 2–3 NPC-якоря |
| **Planar** | Целый план как «государство» (план демонов / план мёртвых) | Как Full, но: космология/пантеон обязателен раньше; биомы вместо провинций; монстры/обитатели отдельным слоем; вход/выход через Разлом |

## Слои (порядок Full)

1. **Идентичность** — тип, роль в мире, гордость народа, эпоха «сейчас vs книги»  
2. **География** — соседи, якоря на карте, спорные рубежи  
3. **Народности → языки → гражданство**  
4. **Власть** — корона/правительство; **двор «сейчас»** (кто реально правит)  
5. **Касты/сословия + вид на улице** (форма между / регалии внутри)  
6. **Религия** — витрина богов (не весь справочник) + реакция на кризис  
7. **Армия / флот / экономика** — что болит на войне  
8. **Образование / ключевые институты**  
9. **Тень** — разведка, криминал (отдельно от публичного)  
10. **Срез «сейчас»** — один кризисный хаб для стола  
11. **Явный список дыр** — не смешивать с каноном  

Праздники: инвентарь из книг → лок найденного → предложения регулярных → утверждение пакетом.

## Процесс интервью

1. Чеклист: уже есть / дыры / режим (Full|Lite|MVP).  
2. **Один вопрос → ответ → лок-файл → апдейт досье → следующий.**  
3. После каждого вопроса (и после лока ответа) агент кратко пишет **как себе это представляет** (атмосфера, стол, риски) — до или сразу после вопроса; не подменяет лок мастера.  
4. Не вываливать 50–100 вопросов списком: объём Planar большой, но ход = **одна** развилка.  
5. История не ослабляет лок; не выдумывать «ок» за мастера без делегирования.  
6. Если мастер делегирует («придумай облики / экономику») — предложить цельный пакет и залочить после явного «берём».  
7. Имена: держать транслит репозитория; не плодить пятые Столпы и т.п. без проверки книг.  
8. В конце блока — **readout** (структурированная сводка) + путь к файлу.

## Артефакты

```
campaign/plot/canon-lock-YYYY-MM-DD-<state>-<topic>.md   # status: locked
world/factions/<state>.md                                 # живое досье
drafts/<state>-statehood-checklist.md                     # чеклист
drafts/<state>-full-portrait-readout.md                   # сводка для чтения
CANON.md                                                  # ссылки на локи
```

Лок: коротко, таблицы, источник `gm-interview-voice` / книга.  
Досье: ссылки на локи, без дублирования простыней.

## Антипаттерны

- Лочить баннер-города, пока не закрыт контур государства (если цель — государство).  
- Писать квесты арки до MVP направлений ухода (план / союзник / фронт).  
- Сваливать гипотезы в канон без пометки draft.  
- Полный пантеон-справочник вместо витрины.  
- Массовая мобилизация / флот «как у всех» без вопроса — спрашивать.

Полный проход: **Аэлендор** (`drafts/aelendor-full-portrait-readout.md`, чеклист `drafts/aelendor-statehood-checklist.md`).

## Planar — доп. порядок слоёв

После идентичности сразу:

- **Пантеон / верховные силы** плана (витрина, потом глубина)  
- **Обитатели и монстры** (кто граждане / кто охота / кто знать)  
- **Города-якоря** (3–7), не россыпь государств  
- **Связь с Разломом и материком** (как магия Аэлендора направляет вход)  
- **Сюжетные крюки** (артефакты Кардиана, Маэстро, арка 3/5)

Эталон в работе: план демонов → план мёртвых (`canon-lock-2026-09-05-razlom-entry.md`).

## После государства / плана

1. Общий вход в Разлом (правила перехода)  
2. **Planar Full** — план демонов (победа арки 3)  
3. **Planar Full** — план мёртвых (Маэстро, Кардиан)  
4. Место уничтожения артефактов Кардиана  
5. Карты  
6. Lite воюющих / баннер-города / квесты  

Квесты — когда есть хоть один описанный «куда войдут».
