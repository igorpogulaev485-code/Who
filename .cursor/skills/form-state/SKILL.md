# Формирование и описание государства (кампания)

## Когда включать

- «Собери / добей государство», «государственность», «портрет страны»
- Страна **уже есть на карте**, но **не описана** — дописать образ и институты
- Sense / кинематографическое / «глазами обывателя» описание
- Наполнение фракции-державы до уровня, пригодного за столом

Не путать с: детальным лором **одного города** → skill **`form-city`**; пакет квестов — после якорей «куда пойдут».

## Две задачи (равноправны)

| Задача | Смысл |
|---|---|
| **Создать** | Новая полития / добить дыры институтов |
| **Описать** | Узел на карте есть; нужен живой текст + структура, чтобы за столом было чем дышать |

«На карте есть ≠ описано». Пока нет sense-portrait и контура слоёв — страна для стола пустая.

## Граница прошлого

Перед новым лором: что уже сыграно = прошлое; не переписывать. Новое = под будущие сессии.

## Режимы глубины

| Режим | Когда | Объём |
|---|---|---|
| **Full** | Домашняя / центральная держава (как Аэлендор) | Все слои ниже |
| **Lite** | Воюющий сосед / фон войны | Слои 1–2, 4, 7, 10 + короткий 3/6; касты/праздники — только если нужно за столом; **sense** — короткий обязателен |
| **Destination MVP** | Куда партия может уйти на сессии | Атмосфера + угрозы + 3–5 мест + правила пребывания + 2–3 NPC; **sense** обязателен |
| **Planar** | План как «государство» | Как Full + космология/пантеон раньше; биомы; обитатели/монстры; вход через Разлом; **sense плана** обязателен |

## Слои (порядок Full)

1. **Идентичность** — тип, роль в мире, гордость народа, эпоха «сейчас vs книги»  
2. **География** — соседи **только с карты**, якоря, спорные рубежи (не выдумывать «рядом», если между ними государства)  
3. **Народности → языки → гражданство**  
4. **Власть** — корона/правительство; **двор «сейчас»**  
5. **Касты/сословия + вид на улице**  
6. **Религия** — витрина + реакция на кризис  
7. **Армия / флот / экономика**  
8. **Образование / ключевые институты**  
9. **Тень** — разведка, криминал  
10. **Срез «сейчас»** — кризисный хаб (война/Разлом) — **отдельным** текстом, не смешивать с вечным образом  
11. **Погружение (sense portrait)** — **обязательный** слой (см. ниже)  
12. **Явный список дыр**

Праздники: инвентарь из книг → лок → предложения → пакет.

## Слой 11 — Погружение (ОБЯЗАТЕЛЬНО)

Цель: читать и **погружаться** — не плакат и не таблица.

### Два текста (не смешивать)

| Текст | Что внутри |
|---|---|
| **Вечный / верхний образ** | Страна как она есть: земля, запах, свет, касты на улице, роль городов. **Без** текущего кризиса (война, Второй Разлом, осада), если мастер не просил «сейчас» |
| **Срез «сейчас»** | Отдельный файл/секция: как война/Разлом **перекрашивают** тот же образ |

### Голос прозы (эталон Аэлендора)

- Лирический, с **изящными сравнениями**; душа важнее слогана.  
- Ясный стержень страны (одна сильная метафора) — но **внутри** живых фраз, не билборд.  
- Сенсорика (запах, свет, кожа, звук) вплетена в повествование.  
- POV: **обычный человек / гражданин любой расы** для верхнего образа.  
- Не вставлять «для агента» аналогии (типа чужих стран мира) в текст канона.  
- Не притягивать соседей «рядом», если карта говорит иначе.  
- Баннер-города страны: кратко, но **живо**, каждый своим запахом/ролью — после общего образа земли.

### Ракурсы (минимум для Full)

Въезд · тело земли · столица власти · духовный хаб · торговый/порт · улица каст · ночь · (опционально рубеж) · контраст **только реальных** соседей · было/стало **только** если пишем срез «сейчас».

Города внутри страны после верхнего образа → углублять skill **`form-city`**.

## Процесс интервью

1. Чеклист: уже есть / дыры / режим; **создаём или описываем?**  
2. **Один вопрос → ответ → лок → досье → следующий.**  
3. После вопроса — краткая «как я это вижу» (не подмена лока).  
4. Не вываливать десятки вопросов списком.  
5. Не выдумывать «ок» за мастера без делегирования.  
6. Делегирование → пакет → явное «берём».  
7. Имена/карта: сверять репозиторий и карты; не плодить ложную географию.  
8. В конце блока — readout + **sense-portrait** (вечный; «сейчас» — если уместно).

## Антипаттерны

- Закрыть институты и **не** написать sense-portrait.  
- Смешать вечный образ с войной/Разломом без запроса.  
- Плакатный телеграф без сравнений и дыхания.  
- «Рядом Лес/ Impерия», если на карте между ними другие государства.  
- Лочить баннер-города до контура государства (если цель — государство).  
- Квесты арки до MVP направлений.
