# Упустили ли описательную часть?

**Короткий ответ: частично да.**

## Аэлендор

| Что есть | Чего нет |
|---|---|
| Структурный портрет государства (касты, власть, война…) — `drafts/aelendor-full-portrait-readout.md` | Цельный **кинематографичный** текст «как пахнет / выглядит / звучит страна» |
| Атмосфера **Лунного Моста** (тучи, фиолетовые молнии, фронтовой быт) — лок | Такие же immersion-абзацы для **Сильванора** и других баннер-городов |
| Короткие «как я это вижу» в чате интервью | Зафиксированная проза в репо для prep/чтения вслух |

## Дом Владыки

| Что есть | Чего нет |
|---|---|
| Ворота (визуал), круги, лорды, витрина обитателей | Sense portrait **плана целиком** |
| 5 семян городов Эха + норма ×4 на круг | Immersion **по каждому городу** (после имён) |

## Решение процесса

В skill `form-state` добавлен слой **11 — Погружение (sense portrait)** для страны/плана и якорей-городов.
