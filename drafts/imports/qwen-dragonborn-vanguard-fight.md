## 🔢 Как работает множитель опыта (правила из DMG, стр. 82)

Множитель применяется **только для оценки сложности боя**, а **НЕ для награды игрокам**. Это критически важное различие:

| Что считаем | Для чего | Применяем множитель? |
|-------------|----------|----------------------|
| **Скорректированный опыт** | Оценка сложности боя (легкий/сложный/смертельный) | ✅ Да |
| **Базовый опыт** | Награда игрокам после боя | ❌ Нет |

---

### Шаг 1: Считаем базовый опыт
Суммируем опыт за каждого монстра **без множителей**.

Пример из вашего боя:
```
К'Тхар (CR 7)          = 3 900 XP
Гор'дук (CR 3)         =   700 XP
Валериан (CR 4)        = 1 100 XP
Гротт (CR 3)           =   700 XP
Огры ×2 (CR 1)         =   400 XP
Орки ×4 (CR 1/2)       =   400 XP
Гоблины ×4 (CR 1/8)    =   200 XP
Скелеты ×4 (CR 1/4)    =   200 XP
Теневые демоны ×3      =   300 XP
──────────────────────────────────
БАЗОВЫЙ ОПЫТ            = 7 900 XP ← это получат игроки
```

---

### Шаг 2: Применяем множитель для оценки сложности

Множитель зависит **только от количества монстров**, а не от их силы:

| Количество монстров | Множитель |
|---------------------|-----------|
| 1                   | ×1.0      |
| 2                   | ×1.5      |
| 3–6                 | ×2.0      |
| 7–10                | ×2.5      |
| 11–14               | ×3.0      |
| 15+                 | ×4.0      |

Ваш бой: **21 монстр** → множитель **×4.0**

```
Скорректированный опыт = 7 900 × 4.0 = 31 600 XP
```

Это число **сравниваем с порогами сложности** для вашей группы.

---

### Шаг 3: Пороги сложности для группы

Таблица из DMG рассчитана на **4 персонажей**. Для других размеров групп применяются коэффициенты:

| Размер группы | Коэффициент к порогам |
|---------------|------------------------|
| 1–2 персонажа | ×2.0                   |
| 3 персонажа   | ×1.5                   |
| 4 персонажа   | ×1.0 (база)            |
| 5 персонажей  | ×0.8                   |
| 6+ персонажей | ×0.5                   |

У вас **9 персонажей** → коэффициент **×0.5**

Пороги для одного персонажа 3 уровня (из DMG):
- Легкий: 75 XP
- Средний: 150 XP
- Сложный: 225 XP
- Смертельный: 400 XP

Для 9 персонажей 3 уровня:
