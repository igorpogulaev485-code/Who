Подход + плотность: [`canon-lock-2026-09-06-demon-plane-cities-approach.md`](../campaign/plot/canon-lock-2026-09-06-demon-plane-cities-approach.md)

**Норма Эха:** ~**4 своих города на каждый круг** (ориентир 36) + лорные must-have.

Статус: must-have зафиксирован как каркас; города Эха наполняем **по кругам**. Стартовые 5 — семя (вшить в слоты кругов при проходе).

| Круг | Город / цитадель | Роль |
|---|---|---|
| 1 Авернус | Ставка / цитадель **Зариэль** | Фронт; выброс Лунного Моста |
| 2 Дис | **Дис** (Железный Город) | Тирания, шпионы |
| 3 Минаурос | **Джанглинг Хайтер** (или столица Маммона) | Алчность, сделки |
| 4 Флегетос | **Абримох** | Двойной двор, огонь/страсть |
| 5 Стигия | **Тантлин** / двор Левистуса | Лёд, заточение |
| 6 Мальболж | Двор **Глазии** | Ловушки, интрига |
| 7 Маладомини | **Гренполи** + руины «идеала» | Ложный закон |
| 8 Кания | **Мефистар** | Магия, холодный ум |
| 9 Нессус | **Мальшим** | Двор Асмодея |
