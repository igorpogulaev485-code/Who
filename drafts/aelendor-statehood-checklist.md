# Государственность Аэлендора — чеклист добивания

Цель: **закрыть общее государство**, без углубления в баннер-города / регионы.

## Дыры государственности (добиваем по порядку)

1. **Народности** — кто граждане / гости / редкость; статус людей; дварфы вне Камнеграда  
2. **Языки** — государственный, уличный, храмовый, торговый  
3. **Двор** — эстетика, этикет, где «двор» без короля (Сильванор / Синклит)  
4. **Армия** — доктрина одним абзацем (не ООБ)  
5. **Флот** — корона vs Розалия; есть ли вообще серьёзный флот  
6. **Казна / валюта** — чем платят, кто держит кошель  
7. **Закон / гражданство** — кто свой, суд светский vs храмовый (рамка)  
8. **Образование / Лесоверье** — школа магии (заявлена, детали пусты)  
9. **Порты / порталы** — логистика государства (порталы уже есть; флот+порты связать)

Города/провинции **откладываем**.
