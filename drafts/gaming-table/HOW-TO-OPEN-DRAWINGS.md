# Как открыть чертежи

Если в браузере виден **код** (`<!DOCTYPE html>…`) — файл сохранён как текст (`.txt`), а не как веб-страница.

## Самый простой способ

Скачай архив **[`chertezhi-stola.zip`](chertezhi-stola.zip)**:

1. Распакуй на рабочий стол.
2. Открой файл **`viewer-standalone.html`** двойным кликом.
3. Должны появиться чертежи и кнопки сверху (План, Разрез…).

Внутри zip также лежат отдельные `drawings/*.svg` — их тоже можно открыть двойным кликом.

## Если уже вставил код в Блокнот

1. Блокнот → **Файл → Сохранить как…**
2. Тип файла: **Все файлы (*.*)** ← важно, не «Текстовый документ»
3. Кодировка: **UTF-8**
4. Имя файла: `viewer-standalone.html` (обязательно `.html` в конце)
5. Сохрани → двойной клик

## Если скачалось как `viewer-standalone.html.txt`

Windows часто прячет расширение:

1. Проводник → **Вид** → галочка **«Расширения имён файлов»**
2. Переименуй файл: убери `.txt` в конце  
   Должно остаться: `viewer-standalone.html`

## Чего не делать

- Не копировать HTML из чата/PR в Блокнот «как текст» без шага «Сохранить как → Все файлы».
- Не открывать файл через «Открыть с помощью → Блокнот» и ждать картинку — Блокнот всегда покажет код.
