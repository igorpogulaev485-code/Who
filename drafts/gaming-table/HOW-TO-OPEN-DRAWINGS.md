# Как открыть чертежи

Нужен файл **`viewer-standalone.html`** (не `viewer.html` и не текст из чата).

## Windows

1. В GitHub / PR открой `drafts/gaming-table/viewer-standalone.html`
2. Кнопка **Raw** → правый клик → **Сохранить как…**
3. Тип файла: **Все файлы**, имя: `viewer-standalone.html`
4. Двойной клик — откроется в браузере с картинками чертежей

Если видишь код HTML — файл сохранён как `.txt`. Переименуй: `viewer-standalone.html`.

## Альтернатива

Открой отдельные SVG из папки `drawings/` — каждый файл сам по себе открывается в браузере или Inkscape.
