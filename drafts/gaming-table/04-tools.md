# 04. Инструменты и расходники

## Минимальный набор (можно собрать стол)

| Инструмент | Зачем | Где взять |
|------------|-------|-----------|
| Шуруповёрт / дрель | Конфирматы, отверстия, коронка | Леман ПРО, есть почти у всех |
| Коронка по дереву Ø93–95 мм | Подстаканники | Леман / Ozon |
| Ручная циркулярка или торцовка | Подгонка, если распил не идеальный | Аренда / Леман |
| Электролобзик | Кривые / подгонка клитов | Леман |
| Шлифмашина (орбиталка) | Плоскости перед финишем | Леман |
| Струбцины F-образные ×6–8 | Склейка реек, клитов, топпера | Леман — **обязательно** |
| Угольник 400 мм + рулетка 5 м | Прямые углы каркаса | Леман |
| Уровень 800–1000 мм | Плоскость ledge и рейки | Леман |
| Набор свёрл по дереву | Шканты Ø8, пилотные отверстия | Леман |
| Кисти / ветошь | Масло / лак | Леман |
| Канцелярский нож + ножницы | Сукно | — |
| Карандаш, малярный скотч | Разметка | — |

Ориентир, если покупать минимум с нуля: **12–25 тыс. ₽**.  
Многое дешевле **взять напрокат** на выходные (циркулярка, торцовка, фрезер).

## Сильно желательно

| Инструмент | Зачем |
|------------|-------|
| Фрезер + пазовая фреза 8 мм и 15–20 мм | Слот телефона, карманы, четверть под ledge |
| Фрезер кромочный | Скругление R3–R5 на рейке (приятно рукам) |
| Кондуктор под шканты / ламели | Точные стыки топпера и длинных реек |
| Мягкая киянка + брусок | Посадка шкантов без вмятин |

## Если есть доступ к мастерской

- Форматно-раскроечный станок — идеальный распил вместо Леман.  
- Ленточная шлифмашина — быстрые плоскости.  
- Лазер/ЧПУ — гравировка топпера и ровные карманы накладок.

## Расходники (кроме BOM)

- Лента малярная 25–50 мм  
- Перчатки нитрил (клей, масло)  
- Респиратор FFP2 (шлифовка фанеры)  
- Очки защитные  
- Мешки под опилки  

## Безопасность

Фанерная пыль — не дышать. Масло/лак — проветривание. Коронкой работать на струбцинах, заготовку не держать руками над пустотой.

## Аренда vs покупка

| Есть дома | Стратегия |
|-----------|-----------|
| Только шуруповёрт | Распил в Леман + аренда шлифмашины и струбцин на 2 дня |
| Шуруповёрт + лобзик + шлифмашина | Хватает для базового стола |
| + фрезер | Делаешь «как на фото» (слоты, карманы, скругления) |
