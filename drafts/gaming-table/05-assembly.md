# 05. Порядок сборки

Ориентир по трудозатратам: **2–4 выходных** при готовом распиле (один человек). Со струбцинами и напарником быстрее.

## Подготовка

1. Проверить комплект деталей по кодам из [02-drawings.md](02-drawings.md).  
2. Разложить на полу «всухую» — план стола.  
3. Промерить диагонали будущего каркаса: должны совпасть (±2 мм).  
4. Проветриваемое место, ровный пол или козлы.

## Этап 1 — Ножки и нижняя обвязка

1. Собрать прямоугольник царг / нижней рамы.  
2. Поставить 4 ножки, зафиксировать уголками + конфирматами.  
3. Проверить: стол не качается, диагонали равны.  
4. Высота до будущей рейки = 750 мм; при регулируемых ногах — выставить позже по уровню.

## Этап 2 — Стенки ниши и дно

1. Собрать короб ниши 1800×700×90 (внутренний свет).  
2. Вклеить / вкрутить дно 12 мм снизу или на четверть.  
3. Короб врезать в верхнюю обвязку каркаса так, чтобы верх стенок был на −18…−20 мм от верха будущей рейки (место под ledge + топпер).  
4. Усилить углы косыми бобышками изнутри.

## Этап 3 — Рейка и ledge

1. Собрать раму рейки: длинные 200 мм, дальняя 200, мастер 350.  
2. Длинные стороны при длине 2200 — стыковать заранее (шканты + усилитель).  
3. На внутренней кромке на высоте −18 мм от верха приклеить/прикрутить **ledge 12×12** по всему периметру ниши.  
4. **Критично:** все 4 стороны ledge в одной плоскости (уровень + правило). Иначе топпер будет качаться.  
5. Скруглить наружную верхнюю кромку рейки R3–R5 (фрезой или бруском с наждачкой).

## Этап 4 — Финиш дерева

1. Шлифовка P80 → P120 → P180.  
2. Обеспылить.  
3. Масло 2 слоя или лак по инструкции (торцы — особенно тщательно).  
4. Сушить полностью **до** оклейки сукном.

## Этап 5 — Сукно

1. Вырезать неопрен с запасом +30 мм по каждой стороне.  
2. Контактный клей на дно (и при необходимости на ткань).  
3. Уложить от центра к краям, разгладить.  
4. Края: заворот под дно **или** заправка в тонкий паз по низу стенок.  
5. Обрезка канцелярским ножом.

## Этап 6 — Топпер

1. Снять фактический проём по ledge.  
2. Подогнать три панели (зазор 2 мм).  
3. Вставить шканты на стыках (ответные отверстия).  
4. Проверить: верх топпера = верх рейки; ничего не качается.  
5. Финиш панелей — как у рейки.

## Этап 7 — Накладки

1. Разметить на заготовках 380×300: слот, карман, центр подстаканника.  
2. Фрезеровать слот и карман (или аккуратно лобзиком + стамеска — хуже).  
3. Коронкой Ø93–95 вырезать отверстие; вставить нержавеющий подстаканник (на силикон или штатный фланец).  
4. Собрать клиты под толщину рейки + 1–2 мм (см. чертёж 07).  
5. Прикрутить клит снизу; наклеить войлок внутри.  
6. Повторить ×8 + станцию мастера 550×400 (лоток кубов углубить / наклеить неопрен).

## Этап 8 — Кубы

1. Собрать 2 мягких лотка (бортики 45 мм + неопрен).  
2. (Опц.) Собрать башню: канал + 3 полки под 35–40° + смотровой лоток.  
3. Навесить клитом у мастера или поставить на DM-tray.

## Этап 9 — Финальная проверка

| Проверка | ОК |
|----------|-----|
| Диагонали каркаса | равны |
| Топпер не качается | да |
| Накладки снимаются одной рукой | да |
| Куб в лотке не выскакивает | да |
| Ширма мастера стоит на рейке 350 | да |
| Ноутбук 16″ на DM-tray | да |
| A4 на player tray | да |
| 8 накладок по периметру не мешают друг другу | да |
| Стол не шатается | да |

## Частые ошибки

- Ledge в разных плоскостях → топпер «пропеллер».  
- Клит впритирку без зазора → не снимается / сдирает лак.  
- Сукно до финиша дерева → пятна масла на ткани.  
- Подстаканник без слива/вкладыша → размокает фанера (нужна нержавейка).  
- Слишком мелкая ниша (&lt;70 мм) → тиррейн не закрывается топпером.

## Уход

- Топпер как обычный стол: салфетки, без луж.  
- Сукно: пылесос мягкой щёткой, пятна — по типу ткани (неопрен обычно влажная салфетка).  
- Раз в год — обновить масло на рейке.
