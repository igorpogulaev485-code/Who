КАК ОТКРЫТЬ ЧЕРТЕЖИ (Windows)

Вариант А — самый простой:
1. Скачай файл viewer-standalone.html из папки drafts/gaming-table/
   (на GitHub: кнопка Raw → правой кнопкой → «Сохранить ссылку как…»)
2. НЕ копируй текст в Блокнот.
3. Если скачался как viewer-standalone.html.txt — переименуй:
   - В проводнике: Вид → поставить галочку «Расширения имён файлов»
   - Удали лишнее .txt в конце, должно остаться только .html
4. Двойной клик по файлу — откроется Chrome/Edge с чертежами (кнопки сверху).

Вариант Б — если уже вставил в Блокнот:
1. В Блокноте: Файл → Сохранить как…
2. «Тип файла» выбери: Все файлы (*.*)
3. «Кодировка»: UTF-8
4. Имя файла точно: viewer-standalone.html
5. Сохрани на Рабочий стол
6. Двойной клик

Вариант В — без HTML:
Открой любой файл из папки drawings/ (например 01-plan.svg) —
он сразу покажется картинкой в браузере.
