# Аэлендор — всё собранное (структура для чтения)

Документ для мастера: **сводка канона** по государству на 2026-09-05.  
Не заменяет отдельные лок-файлы; нужен, чтобы увидеть картину целиком и править skill формирования государств.

**Граница времени:** арки 1–2 = прошлое; арка 3 ещё без сессий. Книги игроков = прошлое (эпоха до Второго Разлома). Сейчас = эпоха **Второго Разлома**.

---

## 0. Одной фразой

Городское эльфийское королевство-хранитель Завесы: без публичного короля правит Синклит; сильная кадровая армия и магия; слабый флот; святой Лунный Мост с Разломом внутри; война раздела на всех рубежах.

---

## 1. Идентичность

| | |
|---|---|
| Тип | Королевство |
| Биом | Леса, центр материка |
| Роль | Хранитель **Завесы** против демонов |
| Столицы | Политика — **Сильванор**; дух — **Лунный Мост** |
| Контраст | vs **Лес Хранителей**: город/статус vs лес/природа; отношения **дружеские, уважительные** |
| Гордость народа | Традиция/история; могущество короны; единение; победа над **Первым Разломом** (без Аэлендора не случилась бы) |

Не путать с Сильванарионом / Сильванионом на карте мира.

---

## 2. География и соседи

| Сторона | Сосед |
|---|---|
| С/СЗ | Теневая Долина |
| СВ | Союз речных долин |
| ЮЗ | Тёмные леса вечной тени |
| ЮВ | Орден пламенеющей стали |
| Запад | Море + горы побережья |

- Провинции есть (белый пунктир); по имени глубоко раскрыта только **Лунные Пики**.
- Баннер-города: Сильванор, Лунный Мост, Розалия, Златоцвет, Элиандор, Вратный град, Хранитель пик, Серебряный предел — **позиции есть, глубокий лор городов отложен**.
- **Столпы Мира — строго 4** на сухопутных рубежах (Северная Завеса / Речное Дыхание / Теневой Корень / Пепельная Грань). **Пятого Столпа нет**; в Лесу — Мировое Древо + Сильфия ≠ Столп.
- Хранитель пик — паломнический узел к Лесу, не Столп.

---

## 3. Народности

- Ядро: **эльфы** всех уместных видов.
- Много: **полуэльфы**.
- Заметно: **дварфы, гномы, сатиры**.
- **Люди:** и постоянные семьи, и гости; в **Розалии** людей много (торговый город), гражданство для них нормально.
- Прочие расы: понемногу.
- **Не население:** орки, гоблины и сходная «негативная» классика.

---

## 4. Языки

1. **Эльфийский** — первый государственный (без раскола «высокий/уличный»).
2. **Общий** — второй государственный (порты, торговля, послы).
3. Общины между собой — на родном (дварфийский и т.д.).

---

## 5. Гражданство и закон

- Только два статуса: **гражданин (= резидент)** или **гость** (туристические условия).
- Урезанного «полугражданина» **нет**.
- **Спрос закона одинаковый** со всех.
- Светский трибунал + храмовые суды (трение юрисдикций = сюжет).

---

## 6. Власть

### Корона
- **Люмиэль** — погиб от **магии Разлома** при открытии (правда мира + улица знает).
- **«Константин III»** — ложная корона; убит на войне.
- **Элессар I** — истинный король; скрыт в Лесу Хранителей; народу неизвестен; из государств знает только Лес.

### Публично
- Правят **советы** → **Верховный Синклит**.
- Председатель: **Филлер** (не «архонт»).
- **Двор сейчас правительственный** (Синклит). Королевского двора как власти нет; семья/свита живут в старой королевской парадигме быта.
- Официально нового короля нет; неофициально у посвящённых всё уже определено (без публичной коронации).

### Синклит — кресла
**Отрасли (9):** маги · рыцари · генералы · старейшины · гражданская коллегия · торговцы · жрецы · адъютанты · Верховный трибунал.  
**Регионы (8):** Сильванор · Лунный Мост · Розалия · Златоцвет · Элиандор · Вратный град · Хранитель пик · Серебряный предел.  
Банкиры — внутри Серебряного Пути, без своего кресла.

### Касты (официальные) + вид на улице
| Каста | Кто | С улицы |
|---|---|---|
| Высшие Дома | Знать | Угольно-зелёный длинный плащ, герб |
| Звёздный Круг | Маги, писцы | Чернильно-синяя мантия, созвездия |
| Щит Луны | Воины | Пепельный мундир, полумесяц |
| Корни | Труд, ремесло | Охра/дерево, зелёный плетёный пояс |
| Серебряный Путь | Торговцы | Серебристый сюртук, «монетные» пуговицы |
| Хранители Завесы | Жрецы | Белое + вуаль + золотая кайма |

Внутри касты — **регалии** на форме (медали, шевроны, перстни…).

### Тень государства
- Теневой Совет Адъютантов (сильный; секрет Элессара); **Кавил** — член.
- Военная контрразведка (армия).
- Маленькая Стража порталов.
- 3 федеральные банды: Чёрная Просека · Паутина Росы · Пепельный Договор; + 2–5 местных/регион; Лунный Мост почти без банд; Хвост Скорпиона уничтожен.

## 7. Религия и Завеса

- Витрина пантеона: **Кореллон, Сеханине, Лабелас, Ханали, Солонор, Аэрдри + обязательно Лолс**.
- Вкус: городские высшие эльфы.
- После Разлома: жрецы успокаивают верой (высшие почти не с улицей; низший клир — да); **радостные ритуалы заморожены**.
- Маги — закрытый контур сдерживания Разлома.
- **Хранители Граней** — живой **мировой** орден (не Аэлендор); до Второго Разлома Обитель в Лунном Мосту **у Зеркала**, управляли узлом.

## 8. Праздники (мирное время; сейчас радость заморожена)

- Событийный: **«Сияние Нового Рассвета»** (сорван).
- Ритм: **цикл Сеханине** (4 фазы); **День Договора** (зимнее солнцестояние).
- Регулярные: День Столпов · Память Первой Печати · Пряжа Корней · Серебряная Ярмарка · Ночь Звёздного Круга · Щит Полумесяца · Слёзы Кореллона · День Единения Каст.

## 9. Армия, флот, экономика, образование

### Армия
Кадровые военные + развитые гарнизоны + опытные полководцы (долгожитие) + **очень сильные маги**.  
Ополчение вторично/слабо. Народ не мобилизуют — обеспечивает гос. жизнь.  
Маэстро (мёртв) — эталон великого заклинателя и учителя.

### Флот
Военный — **слабый** (несколько кораблей у Розалии и другого берега).  
Торговых судов в Розалию — много. Не морская держава.

### Экономика
- Валюта: медь/серебро/золото; наградные «монеты короны» опционально.
- Вывоз: магия, ремёсла, **кристалл-усиленное оружие** (Камнеград).
- Ввоз: через Розалию (чужие суда) + речной восток.
- Тыл: Корни.
- Сейчас болит: осада Розалии + пожар Камнеграда.
- У партии: два вида кристаллов (связь с драконьими яйцами — отдельный трек).

### Образование
Максимально образованное государство; школы/академии в каждом городе.  
**Лесоверье** = Великая магическая академия, колыбель могущества (не единственная школа).

## 10. Лунный Мост — срез «сейчас»

- Разлом **внутри** города (не «рядом»).
- Небо с фиолетовыми молниями **только над городом**; маги сжали бурю к месту Разлома.
- Фронтовой быт: паника → смирение → каждый на своём посту; народ помогает армии/магам, не мешает.
- Ритуалов радости нет.
- После Серебряного Стража: в Чаше — разобщённые остатки Долины, армия зачищает; осторожное доверие к контрнаступлению.
- 3 дракона Хребта (чёрный/зелёный/красный) со всадниками в Чаше; город под Тандилом.

## 13. Что сознательно НЕ добито (и ок)

1. Глубокий лор **баннер-городов** и белых провинций.  
2. Имена ректоров Лесоверья / казначея / трёх драконов + всадников.  
3. Точная дата Памяти Первой Печати; ритм Дня Единения (ежегодно vs 12 лет).  
4. Участок фронта Хостии на земле.  
5. Какие именно части драконьего сета где (кроме: кольцо зелёного у Грока из Розалии; в Мосту части нет).  
6. Детальная эстетика этикета двора (есть только политическая рамка).

## 14. Каркас для skill «формирование государства»

Шаблон слоёв, который сработал здесь (можно перенести в skill):

1. Идентичность + гордость + эпоха  
2. География / соседи / якоря на карте  
3. Народности → языки → гражданство  
4. Власть: корона / правительство / двор «сейчас»  
5. Касты/сословия + **вид на улице**  
6. Религия (витрина, не весь справочник) + кризис веры  
7. Армия / флот / экономика (что болит на войне)  
8. Образование / ключевые институты  
9. Тень (разведка, криминал) — отдельно от публичного  
10. Срез «сейчас» для стола (один город-кризис)  
11. Явный список **дыр**, не смешанный с каноном  

Правило интервью: **один вопрос → лок → следующий**; делегированные куски (облик каст, экономика) агент предлагает целиком на утверждение.
