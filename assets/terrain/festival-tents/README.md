# Фестивальные шатры — STL с местом для миниатюр

Набор из **6 павильонов** в стиле festival/tournament tents (референс: [`reference/festival-tents-ref.jpg`](reference/festival-tents-ref.jpg)).

Масштаб: **28 мм** (1″ = 5 футов).

## Главное для игры

Каждый шатёр печатается **двумя деталями**:

| Деталь | Зачем |
|--------|--------|
| `*_walls.stl` | Полые стены, **без пола** — ставятся на сукно/плитку |
| `*_roof.stl` | **Съёмная крыша** — снимаешь, ставишь миниатюры, надеваешь обратно |

Проёмы рассчитаны под базу **25 мм** и рост миниатюры ~32 мм:

- дверь ≈ **26 × 34 мм**
- высота стен внутри ≈ **38 мм**
- толщина стенки **2 мм**

Проверено пересечением меша: миниатюра проходит в дверь и стоит внутри без коллизии со стенами.

## Печать (FDM)

- Сопло 0.4, слой 0.16–0.2 мм  
- Заполнение 10–15%, стенки 2–3  
- **Стены:** печать как есть, дверь к платформе или на боку — обычно без поддержек  
- **Крыши:** плоской посадочной стороной вниз; флаги/шары — при необходимости tree supports  
- Не склеивать крышу со стенами — она должна сниматься

## Как использовать на столе

1. Поставь `walls` на стол.  
2. Заведи миниатюры через дверь **или** сними крышу и поставь сверху.  
3. Надень `roof` на внутренний уступ стен.  
4. Для лагеря комбинируй с плитками из [`../field-camp/`](../field-camp/).
