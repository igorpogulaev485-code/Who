# Полевой лагерь — STL для 3D-принтера

Модульный набор тиррейна полевого лагеря под миниатюры **28 мм** (сетка D&D: **1″ = 5 футов**).

Базовая плитка: **50.8 × 50.8 мм** (2″). Детали ставятся сверху на плитки или прямо на сукно стола.

## Рекомендации по печати (FDM)

- **Сопло:** 0.4 мм  
- **Слой:** 0.16–0.2 мм  
- **Заполнение:** 10–15% (плитки можно 5–8%)  
- **Стенки:** 2–3  
- **Поддержки:** обычно не нужны; для `14_watch_post` при проблемах с лестницей — tree supports  
- **Масштаб в слайсере:** 100% = 28 мм; для 32 мм миниатюр можно ~110–115%  
- **Количество на лагерь:** 9–16 плиток, 2–4 wedge-палатки, 1 командная, 1 костёр, 2–3 баррикады, периметр из частокола

## Как пересобрать STL

```bash
pip install numpy trimesh numpy-stl
python3 assets/terrain/field-camp/generate.py
```

Скрипт перезапишет файлы в `stl/`.

## Как собрать лагерь на столе

1. Выложи сетку плиток 3×3 или 4×4.  
2. Командную палатку — в центр/тыл, солдатские — по бокам.  
3. Костёр — в центре открытой площадки.  
4. Частокол/баррикады — по периметру со стороны угрозы.  
5. Ящики, бочки, оружейная стойка, знамя — scatter у палаток.  
6. Смотровая площадка — на углу лагеря.

Подходит для энкаунтеров вроде лагеря орков/наёмников, бивака отряда, осадного лагеря у дороги.
