# Барханы для карты боя

Модульные песчаные дюны под битву в пустыне / барханах. Масштаб ориентирован на миниатюры **32 мм**; на ветреных склонах миниатюры стоят, подветренный склон круче (difficult terrain / укрытие).

Референс формы: классический **бархан** (полумесяц), гряда, холмик, сейф-дюна, плитка ряби.

## Печать (FDM)

- Плоской подошвой на стол (уже ориентировано)
- Слой 0.16–0.2 мм, заполнение 8–12%
- Поддержки обычно **не нужны**
- Песок хорошо смотрится в бежевом/охре PLA; сухая кисть светлее по гребням

## Как класть на карту боя

1. Направление «рогов» бархана — по ветру (подветренная сторона).  
2. Крутой склон = difficult terrain / half cover.  
3. Плитки ряби — заполнить промежутки между крупными дюнами.  
4. Гряду и сейф — как линейные препятствия / линии обзора.
