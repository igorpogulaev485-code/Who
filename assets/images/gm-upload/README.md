# Картинки от мастера (inbox)

Сюда кидай **ранее сгенерированные** арты — я подключу в ранбук / канон / iili.

## Как подгрузить (любой способ)

### 1. В чат Cursor (проще всего)
Прикрепи файлы к сообщению агенту (`+` / drag-and-drop в чат) и напиши одной строкой на файл:
`имя-файла = кто/что (НПС Кардиан / карта Амират / сон 2 могилы / …)`

### 2. В эту папку репо
Через IDE: Upload / drag в  
`assets/images/gm-upload/`  
Имя файла латиницей, понятное: `npc-kardian-alt-01.jpg`, `map-amirat-sketch.png`.

Потом в чате: «забери gm-upload».

### 3. Пачками
Можно zip в `gm-upload/` — распакую и разложу.

## Что писать к каждой картинке

| Поле | Пример |
|---|---|
| Кто/что | Кардиан · лицо / Маэстро · шатёр / Берег Памяти · карта |
| Куда | ранбук гл.11 / сны 19 / мир 20 / канон NPC |
| Канон? | да (face-lock) / нет (вариант / атмосфера) |
| Заменить? | старый URL / оставить как доп. кадр |

## Куда я разложу

| Тип | Папка |
|---|---|
| Портреты НПС | `assets/images/npc/` |
| Локации / сцены | `assets/images/…` или `dreams/` |
| Карты | `assets/maps/` |
| HTTPS | `image-urls.json` + заливка iili |

Не удаляю исходники без твоего ok.
