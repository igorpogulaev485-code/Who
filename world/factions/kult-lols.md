# Культ Лолс

Теневой культ. Алтарь в Лунном Овраге; черепа с фиолетовыми глазами; одержимость. Пленников сессии 07, по оценке мастера, телепортировали в сторону храма на пути к Розалии.

## Храмы (лок 2026-09-05)

Храмы Лолс есть **по всему миру**. В них (или через них) спрятаны **артефакты**, за которыми в Аэлендор пришёл авангард **Драконьего Хребта**.

| Место | Артефакт Хребта | Заметка |
|---|---|---|
| **Розалия** | есть храм; статус артефакта уточнять | Город в осаде |
| **Лунный Мост** | храм есть; **артефакта нет** (известно) | Разлом у/около этого храма |
| Другие точки мира | неизвестно | К наполнению |

Связь культа с Разломом / Кардианом — открытая нить (не выдумывать мотив Хребта глубже «ищут артефакты в храмах Лолс», пока мастер не добавит).
