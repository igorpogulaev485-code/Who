# Аэлендор

Эльфийское **королевство** в центре материка мира «Эхо рассвета». Биом — **леса**.  
Хранитель **Завесы** (удерживает демонические вторжения).  
Духовный центр — **Лунный Мост**; политическая столица — **Сильванор**.

Карты: [`aelendor-map.md`](../locations/aelendor-map.md) · [`aelendor-centers.md`](../locations/aelendor-centers.md) · [`states-overview.md`](../locations/states-overview.md)  
Война: [`war-fronts-arc3.md`](../../campaign/plot/war-fronts-arc3.md)  
Граница прошлого: [`past-present-boundary.md`](../../campaign/plot/past-present-boundary.md)

## 1. Идентичность

| | |
|---|---|
| Тип | Королевство |
| Роль в мире | Хранитель Завесы; один из центров эльфийской цивилизации |
| Контраст | vs **Лес Хранителей** (отдельное государство): Аэлендор — «высшие» эльфы, **города и статусность**; Лес — «лесные», единение с природой, поселения ближе к деревням |
| Мифологический образ (книги игроков) | «Крепость камня и ремёсел»; договор с древними драконами; **Столпы Мира** на границах |

Не путать с государствами **Сильванарион** (СЗ) и **Сильванион** (ЮЗ).

## 2. География и соседи

Соседи по карте Аэлендора (приоритет над ранней устной вводной):

| Сторона | Сосед |
|---|---|
| СЗ / север за горами | **Теневая Долина** |
| СВ | **Союз речных долин** |
| ЮЗ | **Тёмные леса вечной тени** |
| ЮВ | **Орден пламенеющей стали** |
| Запад | **море** + горная гряда вдоль побережья |

Внутри: белый пунктир = провинции. Зафиксирована по имени только провинция **Лунные Пики** ([`lunnye-piki-map.md`](../locations/lunnye-piki-map.md)).  
Дороги сходятся в **Сильваноре**.

Через море от **Розалии** — **Империя Звёздной Пыли**.  
Путь к **Лесу Хранителей** (ЮВ материка): юг Аэлендора → Хранитель пик / Орден → дальше.

## 3. Население

**Канон (слова мастера):** эльфы всех видов, дварфы, гномы, сатиры, полуэльфы.

Локальные акценты:
- **Розалия** — преимущественно эльфы; люди и прочие — гости/меньшинство.
- **Камнеград** — дварфийский город у/внутри гор (сожжён).
- **Лунный Мост** — три яруса от монастырей до портовой толпы рас.
- **Харенгоны** в Аэлендоре редкость.

Языки, касты, повседневная религия государства целиком — **ещё не зафиксированы** (к наполнению).

## 4. Власть и институты

### Корона

| Фигура | Статус |
|---|---|
| **Люмиэль** | Король; **убит** → пробуждение Разлома в Лунном мосту |
| **«Константин III»** | Публичная ложная корона (адъютант); **убит на поле боя** |
| **Элессар I** | **Истинный** король; брат Люмиэля; ~500+ лет в Лесу Хранителей (воля матери — избежать войны за трон) |

Карточки: [`elessar-i.md`](../npcs/elessar-i.md) · [`konstantin-iii.md`](../npcs/konstantin-iii.md)

### Институты

- **Орден / Совет адъютантов**
- **Теневой Совет Адъютантов** — разведка/тайные операции; **Кавил** — член (после Стража): архивы «Секретно», вето на локальные операции разведки, прямой канал с высшим командованием
- **Верховный адъютант Филлер** — духовный наставник / начальник Кавила; после «смерти Константина» дал титул **Старшего адъютанта**, картину войны и **три пути** (столица / охота на предателей / диверсия во вражеском стане); приказ: не допустить воскрешения Кардиана, артефакты уничтожить
- **Стража Лунного моста**
- **Мэр военного времени Лунного моста** — **Тандил** (после гибели Маэстро)
- **Совет Магов** (Сильванор) — упоминался как цель героев ранней арки; состав/полномочия не расписаны

История арки 1: после Разлома в Лунном мосту — диктатура **Велариса** (агент Теневой Долины; разоблачён, сбежал).

## 6. Война — статус *сейчас*

Нападали (Филлер): Теневая Долина · Орден · Хостия · Звёздная Пыль (предательство) · Тёмные леса.  
«Почти все поселения потеряны»; Сильванор возвращён; временный союз с авангардом **Драконьего Хребта**.

После возврата **Серебряного Стража**:

| Фронт | Статус |
|---|---|
| Теневая Долина | Снабжение обрублено; группировка в глубине **отрезана**; Аэлендор в **контрнаступлении** |
| Тёмные леса | Связь с Долиной разорвана; атташе → **перемирие** |
| Орден | **Не остановились**; у стен Сильванора |
| Звёздная Пыль | Враг; морской фронт / Розалия |
| Драконий Хребет | Ситуационный союзник; гарнизон у Лунного моста; Камнеград сожжён |
| Разлом Лунного моста | Расширился во время штурма Стража; Велиан ушёл закрывать — судьба неизвестна |

Индекс: [`war-fronts-arc3.md`](../../campaign/plot/war-fronts-arc3.md).  
Победа на земле = **арка 4**, не 3.

## 7. Разлом и Завеса

- Аэлендор — **хранитель Завесы**.
- В мире **7** Разломов; **5** активны. Один — в **Лунном мосту** (пробудился при убийстве Люмиэля).
- У демонов в Разломе: **маска, кинжал, медальон** Кардиана.
- История: временная печать Маэстро у Лунного оврага (арка 1).

## 10. К наполнению (будущие сессии)

Явно **не** канон, пока мастер не заполнит / не залочит:

1. Имена и роли остальных внутренних провинций (белый пунктир).
2. Лор баннер-городов: Златоцвет, Элиандор, Вратный град, Хранитель пик, Серебряный предел.
3. Культурный гайд: языки, вера, праздники (кроме сюжетного фестиваля коронации), эстетика двора.
4. Состав Советов, казна, флот, военная доктрина.
5. Статус **Розалии** и **Хостии** на фронте *после* контрнаступления.
6. Формальность союза с Драконьим Хребтом при гарнизоне у священного города.
7. Привязка **Столпов Мира** к карте.
