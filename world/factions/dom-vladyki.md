# Дом Владыки

Полития **плана демонов**. Живое досье — наполняется локами интервью.

## Идентичность

- Устройство: **Дом Владыки** (единый двор).  
- Гордыня — стержень.  
- Космология: треугольник **боги / ангелы / демоны** = заявленный баланс; на деле — ложь / искажение / личная игра (по демону).  
- Действуют через **грехи**.  
- Лок: [`canon-lock-2026-09-05-demon-plane-identity.md`](../../campaign/plot/canon-lock-2026-09-05-demon-plane-identity.md)
