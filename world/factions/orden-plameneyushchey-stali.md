# Орден пламенеющей стали

Сосед Аэлендора с юга / юго-востока. Один из участников вторжения.

## Сейчас

Поражение / возврат Серебряного Стража их **не остановил**. Легионы всё ещё у стен **столицы Аэлендора (Сильванор)**. Остаются **ядром вторжения**; не отступают.
