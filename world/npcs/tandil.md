# Капитан Тандил

Капитан городской стражи. Резкий, без церемоний. По рекомендации Келебрима навёл группу на банду **«Хвост Скорпиона»** в Поющих Стоках (сессия 1): дань с торговцев, грабежи, кража припасов фестиваля; награда 110 зм из казны.
