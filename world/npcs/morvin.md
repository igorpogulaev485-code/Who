# Морвин

Древняя травница Лунного Моста (эльфийка). Герои спасали её; в доме держала свидетеля поджогов — **Пиппина** (тогда без памяти / без сознания).

Канон: дом + линия с Пиппином после поджогов — **целиком**. См. [`pippin.md`](pippin.md).
