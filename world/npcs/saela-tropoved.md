# Саэла Троповед

Зайцегонша-проводник троп у **Храма Серебряного Порога** (Лес Хранителей).

Портрет (ранбук): [`../../campaign/prep/arc3-visual-book/chapters/11/25-саэла-троповед.md`](../../campaign/prep/arc3-visual-book/chapters/11/25-саэла-троповед.md)

## Роль

| | |
|---|---|
| Зона | Тропы ухода от Порога |
| Функция | Указывает пути: **Силвания** / **Малфурион**; глушь — без провожатых |
| Бой | scout-lite (не босс) |

## Канон после с.1–2 арки 3

- Свидание с **Балтаном** на Пороге.  
- От **родителей** — **камень перемещения между планами**; посещает **план фей**.  
- После попытки кражи Плачем звезды камень **вернули ей**.  
- Получила в дар арбалет **Звездострел** от Балтана (извинение).
