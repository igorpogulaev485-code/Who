# Маэстро Келебрим

Убит **демонами** в Лунном мосту после того, как Грок передал ему 3 артефакта Кардиана (кинжал, медальон, маска) — артефакты унесли в Разлом.

## Воскрешение (канон-хуки)

1. **Дневник** — частично изучен (стр. **16, 17, 29–32, 52–55**). Стр. 16–17 = **Двойник**; 29–32 = Первый Разлом / семья Кардиана. Лок: [`../../campaign/plot/canon-lock-2026-09-24-maestro-clone.md`](../../campaign/plot/canon-lock-2026-09-24-maestro-clone.md) · [`../../campaign/plot/canon-lock-2026-09-24-diary-pages-29-32.md`](../../campaign/plot/canon-lock-2026-09-24-diary-pages-29-32.md).  
2. **Дверь R** (ранбук [гл. 18](../../campaign/prep/arc3-visual-book/chapters/18-index.md)): путь через сосуд.  
   - За жизнь: **7** успешных сосудов; переездов души **2–4**.  
   - **Готовый:** храм в пустыне **Амирата** (~с.**15**; ловушки / путь).  
   - **Растущий:** **Кузад-Дум** (некромантия / чёрная магия; чужие боятся → счёл безопасным).  
   - Душа у **демонов** (не на плане мёртвых) → без освобождения клон не примет.  
   - При успехе: полная сила сразу; пробелы памяти + инструкции восполнения.  
3. **Писчее перо** — у партии.  
4. План мёртвых — **не** про душу Маэстро (другие цели).  
5. Дочь **Милана** — параллель (боги/кастеры); про сосуд только `f_hint`. Гонка: **один** победитель. [`milana.md`](milana.md)  
6. Визуал (лок): портрет + шатёр — галерея [11/40](../../campaign/prep/arc3-visual-book/chapters/11/40-маэстро-келебрим.md) · [11/41](../../campaign/prep/arc3-visual-book/chapters/11/41-маэстро-шатёр.md).
