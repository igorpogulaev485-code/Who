# Сет артефактов божественной силы (5 шт.)

**Канон мастера (замысел):**
- Сет из **5** артефактов божественного происхождения.
- Каждый могущественен сам по себе; **все 5 вместе** дают синергию «почти бог».
- **Секира Правосудия** — у **Грока** (на момент чата). Статы мастера:
  - 1к12, двуручное тяжёлое;
  - 1 заряд / продолжительный отдых;
  - заряд: на 1 минуту все броски секиры с преимуществом + доп. 1к12 урона; урон магический.
- Группа идёт в **Розалию**; у Грока место силы **Хельма**; бог обещал вознаграждение веры → **ещё один артефакт из этого сета**.
- Щит в сете **нельзя** сочетать с двуручной секирой — мастер отклонил такой вариант.

Остальные 4 предмета и синергии — **черновик Qwen** (в т.ч. промпты визуализации секиры).
