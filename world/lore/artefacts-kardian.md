# Артефакты Кардиана

Шесть («Артефакты Падения»). Цель Филлера: не дать воскресить Кардиана; уничтожить артефакты.

Глава книги: [`Artefakty-Padeniya…`](../player-books/chapters/Artefakty-Padeniya--Sozdanie-shesti-predmetov-Tmy-12-05.md)

## Шесть предметов

| # | Название | Где сейчас |
|---|---|---|
| 1 | **Маска знаний** | У демонов в Разломе |
| 2 | **Кинжал души** | У демонов в Разломе |
| 3 | **Доспехи смерти** | **Льды** (Ледяной Союз) |
| 4 | **Меч разрушений** | **Империя Драконьего Хребта** |
| 5 | **Сапоги покрова** | **Империя Звёздной Пыли** |
| 6 | **Медальон призыва** | У демонов в Разломе |

**У партии:** ничего.

Цепочка трёх: Грок носил **маску + кинжал + медальон** → отдал Маэстро в Камнеграде → демоны убили Маэстро → унесли в Разлом.

## Цена ношения (канон)

Считается число артефактов Кардиана **на одном носителе** одновременно. Эффекты **накопительные**: каждый новый уровень добавляется к предыдущим.

| # | Название ступени | Эффект |
|---:|---|---|
| **1** | Эхо | Носитель **чувствует** остальные артефакты (направление / пульс / зов — по ситуации). |
| **2** | Сны | Сны о прошлом Кардиана; **влияют на разум** персонажа (эмпатия, навязчивые образы, давление на решения). |
| **3** | Бессонница плоти | **Долгий отдых не работает** (игромеханически). |
| **4** | Разомкнутый контур | Заклинания носителя наносят **двойной урон**; урон **по нему** от заклинаний — тоже **двойной**. |
| **5** | Чужая воля | Персонаж **перестаёт подчиняться игроку** (контроль у Мастера / Кардиана). |
| **6** | Воскрешение | Персонаж **теряет себя**; в теле **воскресает Кардиан**. |

### Заметки мастера

- Ступени 1–2 — в основном нарратив + давление на отыгрыш; 3–6 — жёсткая механика / сюжетный триггер.
- Грок на пике держал **три** → уже был на ступени «долгий отдых не работает»; сны (ступень 2) и пропитка после сдачи предметов — следствие.
