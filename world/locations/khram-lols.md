# Храм Лолс

На **самом длинном** пути к Розалии (между Мёртвым городом и фермой). Частично продуман мастером; детальная головоломная проработка — в чате Qwen (архив + файлы ниже).

## Канон / замысел мастера

- Храм = **одна сплошная сложная головоломка** (запрос игроков).
- Внутри: **демон**, **шаман орков**, **пленники** (Дранник, Мёртвый Лист, Багал) — согласуется с подготовкой боёв.
- Здесь же по замыслу спрятан **первый** кусок драконьего сета для **Кеши**.
- Мастеру нужны **физические реквизиты** на стол (списки закупок — в детальных файлах).

## Ключевые механики (принятые направления)

1. **Зал 6 статуй** — повернуть каждую в верном направлении по загадкам окружения; у каждой загадки **2 ложных следа**; все 6 верно → отражённый луч открывает дверь.  
   → [`khram-lols/hall-six-statues.md`](khram-lols/hall-six-statues.md)
2. **Наказания за ошибки** — мучают разум, не мгновенный TPK.  
   → [`khram-lols/punishments.md`](khram-lols/punishments.md)
3. **10 независимых туннелей** — текстовые загадки «продолжи фразу».  
   → [`khram-lols/ten-tunnels-riddles.md`](khram-lols/ten-tunnels-riddles.md)
4. Ранняя общая структура «Паутина Судьбы» (залы до статуй/туннелей):  
   → [`khram-lols/structure-web-of-fate.md`](khram-lols/structure-web-of-fate.md)
