# Пять верных столиц

Союзники Аэлендора (предложены при ложном «Константине»). Партия **выбрала путь** в **Империю Звёздной Пыли**, но **не дошла**: маршрут через **Розалию** → осада → разворот → **Лунный Мост** через **Камнеград**.  
Лок: [`canon-lock-2026-09-05-telegram-v3.md`](../../campaign/plot/canon-lock-2026-09-05-telegram-v3.md).

**Не путать:** TG «Моредон / Элдеринская гавань» = отдельное государство [`elderinskaya-gavan.md`](elderinskaya-gavan.md), **не** одна из пяти верных столиц (пятая гномья нога = **Ульфгард**).

## 1. Империя Звёздной Пыли — **Небесный Форт** *(путь выбран, визит не состоялся)*

- Правитель: император Вентариус IV (медитация); фактически Великий Магистр **Кайрос Вентарий**
- Связь: Аэлендор хранит Завесу; общая история Пяти Жертв
- Позже: **предательство** Аэлендора (причина для партии ещё закрыта)

## 2. Ледяной Союз — **Гримхельм**

- Столица: Гримхельм (в лоре также Храм / сердце льда — деталь внутри города)
- Верховная жрица **Фростара Безмолвная** (из ранней сводки)
- Здесь выковано Зеркало Завесы; тают священные льды

## 3. Союз свободных гномов (клан Ульфгард) — Кузня Судьбы

- Верховный кузнец **Громм Твердорук**
- Кристаллы для защиты Лунного Моста; шахты под атакой

## 4. Халифат / Амират — **Аль-Харима**

- Султан **Амалий I**
- Знания некромантических печатей; столица в осаде мятежников (ранняя сводка)

## 5. Лес Хранителей — **Сильвания** / **Древо Мира**

- Два имени **одного** места (оба ок)
- Совет Древних Друидов; связь с Мировым Древом / Лунным Мостом
- Здесь **Элессар I** (истинный король)
