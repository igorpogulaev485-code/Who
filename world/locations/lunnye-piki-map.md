# Провинция Лунные Пики

Файл: [`assets/maps/lunnye-piki-map.jpg`](../../assets/maps/lunnye-piki-map.jpg)  
Аэлендор целиком: [`aelendor-map.md`](aelendor-map.md)

Локальная карта вокруг **Лунного моста**: котловина / долина в кольце снежных пиков, залив/река на СЗ.

## Подписанные места

| Место | Положение | Заметка |
|---|---|---|
| **Лунный мост** | Центр, у озера | Точка партии сейчас; зелёные крыши / дворец |
| **Серебряный Страж** | Север, у побережья | Аванпост, который вернули в финале 2-й арки; сейчас восстанавливают |
| **Камнеград** | Восток, в снежных пиках | Врата/проход в горах; **сожжён** драконами авангарда |
| **Лунный овраг** | Южнее Лунного моста | Деревня (битвы арки 1) |
| **Чаша Шепотов** | Долина/лес севернее Лунного моста | Подпись над местностью (не город) |
| **Серебряный Ручей** | СЗ у побережья, западнее Стража | Небольшое строение |
| **Туманный клык** | Западные горы | Башня / форпост |
| **Перевал Туманного Клыка** | Западнее/севернее, арка в скалах | Горный проход |
| **Тихий брод** | Между Туманным клыком и Лунным мостом | Переправа |
| **Белый шип** | Западный край карты | Белая крепость |
| **Звёздная Поляна** | Дорога Лунный мост → Камнеград | Небольшая стоянка / дом |
| **Рассветный путь** | СВ от Лунного моста | Лагерь (палатки) |
| **Поле павших героев** | ЮВ, бурая равнина | Статуя воина со щитом и копьём |
| **Ручей Красных Листьев** | СЗ водный путь / залив | Гидроним |

## Дороги

Главная ось **запад↔восток**: Белый шип → Туманный клык / Тихий брод → **Лунный мост** → Звёздная Поляна → **Камнеград**.  
Ветки на север к **Серебряному Стражу** и на юг к **Лунному оврагу**.

## Важно: два «Серебряных»

| Название | Карта | Где |
|---|---|---|
| **Серебряный Страж** | Лунные Пики | Север провинции у воды — **тот самый** аванпост из арки 2 |
| **Серебряный предел** | Карта Аэлендора | ЮВ рубеж у Ордена пламенеющей стали — **другое место** |

Раньше ошибочно сливали в одно — **исправлено**.

## Сейчас для партии

Стоят в **Лунном мосту**. Рядом: восстановление Стража (С), пепелище Камнеграда (В), Лунный овраг (Ю). Выбор — дальше в мир (Лес Хранителей) или в Разлом (точки Разлома на карте не подписаны).
