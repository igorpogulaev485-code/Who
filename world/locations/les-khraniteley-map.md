# Карта Леса Хранителей

Файл: [`assets/maps/les-khraniteley-map.jpg`](../../assets/maps/les-khraniteley-map.jpg)  
Мир: [`world-map.md`](world-map.md) · эталон **стиля** (не границ): [`aelendor-map.md`](aelendor-map.md)  
Паспорт государства: [`states/les-khraniteley.md`](states/les-khraniteley.md)

Красный пунктир — **внешние границы государства с карты мира** (не контур Аэлендора). Белый пунктир — тропы. Чёрные линии — дороги гонцов.

## Контур (чтение с карты мира)

| Край | Что на мире |
|---|---|
| Запад | Горная стена Пепельных земель |
| Север | Рубеж с Орденом пламенеющей стали |
| Восток | Подступы к Элдеринской гавани |
| Юго-восток | Переход к Болотам скорби |
| Юг | **Берег залива** (не сухопутная граница с Хребтом) |
| Сквозь лес | Река с запада в залив |

## Соседи (подписи на карте)

| Сторона | Сосед |
|---|---|
| С | **Орден пламенеющей стали** |
| З | **Королевство пепельных земель** |
| В | **Элдеринская гавань** |
| ЮВ | **Хозяйство болот скорби** |
| Ю (через залив) | **Империя Драконьего Хребта** |

## Места с баннерами (канон карты)

| Место | Положение | Роль |
|---|---|---|
| **Силвания** | Центр | **Столица**; живой древесный город |
| **Мировое Древо** | Севернее столицы | Святыня; «пятая столица» союза в дипломатии |
| **Серебряный Порог** | СЗ, у гор / гостевой тропы | Храм-порог для чужих посланников (не столица) |
| **Северная Заводь** | Север, у реки | Речной рубеж / застава гонцов к Ордену |
| **Восточные Врата** | Восток | Ворота к Элдеринской гавани |
| **Зелёные Топи** | ЮВ | Влажные кроны; якорь **Сильфии Вечный Ветер** |
| **Круги Бури** | ЮЗ, глубь леса | Круги друидов; путь к **Малфуриону** / совету |
| **Пепельный Рубеж** | Запад у гор | Рубеж к Пепельным землям |

## Ландшафт (чтение карты)

Густой полог; река гора→залив; запад — скалы; юг — **рваный берег и острова залива**; ЮВ — топи. Не кольцо гор Аэлендора.
