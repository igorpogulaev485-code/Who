## Контур (лок мастера)

Государство — **не** только северный лесной «пузырь». В красной обводке:

| Часть | Содержание |
|---|---|
| Север / СЗ | Густой лес (лейбл «Лес Хранителей» на карте мира) |
| Запад | Восточные склоны гор Пепельных земель |
| Центр–юг | **Большой залив** с островами — **внутри** границ |
| Восток | Подступы к Элдеринской гавани / кромка Болот скорби |
| Юг обводки | По воде, **севернее** Драконьего Хребта |

Река: с западных гор через северный лес → в залив.

## Соседи (снаружи обводки)

| Сторона | Сосед |
|---|---|
| С | **Орден пламенеющей стали** |
| З / СЗ | **Королевство пепельных земель** |
| ЮЗ (за горами) | **Амират** |
| Ю (за заливом) | **Империя Драконьего Хребта** |
| В / ЮВ | **Хозяйство болот скорби** |
| СВ / В | **Элдеринская гавань** |
