# Лунный Овраг

Деревня **южнее Лунного моста** (подпись на карте Лунных Пиков). Связана с «Чёрным урожаем», культом Лолс и (ранее) Пиппином.

## Ключевые точки

Нумерованная карта (ниже) + исторические якоря кампании:

- Колодец (ритуал / Тень) → **#1**
- Дом Харлона *(уточнить на карте при нужде)*
- Часовня Сеханэ → **#7**; алтарь/культ Лолс → руины **#10**
- Дом Морвин (тайный вход) *(уточнить)*
- Дом старосты Брана → **#3**
- Северные поля / птичник → **#5**
- Курган Предков → **#8**
- Руины Храма Лолс → **#10** (риск Араха)

## История в кампании

Одержимость старосты Брана → спасение Пиппина → битва с демонами (сессия 6) → появление «Константина» и старт миссии.
