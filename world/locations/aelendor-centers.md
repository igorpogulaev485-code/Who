# Региональные центры Аэлендора

Мастер назвал известные крупные узлы: **столица**, **Лунный Мост**, **Розалия**. Ниже — сводка по репо.

## Крупные центры (канон)

| Название | Роль | Файл / заметка |
|---|---|---|
| **Сильванор** | Столица / админ. центр | По сводкам после Разлома — **потерян**; Совет Магов / путь героев туда обсуждались. Отдельный файл локации пока тонкий |
| **Лунный Мост** | Священный град, духовный центр | [`lunnyy-most.md`](lunnyy-most.md) |
| **Розалия** | Порт, не столица | [`rozaliya.md`](rozaliya.md) |

## Важные места на карте (не обязательно «крупный региональный центр»)

| Название | Что это | Откуда |
|---|---|---|
| **Лесоверье** | Эльфийская магическая школа | Пути к Розалии (сессия 07) |
| **Красный луг** | Город | Пути к Розалии |
| **Драконий чертог** | Локация у вулкана / малых гор | Короткий путь к Розалии; не проработан |
| **Крепость Булат** | Разрушенная крепость | Слияние 2–3 путей к Розалии |
| **Мёртвый город** | Проклятый карман времени | [`mertvyy-gorod.md`](mertvyy-gorod.md) — не живой центр |
| **Серебряный Страж** | Аванпост | Захвачен Теневой Долиной |
| **Лунный Овраг** | Деревня | [`lunnyy-ovrag.md`](lunnyy-ovrag.md) |
