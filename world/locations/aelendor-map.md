# Карта Аэлендора

Файл: [`assets/maps/aelendor-map.jpg`](../../assets/maps/aelendor-map.jpg)  
Мир целиком: [`world-map.md`](world-map.md)

Красный пунктир — внешние границы с соседями. Белый пунктир — внутренние провинции (**8** контуров ≈ баннер-города). Чёрные линии — дороги.

Паспорт государства: [`states/aelendor.md`](states/aelendor.md) (`fill_wave: 1`).  
Имена провинций 2–8 (кроме **Лунных Пиков**) — рабочие; лок через [`survey-aelendor-state-w2`](../../campaign/plot/survey-aelendor-state-w2.md).

## Соседи (подписи на карте)

| Сторона | Сосед |
|---|---|
| СЗ / север за горами | **Теневая долина** |
| СВ | **Союз речных долин** |
| ЮЗ | **Тёмные леса вечной тени** |
| ЮВ | **Орден пламенеющей стали** |

Запад — море и горная гряда вдоль побережья.

## Города с баннерами (канон карты)

| Город | Положение | Иконка / роль |
|---|---|---|
| **Розалия** | Крайний север, у залива / подножия северных гор | Порт-крепость; у моря корабли. Сосед Теневой Долины |
| **Лунный мост** | СЗ, в кольце гор | Священный град / многобашенный замок |
| **Златоцвет** | СВ, у реки | Укреплённый город |
| **Сильванор** | Центр–запад, узел дорог | **Столица**; крупная крепость-город |
| **Элиандор** | Центр–восток | Крупный замок / город |
| **Вратный град** | ЮЗ, ближе к побережью / Тёмным лесам | Ступенчатая / зиккурат-подобная постройка |
| **Хранитель пик** | Юг, у границы | Замок на пике / южный форпост |
| **Серебряный предел** | ЮВ | Башня / рубеж у Ордена пламенеющей стали |

## Имя «Серебряный Страж» vs «Серебряный предел»

Это **два разных места** (уточнено картой Лунных Пиков):

| Название | Где |
|---|---|
| **Серебряный Страж** | Север провинции **Лунные Пики** у воды — аванпост арки 2 |
| **Серебряный предел** | ЮВ Аэлендора у Ордена пламенеющей стали |

Карта провинции: [`lunnye-piki-map.md`](lunnye-piki-map.md).

## Не подписано баннером (но есть в кампании)

- **Камнеград** — на этой карте **без баннера** (возможна мелкая иконка; точное место уточнить).  
- **Лунный Овраг**, **Лесоверье**, **Красный луг**, **Мёртвый город** — локальные точки; на обзорной карте могут быть без подписи.

## Дороги (логика)

**Сильванор** — центральный перекрёсток. От него лучи к Розалии / Лунному мосту / Златоцвету / Элиандору / Вратному граду / Хранитель пику / Серебряному пределу.

## Сейчас для партии

- Герои: **Лунный мост** (СЗ в кольце гор).  
- **Розалия** — север, держалась в осаде без партии.  
- **Сильванор** — центр, возвращён и укреплён (Филлер).  
- Путь в **Лес Хранителей** (за пределами этой карты, южнее на карте мира) — через юг Аэлендора (**Хранитель пик** / Орден / дальше).

Сводка центров: [`aelendor-centers.md`](aelendor-centers.md).
